# 統計数理 Core 48

100大問のうち Core 48題だけを、分野別の旧No.ではなく**演習価値順**に並べ直した実戦用セットです。

## 品質統一ルール

各問を必ず次の4区分で収録します。

1. `問題`
2. `詳細解答`
3. `本番答案`
4. `採点基準`（20点満点）

さらに各問に、旧100大問No.、演習価値、難度、目安時間、手計算監査を付けます。

## 手計算監査

2026年度の統計検定1級では、通常の四則演算・百分率・平方根が扱える一般電卓が使用でき、必要な統計数値表は問題冊子に掲載される前提です。したがって本セットでは、次を受験者に暗黙要求しません。

- 対数・指数関数の数値評価
- 正規分布CDFやカイ二乗・F分布CDFの数値積分
- 非心F分布の数値評価
- 大きな二項尾確率の大量加算
- 反復計算を必要とする数値最適化
- 行列計算ソフトやプログラムの利用

### 記号

- `◎`: 紙と鉛筆だけで自然に完答できる。
- `○`: 四則演算・平方根程度の一般電卓があると速い。
- `表`: 分位点・CDF値は問題中の与値または統計数値表を使う。数値化そのものは採点対象にしない。
- `修正済`: 元問題のままだと数値関数評価を要求しうるため、Core版で「式まで」「与値使用」に修正した。

**Core 48では `NG`（関数電卓・コード・数値積分が実質必須）は0題**とする。

## 再順位付け基準

同じ演習価値S/Aの中では、次の順で上位に置きます。

1. 他論点へ転用できる骨格の強さ
2. 推定・検定・線形モデルをまたぐ接続性
3. 本番で部分点を積み上げやすいこと
4. 公式暗記より導出練習になること
5. 近い問題との重複が少ないこと
