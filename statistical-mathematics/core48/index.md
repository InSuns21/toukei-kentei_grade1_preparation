## 手計算監査の結論

正規化後のCore 48では、関数電卓・CAS・R/Python・数値積分がなければ完答できない問題は **0題**。

特に負荷が出やすい問題は次のように処理した。

- Core 02, 09, 32: 尤度比の `log` は**式のままで完答**。小数値を要求しない。
- Core 12: 検出力は $\Phi$ を用いた式までで完答。必要なら表の値を問題側から与える。
- Core 13–15, 22: 分位点は問題中に与えるか統計数値表を参照する。
- Core 21: 正確P値の構造を学ぶため、手で和を取れる $K=10$ に設定。
- Core 23: 非心Fの検出力は $P(F_{\nu_1,\nu_2}(\lambda)>c)$ までで完答。数値評価は要求しない。
- Core 31: 正規確率を含む数値は問題中に与え、Monte Carlo分散比較そのものを採点する。

このため「理論問題のはずが、実は数値計算能力を測っている」という逆転を避けている。
