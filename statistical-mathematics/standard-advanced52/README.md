# 統計数理 Standard + Advanced 52

Core 48以外の **Standard 32題 + Advanced 20題 = 52題** を、Core 48と同じ品質基準へ正規化した版です。

## 品質統一ルール

各問を必ず次の4区分で収録します。

1. `問題`
2. `詳細解答`
3. `本番答案`
4. `採点基準`（20点満点）

さらに各問に、旧100大問No.、学習層、演習価値、難度、目安時間、手計算監査を付けます。

## 手計算監査

Core 48と同じ基準を使います。

- `◎`: 紙と鉛筆だけで自然に完答できる。
- `○`: 四則演算・平方根程度の一般電卓があると速い。
- `表`: 分位点・CDF値などは問題中の与値または統計数値表を使う。数値化そのものは採点対象にしない。
- `修正済`: 元の論点を保ちながら、関数電卓・コード・長大な数値計算を暗黙要求しない形へ修正した。

この正規化版では、対数・指数・三角関数・正規CDF・非心分布・大規模な組合せ和・EM反復などを**手で数値評価させない**。必要な場合は式まで、または与値使用とする。

**Standard + Advanced 52では `NG`（関数電卓・コード・数値積分が実質必須）は0題**とする。

## 監査観点

- 問題文だけで必要条件・記号が確定するか
- 解答に飛躍や暗黙の正則性仮定がないか
- 本番答案が20〜30分の答案として過不足ないか
- 採点基準が20点に分解できるか
- Core 48との重複が強すぎないか
- 本番で不自然な数値関数評価を要求していないか
- KaTeX strictで扱える記法だけを使っているか
