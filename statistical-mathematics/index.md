# 統計検定1級 統計数理 100大問

統計検定1級「統計数理」向けのオリジナル演習集です。確率分布、推定、検定、線形モデル、漸近理論、計算統計などを、大問形式で繰り返し使える形に整理しています。

本試験は90分で5問から3問を選ぶ論述式です。この問題集でも、1題をおおむね20〜30分で解くことを想定しています。

## この問題集について

単なる公式確認ではなく、**定義や確率密度関数・尤度などの出発点 → 計算・定理適用 → 結論**までを一つの解答として組み立てる練習を重視しています。

実際の過去問題の問題文を転載するものではありません。

## 学習層

- **Core 48**：本番で繰り返し使う主要な推定・検定・分布計算・線形モデルを優先した48題です。
- **Standard 32**：Core の次に、変形問題や周辺論点への対応力を広げる32題です。
- **Advanced 20**：高度な分布計算、漸近理論、発展的な推測・計算統計を扱う20題です。

各問題には演習価値と難度を付けています。演習価値は **S → A → B** の順に優先度が高く、難度は **B → A → S** の順に高くなります。

## 学習の進め方

まず Core 48 を表の学習順で進め、次に Standard 32、最後に Advanced 20 へ進むのが基本です。苦手分野が明確な場合は、サイドバーから該当する問題へ直接移動して分野横断で解いても構いません。

## 問題一覧

各問題へは左のサイドバーから直接移動できます。100題を学習層・演習価値・難度で比較したい場合は、[100大問の一覧表](exercise-index.md)を利用してください。

## 1問の構成

各大問は原則として、**問題 → 詳細解答 → 本番答案 → 20点の採点基準**で構成しています。詳細解答では、主要な微分・積分・行列計算・漸近展開や定理の適用条件を追えるようにしています。
