# Standard + Advanced 52 品質・手計算監査

監査日: 2026-08-25

対象は `statistical-mathematics/index.md` のうち Core 48を除いた **Standard 32題 + Advanced 20題**。

## 結論

- 全52題を `問題 / 詳細解答 / 本番答案 / 採点基準（20点）` に統一した。
- 全52題に手計算監査を付けた。
- 関数電卓・コード・数値積分・長い反復計算を実質必須とする問題は **0題**。
- ただし元テーマのままでは過剰計算になりやすい論点があり、正規化版では式まで、与値使用、または設定変更で解消した。

## 重点修正

### 1. 数値関数評価の暗黙要求を除去

対象例: 旧No.12, 17, 23, 35, 68, 69, 73, 83, 85, 91, 99, 100。

- コーシー逆関数法の `tan`、フィッシャー zの `atanh`、Box–Mullerの `log`, `sin`, `cos` は**生成式の導出まで**を採点対象とする。
- 切断正規、相関検定、一様最強力不偏検定、複合帰無のP値では、正規累積分布関数・分位点は記号または問題中の与値を使用する。
- 尤度比の対数項は数値化させない。

### 2. 長大な有限和・反復計算を除去

- 旧No.47（二項比率ワルド区間）: 被覆確率は二項和の**式を立てるところまで**。境界での被覆不良は $X=0$ のような小例で確認する。
- 旧No.61（ポアソン混合EM）: E-step/M-stepの更新式導出まで。収束までの反復計算は要求しない。
- 旧No.69（コーシー NP）: 臨界値はサイズ条件の積分式で定義し、数値求解を要求しない。

### 3. Coreとの重複を削減

- 旧No.32はCore側のGaussian bridgeと近かったため、正規化版では独立だが分散が異なる $X_i$ を和で条件付ける一般形へ拡張した。
- 旧No.36は単純な正規–正規ベイズ更新と重ならないよう、ベクトル $X$ のノイズ付き線形観測 $Y=a^TX+\varepsilon$ に一般化した。
- 旧No.68はCoreの多項尤度比検定と重ならないよう、**母数を1個推定する適合度検定の自由度減少**を中心にした。

## 手計算監査の最終判定

- `◎` または `○`: 本番の一般電卓範囲で完結。
- `表`: 分位点・累積分布関数値は与値または統計数値表を使用。
- `修正済`: 数値関数・反復・巨大和を答案作業から除外。
- `NG`: **0題**。

## 今後の運用

新規問題を追加するときも、少なくとも次を信頼区間前レビュー項目とする。

1. 20点採点基準が合計20点か。
2. 関数電卓を暗黙要求していないか。
3. 累積分布関数・分位点・非心分布を数値化させる場合は与値があるか。
4. 数値最適化・EM・大規模和は式の導出までに止めているか。
5. Core / Standard / Advanced間で同じ問題を数値だけ変えて重複させていないか。
