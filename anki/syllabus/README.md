# Ankiシラバス正本

`syllabus.yaml` は、2015年5月8日版「統計検定1級出題範囲表」の画像4枚を目視転記した分類正本です。

## 対象範囲

- 統計数理：公式表の5大項目、26小項目
- 統計応用：共通した事項の7小項目（冒頭の「確率・統計の基礎事項…」は小項目ではなく前提文）
- 統計応用（理工学）：理工学分野の6小項目

人文科学、社会科学、医薬生物学分野は、この教材の対象外なのでカテゴリー、進捗、coverageには登録しません。

## データ構造

- `categories`: 公式表の大項目。表示順、掲載画像ページ、公式の「ねらい」全文を持つ。`aims[]` は同じ「ねらい」欄を共有する小項目と原文を対応付け、省略要約しない。
- `subcategories`: 公式表の小項目の日本語表示名。
- `items`: 各小項目に対応する公式表の「項目（学習しておくべき用語）例」。
- `source.images`: 目視照合に使う画像と公式表上のページ番号。
- `coverage.yaml`: 各小項目と公式用語例に対応するカードID、現在の収録状態。完了対象では全公式用語に同一小項目のカードIDを要求する。

内部IDは機械処理のため英語を使います。`name` は公式表の原名、`display_name` は画面向けの明確な日本語名です。統計応用の2カテゴリーは科目群を「統計応用」、カテゴリーを「統計応用（共通事項）」「統計応用（理工学）」と表示し、それ以外は `section` と `name` を表示します。大項目・小項目・ねらい・用語例を変更するときは画像と再照合し、`validate_cards.mjs` の公式範囲ハッシュも同じ変更単位で更新します。`npm run anki:validate` で階層、ねらい、用語例、coverage、カード分類を検証します。
