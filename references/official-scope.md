# 統計検定1級公式出題範囲との対応

## 範囲を読むときの最重要注意

統計検定1級の公式ページは、試験内容として **「統計検定準1級の内容をすべて含みます」** と明記している。

さらに、2015年の1級出題範囲表では「統計応用」に **各分野に共通した事項** と **理工学固有事項** が別々に置かれている。したがって、本リポジトリでは統計応用（理工学）の範囲を次の三層で管理する。

1. **1級統計応用・共通事項層**: 2015年の1級出題範囲表にある、統計応用の全分野に共通する事項。
2. **1級理工学固有層**: 同じ範囲表の理工学分野に固有の事項。
3. **準1級包含層**: 受験時点で有効な準1級出題範囲。上二層との重複も多いが、より細かな診断法・多変量解析・計算統計などを補完する。

**「理工学固有欄に書いていない = 1級理工学の範囲外」ではない。** たとえば Brown 運動、$L_1$ 正則化、主成分分析、因子分析、判別分析、クラスター分析、ロジスティック回帰、プロビット分析、非線形回帰、サポートベクターマシン、状態空間モデルは、2015年の1級「統計応用・共通事項」にすでに明記されている。

したがって Brown 運動を「準1級を含むから追加するだけの発展項目」と扱うのも不正確である。**1級統計応用の明示範囲であり、かつ準1級にも含まれる重複項目**として扱う。

公式ページ:

- 統計検定1級: <https://www.toukei-kentei.jp/grade/grade1/>
- 統計検定準1級: <https://www.toukei-kentei.jp/grade/grade_pre-1>
- 統計検定1級出題範囲表: <https://www.toukei-kentei.jp/hubfs/files/grade_range/grade1_hani_20150508_2.pdf>

### 2026年試験と2027年以降を混ぜない

2026年11月の1級対策では、**2026年12月31日まで有効な準1級範囲**を包含層として用いる。

準1級は2027年1月1日から新範囲へ移行する。2027年以降の1級対策では、1級公式ページの「準1級をすべて含む」という記述が維持されているかを再確認したうえで、新準1級範囲との差分を取り込む。

## 統計数理: 1級固有層の要約

- 確率: 事象、条件付き確率、独立、Bayesの定理、同時・周辺・条件付き分布。
- 分布: 分布関数、母関数、期待値・分散・共分散、歪度・尖度、変数変換。
- 基本分布: 離散分布、連続分布、多変量正規分布、$t$・カイ二乗・$F$ 分布。
- 極限定理: 大数の法則、中心極限定理、二項分布の正規・Poisson近似。
- 推定: 十分統計量、尤度、最尤法、モーメント法、最小二乗法、最良線形不偏推定、不偏性・一致性・有効性。
- モデル評価・漸近論: Kullback--Leibler情報量、赤池情報量規準、交差検証、Cramér--Rao不等式、Fisher情報量、最尤推定量の漸近正規性、Delta法。
- 区間推定・検定: 被覆確率、Neyman--Pearson、尤度比・Wald・Score検定、正規母集団、適合度、ノンパラメトリック法。
- データ解析: 分散分析、回帰、分割表、不完全データ、シミュレーション、Markov連鎖Monte Carlo法、bootstrap、Bayes法。

過去問照合で独立章として扱う必要が確認された横断項目は、混合分布・潜在変数、経験分布・有限母集団、逆関数法・棄却法・Monte Carlo、Bayes推定、欠測・不完全データである。単なる用語掲載ではなく、分布導出から推定・検定・解釈へ進む複合問題で扱う。

## 統計応用: 1級共通事項層

2015年の1級出題範囲表で、統計応用の各分野に共通する事項として明示されているもののうち、理工学80大問の設計に直接関係する主な項目を整理する。

### 研究・標本調査・実験計画

- 実験研究、観察研究、調査、調査票設計。
- 各種標本抽出、有限母集団、推定、標本サイズ設計。
- 実験計画、分散分析、ブロック化、要因計画など。

### 重回帰・回帰診断

- 重回帰モデル、変数選択、残差分析。
- 一般化最小二乗推定、Gauss--Markovの定理、多重共線性。
- **$L_1$ 正則化法、回帰診断法。**

### 多変量解析・分類・非線形モデル

- **主成分分析、因子分析、判別分析、クラスター分析。**
- **ロジスティック回帰、プロビット分析、一般化線形モデル、非線形回帰。**
- **サポートベクターマシン。**

### 確率過程・時系列

- **Markov連鎖、ランダムウォーク、Poisson過程、Brown運動。**
- 時系列解析、自己回帰和分移動平均モデル。
- **状態空間モデル。**

この層は理工学固有欄とは別に全ての統計応用受験者へ課されるため、`applied-rikou-80/` の範囲監査では必ず独立に確認する。

## 統計応用（理工学）: 1級理工学固有層

2015年の理工学固有欄では、少なくとも次を明示している。

- 多変量解析法: 多変量正規分布、平均ベクトル、分散共分散行列、相関行列、固有値・固有ベクトル。
- 確率過程: ランダムウォーク、Markov過程、Poisson過程、Markov連鎖、時系列解析、自己回帰過程、移動平均過程、自己回帰和分移動平均過程。
- 線形推測: 線形モデル、一般化線形モデル、線形結合の分布、線形対比、線形制約。
- 漸近理論: 大数の法則、中心極限定理、最尤推定量の漸近正規性、漸近分散、一致性、Delta法。
- 品質管理: 管理図、信頼性、保全性、プロセス管理、工程能力指数。
- 実験計画: 実験の計画と実施、固定効果、変量効果、交絡因子、ブロック化、直交表、交絡法。

これは **理工学固有層** であって、統計応用で問われる内容の全集合ではない。上の「統計応用・共通事項層」と合併して読む。

## 準1級包含層: 2026年11月試験で追加確認する主な項目

現行準1級の範囲には、1級統計応用の共通事項・理工学固有事項との重複が多い。したがって、この層では「1級表にない新規論点だけ」を機械的に抜くのではなく、**1級表の語をより細かく具体化する項目**も監査する。

### 回帰・生存時間

- 系列相関、Durbin--Watson比、外れ値、leverage、Q--Qプロットなどの回帰診断の具体項目。
- 打ち切り、比例ハザード。

### 多変量解析・分類評価

- Fisher線形判別、二次判別。
- ROC曲線、曲線下面積、混同行列。
- 階層型クラスター分析、デンドログラム、$k$-means。
- 共分散構造分析、因子回転、多次元尺度法、正準相関、対応分析、数量化法。

### 時系列

- 自己相関、偏自己相関、**ペリオドグラム**。
- 定常性、階差などの診断・モデル同定の具体項目。

### その他の横断項目

- 分割表、対数線形モデル、条件付き独立、グラフィカルモデル。
- 欠測メカニズム、期待値最大化法。
- 情報量規準、赤池情報量規準、交差検証。
- 事前分布・事後分布、階層Bayes、Gibbs sampling、Metropolis--Hastings法。
- jackknife、bootstrap、乱数、棄却法、Monte Carlo、Markov連鎖Monte Carlo法。

`applied-rikou-80/` は80大問という制約があるため、これらを「1用語 = 1大問」で機械的に増殖させない。1級統計応用の明示項目と近年の理工学過去問との接続が強いものを優先して大問化し、低頻度の項目は通常教材への前提リンクや横断問題への統合でカバーする。

## 公式出題範囲と「公式として使える式」の区別

**公式出題範囲に用語・分布・特性値が掲載されていることは、その閉形式を途中計算なしで答案に置いてよいことを意味しない。**

たとえば「中央値」「分位点」「モーメント母関数」がシラバス上の対象でも、設問がそれらを「求めよ・導け・示せ」と要求する場合は、問題文で使用を明示的に許可されていない限り、定義・確率密度関数・累積分布関数・変数変換など採点対象の出発点から導く。

この判断を含む演習・詳細解答の唯一の正本は [`../EXERCISE_GUIDELINES.md`](../EXERCISE_GUIDELINES.md) とする。通常教材固有の差分は [`../textbook/style-guide.md`](../textbook/style-guide.md) に従う。ここでは公式出題範囲の「掲載」と公式利用の「許可」を混同しないことだけを確認し、詳細な執筆規則は重複定義しない。

## 運用

各 `chapter.yaml` の `official_scope` に対応語を記録する。査読では学習目標・例題・演習のいずれかが各対応語を実質的に扱うか確認する。単なる語の掲載を範囲カバーと数えない。

`applied-rikou-80/` の監査では、少なくとも次を別々に記録する。

1. **1級統計応用・共通事項層**を cover しているか。
2. **1級理工学固有層**を cover しているか。
3. **現行準1級包含層**の具体項目に明確な穴がないか。
4. 過去問で実際に理工学午後問題へ接続した論点を Core / Standard に十分配置しているか。
5. 問題文だけで必要記号・概念が読めるか。未習の専門用語・作用素を詳細解答で初めて定義する構成になっていないか。
