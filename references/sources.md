# 参照資料

- `../pdfs/grade1_hani_20150508_2.pdf`: [統計検定1級公式出題範囲表（2015-05-08）](https://www.toukei-kentei.jp/hubfs/files/grade_range/grade1_hani_20150508_2.pdf)。範囲対応の正本。

- [統計検定公式問題集](https://www.toukei-kentei.jp/preparation/books/): 過年度の問題文・詳細解説の正規の入手先。
- `past-exam-trends.md` と `past-exam-index.yaml`: 過去問構造の分析と章別対応。
- `distribution-notation-guide.md`: 分布の台・母数・確率質量関数・確率密度関数と略語導入の正本。

- [Star Pentagon「統計検定1級の過去問と解答例」](https://starpentagon.net/analytics/stat_certificate_past_problems/)

これらは第三者資料である。年度別テーマの索引、解法候補、誤りや訂正の探索に使うが、問題文・正解の正本とはしない。教材へは問題文を転載せず、年度・科目・大問番号と公式入手先を示す。

## 難度・構成の参考

- `../pdfs/MathStat_Answers.pdf`: [久保川達也『現代数理統計学の基礎』著者サポートページ](https://sites.google.com/site/ktatsuya77/xian-dai)で公開されている章末演習と解答例。
- `../pdfs/現代数理統計学の基礎_目次.txt`: 同書の章構成。

久保川資料は著者公開の解答資料であり、教材の問題・解答を転載する許可を意味しない。本プロジェクトでは難度、前提知識、解法パターン、詳細解答で補うべき行間の分析に使う。
