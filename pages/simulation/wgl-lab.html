WebGL2 三角形：コードを直して画素を確かめる

課題

予測：背景は黒、三角形は橙色。描画バッファ中央の画素は三角形内、左下角は背景です。三角形の座標と描画結果を比較してください。

  1. 最初は初期ソースで実行し、中央と左下の RGBA を確認する。
  2. fragment shader の色を変え、画素診断の変化を観察する。
  3. 「構文エラー」プリセットで GLSL の失敗箇所を観察する。
  4. 縦横ピクセル数を変更し、viewport と検査対象座標を確認する。

JavaScript は隔離された sandbox iframe で実行します。GPU／ブラウザのハングを完全には防げません。自分のコード以外を貼り付けないでください。

幅・高さは CSS 表示サイズではなく描画バッファの画素数。最大 2,097,152 画素（負荷が重い場合は縮小）です。ソースはこの端末にバージョン付きで保存できます。
