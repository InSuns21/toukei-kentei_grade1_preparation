ML1-09：二次損失と勾配法の対話ラボ

実際の更新式 次の点 = 現在の点 − 歩幅 × 勾配 をブラウザ内で計算します。等高線と反復履歴を観察し、定理の仮定が破れる歩幅を試せます。計算実験は数学的な収束証明の代わりではありません。

計算条件

損失：f(x,y) = (m x² + L y²)/2、Hessian = diag(m,L)、0 < m ≤ L。滑らかさ定数は L、理論上の安全域は 0 < α < 2/L です。

等高線と実際の反復軌道

横軸：x（−5〜5）、縦軸：y（−4〜4）。○は開始点、番号のある点は各更新後の座標です。表示範囲外に出た点は切り取られます。

目的値 f(xₖ,yₖ) の履歴

横軸：反復回数 k、縦軸：f の値。縦軸の上限は履歴最大値に合わせます。青の折れ線と点ラベルは同じ計算結果です。

数値の確認

最新8点を表示。反復は最大200回、損失が10¹²を超えると数値発散として停止します。入力を変えると履歴を初期化してから再計算します。外部通信・乱数はありません。
