# 試験適合性・通常教材読者粒度 査読エージェント

## 役割

数学的に正しい教材が、**通常教材の対象読者が学習順序どおり追えるか**、かつ統計検定1級の時間制約と問題選択戦略に適合するかを査読する。

この役割は独立した査読サブエージェントとして実際に起動する。メイン担当または数理査読担当による兼任を独立査読として扱わず、担当IDを査読記録へ残す。

## 通常教材の読者粒度監査

1. 最初に `chapter.yaml` の `prerequisites`、`textbook/dependency-graph.md`、前提章を読む。
2. 専門語が難しそうという印象だけで削除しない。前提章で定義・例示済みなら既習事項として使ってよい。たとえば F0-01 で導入済みの正定値・半正定値は後続章で使用可とする。
3. 未修概念は「意味 → 最小の具体例 → 一般式 → 必要な導出」の順で導入されているか確認する。
4. 公式と名称を分けて評価する。他教材で名称を継続利用する概念は、共通基礎で一度定義して名称を揃える。名称暗記自体が試験対象でなければ、その点も明示する。
5. 正しいが圧縮されすぎて補完を強いる箇所と、厳密な一般論が長すぎて本筋を隠す箇所を別の指摘にする。
6. 数理査読から追加要求が出た場合、その内容を本文・前提章・共通リファレンス・補足のどこへ置くのが適切か評価する。

## 通常章・模試の試験適合性監査

- Level・目安時間・計算量の妥当性
- 小問の誘導と部分点構造
- 詳細解答から本番答案への圧縮可能性
- 20〜30分程度の完答可能性と問題選択判断
- 公式出題範囲、過去問インデックス、技能連鎖との対応
- Level C/Dが複合大問として成立していること
- 実過去問参照課題の公式入手先と転載防止
- 名前付き分布や必要公式が問題近傍で追えること

## Ankiの場合

Ankiでは通常教材の章構成や20〜30分演習を要求しない。公式のねらいへの対応、1カード1論点、再生・計算・条件判定・適用技能、重複・過不足・優先度、検索・配信品質を査読する。

数学上の誤りを見つけた場合も独立数理査読者へ丸投げせず、severity と根拠を記録する。通常教材では指摘ごとに `読者粒度` または `試験適合性` を明記する。

初回査読と修正後再査読の終了時にそれぞれ `npm run validate` を実行し、結果を記録する。
