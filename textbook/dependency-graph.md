# 依存関係

通常カリキュラムの機械可読な正本は `curriculum.yaml` の各章の `prerequisites` です。

```text
F0-00（数学速習）
  -> P1 -> P2 -> P3 -> P4 -> S1
  -> I1 -> I2 -> I3 -> I4
  -> L1 -> L2
  -> E1 / E2 / E3 / E4
```

F0-01は通常教材章として廃止済み。`status: supplementary` の補講は通常カリキュラムの進捗集計へ含めない。補講の局所的な機械可読前提は各 `chapter.yaml` の `prerequisites` を正本とする。

```text

  ↓

  ↓

  ↓

  ↓

  ↓

```

位相・コンパクト性へ進む局所的な前提列は

```text
A1 → A1B → A1C → B0 → B → B1 → C → C1
```

とする。A1Bで実数の上限性質・Archimedes性、A1Cでべき集合・集合族・添字集合・添字付き集合族・任意和/任意交差、B0で点列・部分列・「十分大きい添字」、Bで距離空間、B1で位相空間・近傍・部分空間位相・位相的収束・位相的連続性を導入する。A1D・A2・A3・A3Aは順序・整列・選択公理・Zornの補題を追う集合論側の深掘りであり、この局所列の必須前提にはしない。

実数の構成を追う局所列は

```text
D → D0 → D0A → D0B → D0C
```

とする。D0で有理Cauchy列の商から $\mathbb R_C$、D0Aで任意の距離空間の完備化、D0BでDedekind切断から $\mathbb R_D$、D0Cで $\mathbb R_C\cong\mathbb R_D$ を構成する。局所的な必須前提は各 `chapter.yaml` を正本とし、D0Bは上限性質との接続のためA1Bも参照する。

標準通読は細かく刻む一方、局所的な必須前提は各 `chapter.yaml` を正本とする。EはBを前提とし、D1はD+C2+Eを前提とするため、線形代数を測度論より前へ置く。例としてHahn--Banach本体C6はA3+C2から、RKHS本体C7はC2から読める。02AはFarkasの証明を02Bへ参照するが、02Bは02Aを必須前提としないため循環しない。C2のRiesz標準証明はC1AのHilbert射影定理を使用する。

NA5 では、NA4 の Lagrange 補間を積分して補間型求積公式と Newton--Cotes 公式を導き、複合台形則・複合 Simpson 則の大域誤差評価を証明する。さらに重み付き多項式内積と Gram--Schmidt から直交多項式を構成し、その零点定理を閉じた上で Gauss 求積の $2n-1$ 次正確性、重みの正値性、$n$ 点公式としての最適性、Hermite 補間と Rolle の定理による誤差公式まで導く。

NA6 では、ODE1 の初期値問題と $y$ に関する Lipschitz 条件を数値時間発展へ接続する。Euler 法を含む一段法、局所打切り誤差、整合性、大域誤差を定義し、離散 Grönwall 型評価から有限時間摂動安定性を証明する。さらに局所打切り誤差 $O(h^p)$ と摂動安定性から大域誤差 $O(h^p)$ を導き、Euler 法の一次収束を閉じる。整合的でも摂動を過剰増幅する人工的一段法を反例として置き、固定有限時間での収束と NA7 で扱う絶対安定性を区別する。

NA7 では、NA6 の一段法と収束論を高次 Runge–Kutta 法へ拡張し、二次の次数条件と古典4段4次法の自律スカラー4次性を Taylor 展開から導く。さらに線形テスト方程式から安定関数・絶対安定領域・A 安定性・L 安定性を定義し、陽的 Runge–Kutta 法が A 安定になれないこと、後退 Euler 法が A/L 安定であること、台形法が A 安定だが L 安定でないことを証明する。速い減衰モードと遅いモードが共存する硬い系を具体例で解析し、theta 法が A 安定となる必要十分条件 theta >= 1/2 と L 安定となる theta=1 を閉じる。

NA8 では、一般の密な正方連立方程式を Gauss 消去法・LU 分解・部分ピボット選択へ落とし、三角連立方程式の前進代入・後退代入から解法を構成する。行交換なし LU 分解の首座主小行列式による存在判定と一意性、部分ピボット選択付き PA=LU と消去乗数の評価を証明し、要素成長率を通じて安定性の限界を説明する。実対称正定値行列では Schur 補行列の正定値性から Cholesky 分解の存在一意性を閉じる。QR については F0-00E1 の canonical definition を再利用し、Householder 反射の直交性と軸への写像を証明して数値構成へ接続する。最後に正規方程式が2-ノルム条件数を二乗すること、残差・後方誤差・条件数による解の評価を確認する。

NA9 では、行列分解から定常反復を導き、誤差伝播行列のスペクトル半径が1未満であることと任意初期値からの収束が同値であることを Jordan 標準形から証明する。Jacobi 法・Gauss--Seidel 法を具体化し、狭義行優対角性から Jacobi 法の収束を導く。Krylov 部分空間と残差多項式表示を導入した後、実対称正定値系に対する共役勾配法について残差直交性、探索方向の A-共役性、有限回終了、Krylov 空間上の A-ノルム最良近似性を閉じる。さらに NA4 の Chebyshev 多項式を用いて条件数依存の収束評価を導き、対称前処理でスペクトルを改善する意味と計算コストのトレードオフを説明する。

NA10 では、実対称固有値問題を中心に、Rayleigh 商と固有対残差から近傍固有値の存在と対称後方誤差を評価する。冪乗法について固有ベクトル展開から方向収束と固有値比による収束率を証明し、固定シフト付き逆反復法ではシフトに最も近い固有値へ収束する機構を閉じる。さらに Rayleigh 商反復の局所3次収束を導き、複数固有方向へ拡張する直交反復法から QR 法へ接続する。QR 更新が直交相似変換として固有値と対称性を保存することを証明し、シフト・デフレーションの役割まで説明する。

NA11 では、非負行列に対する Perron--Frobenius 理論を正行列から既約・原始行列へ段階的に証明し、列確率行列の定常確率ベクトルへ接続する。既約性は正の Perron 固有ベクトルの一意性を、原始性はスペクトルギャップと冪収束を担うことを2周期反例で分離する。PageRank では dangling node 修正と teleportation を導入し、正の列確率行列として存在一意性を得た上で、1-ノルム縮小性、Neumann 級数、反復差による停止判定、リンク行列摂動に対する感度評価まで導く。

NA12 では、無制約最適化の一階・二階条件、降下方向、厳密直線探索、最急降下法、Newton 法を導入し、実対称正定値二次関数では最小化と線形方程式 Ax=b が同値になることを目的関数差の恒等式まで含めて閉じる。最急降下法には条件数 κ が直接現れる収束評価を証明し、NA9 の共役勾配法については直交性・有限回終了を重複再証明せず、残差が負の勾配であること、歩幅が厳密直線探索から得られること、A-ノルム最良近似性が Krylov アフィン空間上の二次目的関数最小化と同値であることを示す。

FDM1 では、PDE3 の一次元熱方程式を時空間格子へ落とし、前進時間差分・中心二階空間差分から前進時間・中心空間差分法と後退 Euler 差分法を導く。初期条件・非斉次 Dirichlet 境界条件の組込みを具体化し、後退 Euler 差分法の三重対角係数行列が実対称正定値で各時刻ステップが一意可解であることを二次形式から証明する。さらに空間半離散化した ODE 系へ NA7 の前進・後退 Euler 法を適用すると二つの差分スキームが得られることを示し、各ステップの可解性と FDM2 で扱う安定性を明確に分離する。

FDM2 では、FDM1 の熱方程式差分法を摂動の時間発展として解析し、周期格子の離散 Fourier 分解と Parseval 恒等式から von Neumann 型安定性解析の根拠を閉じる。FTCS の増幅因子から拡散 CFL 条件 $r\le1/2$ を導き、条件違反では高周波モードが増幅する機構を示す。後退 Euler 差分法、Crank--Nicolson 差分法、一般の theta 差分法を比較し、$\theta\ge1/2$ の無条件安定性と高周波減衰の違いを NA7 の A/L 安定性へ接続する。さらに斉次 Dirichlet 格子の離散正弦モードを導出し、固定格子の判定と格子細分化に一様な安定条件を区別する。

FDM3 では、NA6 の局所打切り誤差・整合性・大域誤差を時空間差分格子へ移し、FTCS と後退 Euler 差分法の局所残差を Taylor 展開から $O(\tau+h^2)$ と評価する。FTCS では $r\le1/2$ の下で更新係数が凸結合になることから離散最大値原理と最大ノルム縮小性を証明し、線形誤差伝播公式から最大ノルム大域誤差 $O(\tau+h^2)$ を導く。後退 Euler 差分法では最大成分を使う離散最大値原理型の議論により任意の $r\ge0$ で最大ノルム縮小性を示し、CFL 条件なしで同じ収束評価を得る。さらに $r>1/2$ の FTCS が整合的でも高周波摂動を増幅する例を通じ、整合性だけでは収束が閉じず、安定性が必要であることを具体化する。

FDM4 では、一次元定常移流拡散問題を用いて中心一次差分と風上一次差分を比較する。格子 Péclet 数 $Pe_h=|a|h/(2\kappa)$ を導入し、中心差分では $Pe_h\le1$ が隣接係数の非負性と離散最大値原理を保証する一方、$Pe_h>1$ では特性根が負となり交互振動が生じることを具体的に示す。風上差分では任意の $Pe_h$ で離散最大値原理を回復することを証明し、Taylor 展開による修正方程式から $|a|h/2$ の数値拡散を導く。これにより格子細分化・風上化・後続 FEM7 の安定化を同じ移流卓越問題への応答として位置付ける。

FEM1 では、GPDE6 の Poisson 変分形式と双線形形式の有界性・強圧性、GPDE7 の Lax--Milgram 定理を canonical dependency として再利用し、有限次元部分空間上の適合 Galerkin 離散化へ進む。基底を選ぶと離散問題が連立一次方程式になること、強圧性から係数行列が正則になること、対称問題では実対称正定値になることを示す。さらに Galerkin 直交性を証明し、有界性・強圧性と組み合わせて Céa の補題を導く。Poisson の対称形式ではエネルギーノルムで厳密な最良近似性を得る一方、Céa だけでは最良近似誤差のメッシュ幅依存率は決まらないことを明示し、FEM2–FEM4 の空間構成・補間・誤差解析へ接続する。

FEM2 では FEM1 の有限次元 Galerkin 空間を、適合三角形分割・参照要素・局所基底・大域組立てとして具体化する。FEM3 では節点補間、形状正則性、局所補間誤差と大域化を扱う。FEM4 では Céa の補題と補間誤差を接続して H1 誤差を導き、Aubin--Nitsche 型双対論法で L2 誤差を評価する。

FEM5 では、強圧型一変分方程式から制約付き鞍点問題へ進み、制約核上の強圧性と inf-sup 条件から Babuška--Brezzi 型存在一意性を導く。Stokes 方程式では圧力を発散零制約の Lagrange 乗数として定式化し、混合有限要素法、離散 inf-sup、Schur 補行列、偽圧力モード、Taylor--Hood 要素の位置付けまで扱う。

FEM6 では、GPDE10 の時間発展弱形式とエネルギー法、FEM4 の楕円型誤差解析、NA7 の後退 Euler 法を接続する。空間半離散化から質量行列・剛性行列を導き、半離散エネルギー評価、Ritz 射影による空間誤差分解、後退 Euler 全離散化と離散エネルギー評価を閉じる。さらに後退差分の時間残差を積分表示し、十分滑らかな解に対して一次有限要素 + 後退 Euler 法の L2 誤差を O(h^2+τ) と評価する。前進 Euler の CFL 型制約と後退 Euler の無条件安定性を分離し、τ≈h^2 が後者では精度を釣り合わせる選択であることを明示する。

FEM7 では、FDM4 の移流拡散・格子 Péclet 数・風上化と FEM4 までの適合有限要素法を接続する。一次元一様格子では一次有限要素の標準 Galerkin 法が中心差分型の内部節点方程式を作ることを直接導き、要素 Péclet 数が大きいと隣接係数の符号構造が崩れて交互振動を許すことを示す。さらに強形式残差に基づく SUPG を導入し、一次要素の流線方向安定性と強整合性を証明する。一次元で τ=h/(2b) とすれば風上差分と一致し、指数フィッティング型の安定化係数まで導出する。

MC1 では、確率論側の F0-00P5「有限分散版強大数則」、F0-00P5A「独立同分布・有限平均版の強大数則」、F0-00P6A「独立同分布中心極限定理」を canonical dependency として再利用する。積分を期待値へ読み替え、独立同分布標本の平均を Monte Carlo 推定量として定義し、不偏性、分散 $\sigma^2/N$、二乗平均平方根誤差 $\sigma/\sqrt N$ を直接導く。強大数則から強一致性、中心極限定理から $\sqrt N$ 尺度の統計的誤差を得て、標本分散による Monte Carlo 標準誤差と漸近信頼区間へ接続する。さらに離散近似 $Q_h$ を使う場合の二乗平均誤差を、離散化バイアスの二乗と標本分散項へ分解し、MC4 のバイアス・分散・計算費用の設計への入口を作る。

MC2 では MC1 が仮定した独立標本の生成側へ進む。疑似乱数生成器を決定論的状態遷移として定式化し、有限状態なら鳩の巣原理により出力列が最終的に周期へ入ることを証明する。線形合同法の小例から長周期だけでは独立一様性を保証しないことを確認し、理想的な一様乱数を目的分布へ写す逆関数法を一般化逆関数で証明する。さらに提案密度 $g$ と包絡定数 $M$ を用いる棄却法について、受理後の密度が目標密度 $f$ になること、受理率が $1/M$、平均提案回数が $M$ であることを導く。実装側ではシード、乱数ストリーム、サブストリーム、並列割当てと再現性を分離し、異なるシードだけではストリーム間独立性を保証できないことを明示する。

MC3 は MC2 を直接 prerequisite とし、MC1 の分散公式と MC2 の標本生成を受けて分散減少へ進む。対称変量法では $U$ と $1-U$ の負の共分散、制御変量法では最適係数 $c^*=\operatorname{Cov}(Y,X)/\operatorname{Var}(X)$ と最小分散、層化抽出では層内分散と $n_k\propto p_k\sigma_k$ の最適配分、重点サンプリングでは台条件・不偏性・二次モーメントによる分散公式を核心証明まで閉じる。重点密度の選択を誤ると不偏でも分散が無限大になり得る反例を置き、MC4 の multilevel coupling を「同時分布を設計して差の分散を下げる」発想へ接続する。

MC4 は MC3 を直接 prerequisite とし、MC1 のバイアス・分散分解と MC3 の「同時分布を設計して分散を下げる」視点を受けて Multilevel Monte Carlo へ進む。近似階層の期待値を望遠鏡和へ分解し、隣接レベルを同じ基礎乱数で結合してレベル補正の分散を減衰させる。MLMC 推定量の期待値と分散、真の期待値に対する二乗平均誤差分解を証明し、Cauchy--Schwarz の不等式から $N_\ell\propto\sqrt{V_\ell/C_\ell}$ の費用最小配分を導く。さらにバイアス率 $\alpha$、分散減衰率 $\beta$、費用増加率 $\gamma$ から三つの計算量ケースを導出し、二進量子化の例で結合を外すと $V_\ell$ が減衰せず MLMC の改善が失われることを示す。

QMC1 は MC1、F0-00D2C、RA3 を直接 prerequisite とする。MC1 の単位立方体上の積分を点平均で近似する入口から、独立乱数ではなく決定論的点集合の一様性へ進み、RA3 の微分法と F0-00D2C の Fubini の定理で Hlawka--Zaremba 恒等式の微分・積分順序交換を正当化する。アンカー付き直方体の局所ディスクレパンシーとスター・ディスクレパンシーを導入し、一様分布する点列と $D_N^*\to0$ の同値性を包除原理と有限格子近似から証明する。関数側では Vitali 変動と1側にアンカーした Hardy--Krause 変動を導入し、滑らかな関数について多変数微積分の基本定理から Hlawka--Zaremba 恒等式を完全導出して Koksma--Hlawka の不等式を得る。一般の有界 Hardy--Krause 変動への拡張では、多次元 Vitali 変動に対する Stieltjes 積分・部分積分の標準理論だけを意図的黒箱として境界明示する。

QMC2 は QMC1、F0-02C7、F0-00D2E、GPDE3 を直接 prerequisite とする。F0-02C7 の再生核 Hilbert 空間・再生性・再生核を再定義せず stable anchor から再利用し、積分汎関数を Riesz 表現元へ移す。求積誤差を誤差表現元との内積として表し、単位球上の最悪誤差がそのノルムに一致することと、核だけからなる最悪誤差平方の公式を証明する。重み付きアンカー型 Sobolev 空間では GPDE3 の Sobolev 空間を canonical concept として再利用しつつ、F0-00D2E の $L^2$ 完備性を用いて Hilbert 性を閉じ、$1+\gamma\min(x,y)$ の再生性を直接確認する。多次元では積型重み、重み尾による実効切断次元、情報複雑度、tractability を導入し、独立一様乱数点に対する最悪誤差平方の期待値からよい決定論的点集合の存在上界を導く。さらに $\sum_j\gamma_j<\infty$ なら次元に依らない $N^{-1/2}$ 上界を得て、強多項式 tractability を証明する。
