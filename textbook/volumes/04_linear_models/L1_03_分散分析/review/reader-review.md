# L1-03 読者粒度レビュー

- 基準: P3-03、CONTENT_GUIDELINES.md、EXERCISE_GUIDELINES.md、textbook/style-guide.md
- 初回判定: EXPAND
- 初回主要指摘:
  1. 一元配置・二元配置・多重比較の本文骨格はあるが、演習が少なく、平方和分解や交互作用を自力で導く機会が不足。
  2. 「分散分析を棄却した後にどの比較をするか」と「最初から指定された線形対比を検定すること」の違いを問題で確認する必要がある。
  3. Bonferroni法とScheffé法は式だけでなく、何を同時保証するか・比較数との関係を説明できる必要がある。
  4. 二元配置は自由度だけでなく、差の差としての交互作用を数値表から計算する演習が必要。
- 修正方針: Level A 4題、B 4題、C 5題、D 1題、30分ドリルへ拡張し、一元配置・二元配置・線形対比・多重比較を一連の線形モデルとして接続する。
