# P1-02 条件付き確率・独立・Bayesの定理

略語と主要分布の式は`references/distribution-notation-guide.md`を共通索引とし、本章の公式は事象の積と比だけから導入します。

## この章で解けるようになる問題

観測前の確率と観測後の確率を区別し、樹形図だけに頼らず集合式で計算します。検査陽性後の有病確率、複数集団を混ぜたときの確率、非復元抽出、独立性の証明・反証を、20〜30分の論述答案にまとめます。

## 公式出題範囲との対応

| 公式範囲 | 本章の内容 |
|---|---|
| 条件付き確率 | 定義、乗法公式、連鎖律 |
| 統計的独立 | 二事象、有限個の相互独立、対独立との違い |
| ベイズの定理 | 全確率公式、事前確率、尤度、事後確率 |

確率変数の条件付き分布は P3-03 で扱い、本章では事象だけを扱います。

## 前提知識チェック

1. P1-01: $P(A\cap B)$ と $P(A\cup B)$ の違いを述べる。
2. P1-01: 排反分割に可算加法性を適用する。
3. P1-01: 有限等確率モデルで $P(A)=|A|/|\Omega|$ を使う条件を述べる。
4. P1-01: 補集合公式と三事象の包除原理を使う。

## 学習目標

- 条件事象の確率が正であることを確認してから $P(A\mid B)$ を定義する。
- 同時確率を条件付き確率と周辺確率の積へ分解する。
- 独立と排反、対独立と相互独立を反例つきで区別する。
- 分割を見つけ、全確率公式でBayesの分母を構成する。
- Level Cを25分時点で提出可能な形へ閉じる。

合格基準は Level B 85%以上、Level C 70%以上、30分ドリル70点以上です。
