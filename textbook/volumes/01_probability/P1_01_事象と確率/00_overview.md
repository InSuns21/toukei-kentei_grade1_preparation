# P1-01 事象と確率

略語と主要分布の式は`references/distribution-notation-guide.md`を共通索引とし、未導入の測度論用語を前提にしません。

## この章で解けるようになる問題

この章では、確率計算の前に「何を一つの結果とし、どの結果の集合を数えるか」を言語化します。学習後には、三事象の重複分類、増加・減少事象列の極限、包除原理と余事象の選択を論述できるようになります。

## 公式出題範囲との対応

| 公式範囲 | 本章の内容 |
|---|---|
| 確率の計算 | 補集合、差、加法公式、数え上げ |
| 包除原理 | 二事象・三事象、ちょうど何個起こるか |

統計的独立、条件付き確率、Bayesの定理は次章 P1-02 で扱います。

## 前提知識チェック

1. 本章で用いる集合演算の準備として、$A\setminus B=A\cap B^c$ を所属関係から説明する。
2. F0-01: $A\Longrightarrow B$ と $A\Longleftrightarrow B$ の違いを述べる。
3. F0-01: 有限和 $\sum_{k=1}^n k$ を計算する。
4. F0-01: 単調増加する有界数列が収束する理由を説明する。
5. F0-01: 「全ての」と「少なくとも一つ」の否定を書く。

## 学習目標

- 事象を集合として定義し、補集合・和・積・差を日本語と相互変換できる。
- 確率公理から補集合公式、単調性、加法公式を導ける。
- 三事象の包除原理で各項が何回数えられるか説明できる。
- 増加・減少事象列に確率の連続性を適用できる。
- Level Cを20〜30分で記述できる。

合格基準は Level B 85%以上、Level C 70%以上、30分ドリル70点以上です。

## 難度配分について

章末演習は A/B/C/D を3/3/3/1問とします。標準配分より Level C が少ないのは、本章が確率公理と集合演算を初めて導入する基礎章であり、A/Bで定義から式を導く訓練を厚くするためです。その代わり、`P1-DRILL-01` を独立した Level C 相当の30分問題として必須にし、C01--C03と合わせて4題すべてを合格基準の対象にします。後続章 P1-02 以降では標準の Level C 比率へ戻します。
