# CS3 建物・地形・仮想浸水深：高さ基準と透過の検証

[WGL20で定義した仮想浸水深](index.md#def-wgl20-depth)は、**地盤高と仮想水面高の差**です。Project PLATEAUの建物形状は実在サンプル由来ですが、緑の地盤面と青い水面は教材用に生成したものです。現実のDEM、水理モデル、洪水ハザードマップとは無関係です。

## 編集・実行ラボ

このラボでは、合成道路・地盤と公式建物1棟・合成周辺建物8棟を先に深度付きで描き、次に仮想水面をアルファ0.33の透明面として描きます。水面は背景の深度を参照しますが**深度を書き込まない**ため、地物の位置関係を水面単独の描画順で隠さないようにしています。一般の複数透明物体では背面からのソート等がさらに必要で、[WGL8の透明合成](../WGL8/index.md#def-wgl8-source-over)だけで完全な透明描画になりません。

1. terrain.js の waterLevelM を32から30へ変更します。原点の水深は2.29497413 mから0.29497413 mへ変わります。先に紙で計算してからGPUの見た目を比較します。
2. Z誇張を1.5から2へ変更します。**局所Z座標の描画だけ**が変わり、地盤標高・水面標高・水深の報告値は変わりません。高さの違いと水深の違いを混同しないでください。
3. showWater を false にすると水面は消えますが地面・道路・建物は残ります。usePlateau を false にすると公式PLATEAU建物が消えても**合成の周辺8棟・地盤と水深の検算は成立**します。
4. terrain.frag の水面alphaを変え、背後の建物がどの程度見えるかを観察します。透明度の見た目から水深を推定できない理由を説明してください。
5. [WGL15のIDと深度の検査](../WGL15/index.md#def-wgl15-id-buffer)を適用する場合、水面を透明色とIDの両方へ入れるか、CS1のように**水面をIDパスから除外して建物を選ぶ**かを仕様として先に決めます。

## 計算検証

地面の合成式は

$$
G(E,N)=29.70502587+0.02E-0.01N\quad\mathrm m,
$$

仮想水面は $W=32$ mです。原点では $d=\max(0,32-29.70502587)=2.29497413$ m。$(10,-20)$ mでは $G=30.10502587$ m、$d=1.89497413$ mです。数値は**共通の鉛直基準**を仮定した差であり、PLATEAUの地盤がその地形と実際に一致すると主張していません。

**追加演習**。地盤30 m、仮想水面32 mでZ誇張2、alpha0.48とする。(i) 物理的水深、(ii) 描画座標の鉛直差、(iii) alphaを0.1に変えても変化しない値を説明しなさい。

**詳細解答**。(i) [水深の定義](index.md#def-wgl20-depth)より $\max(0,32-30)=2$ mです。(ii) 共通原点を0とすれば、表示差は $2(32-30)=4$ m相当です。(iii) alphaは[WGL8のsource-over合成](../WGL8/index.md#def-wgl8-source-over)で使う**画素色の重み**に過ぎないので、地盤高30 m・水面高32 m・水深2 mはすべて不変です。透明度から水深を読み取るのは誤りです。
