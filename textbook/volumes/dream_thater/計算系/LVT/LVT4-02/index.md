# LVT4-02 Property-Based Testingの原理

前提講座：[LVT4-01](../LVT4-01/index.md)。

前講では、三目並べの着手番号8と9を手で選び、期待出力を比較しました。入力が長いリストや多数の操作の組合せになると、全部の具体例を手で書くことは難しくなります。そこで入力を作る処理と、どの入力にも成り立ってほしい条件を分けます。条件を一度書けば、生成した多数の入力で繰り返し検査できます。

**ブラウザで実行：** [本講の実行ラボ](../browser-lab.html?chapter=LVT4-02)。Lean Web の版は固定版と異なる場合があります。Lake と乱数による実験はラボから Codespaces を開いて実行できます（ログイン・利用枠が必要です）。

## 1. 入力・性質・判定を分ける

着手番号だけを検査する小さな関数を考えます。三目並べの [着手規則](../LVT3-06/index.md#def-lvt3-06-play) では終局や占有状態も拒否しますが、ここではそれらとは独立に番号が範囲内かを返す補助関数を対象とします。入力は自然数（0を含む）、出力は Bool です。仕様では0から8までを許可します。対象関数が返す値とこの要求を比較する処理が判定器です。具体的な入力を供給する処理を入力生成器とします。

<a id="def-lvt4-02-pbt"></a>

<!-- formal-statement-start -->
### 定義（性質ベーステスト）

入力集合を $X$、出力集合を $Y$、検査対象を関数 $f:X\to Y$ とし、任意の入力に対して一意の出力が得られるとする。要求を表す命題 $P(x,y)$ は任意の $x\in X$ と $y\in Y$ について真偽を判定できるとする。

入力生成器が有限列 $x_1,\ldots,x_N$ を供給し、各入力が $X$ に属するとする。各入力について判定器 $c_f:X\to\{\mathrm{true},\mathrm{false}\}$ は、$P(x,f(x))$ が真のとき、かつそのときに限り true を返す。

この生成入力列について $c_f$ を評価し、false となる入力を反例として記録する検査を性質ベーステスト（Property-Based Testing）とする。
<!-- formal-statement-end -->

<!-- definition-example-start: def-lvt4-02-pbt -->
**定義の確認**　対象を $f(n)=(n\le 9)$ の真偽を返す関数とします。要求 $P(n,y)$ は、$y$ が $n\le 8$ の真偽と一致することです。両方とも自然数の比較と Bool の等しさだけで判定できます。生成器が [8,9,10] を返すと、すべて自然数であり、各比較は下表の通りです。

| 入力 | 実測値 | 要求値 | 判定器 |
| --- | --- | --- | --- |
| 8 | true | true | true |
| 9 | true | false | false |
| 10 | false | false | true |

要求と実測が一致する場合だけ true を返すため、反例は9です。この反例は「すべての自然数で要求を満たす」という主張を否定します。
<!-- definition-example-end -->

要求は対象実装から独立に決めます。たとえば誤って要求も「9以下」に変更すると、9を生成しても失敗しません。生成能力と判定の正しさは別の責務です。前講の [単体テストの成功条件](../LVT4-01/index.md#def-lvt4-01-unit-test) では個々の期待出力を指定しました。ここでは入力から期待出力を計算する一つの規則を指定するため、追加の入力にも同じ判定器を使えます。

## 2. 有限列に対して何を検査したか

入力列には同じ値が現れても構いません。0件の列も扱えるようにします。判定器を先頭から評価して、すべて true の場合に true を返す関数を allPass とします。実装は空列に true、先頭がある列に先頭の判定と残りの判定の論理積を返します。反例一覧を求める failures は判定が false の入力だけを順番通りに残します。

<a id="prop-lvt4-02-all-pass"></a>

<!-- formal-statement-start -->
### 命題（生成入力列の全件成功条件）

任意の自然数上の Bool 値関数 $c$ と有限リスト $L$ に対し、allPass が空リストに true を返し、先頭 $x$ と残り $T$ からなるリストに $c(x)$ と allPass(c,T) の論理積を返すとする。このとき次が成立する。

$$
\operatorname{allPass}(c,L)=\mathrm{true}
\iff \forall n\in L,\ c(n)=\mathrm{true}.
$$
<!-- formal-statement-end -->

**証明の見取り図**　空列では反例が存在しません。先頭と残りに分けると、全件成功は先頭の成功と残りの全件成功に分解できます。

<!-- proof-start -->
### 証明

[Leanのリストの帰納法](../LVT2-05/index.md#principle-lvt2-05-list) を用いる。命題 $P(L)$ を上の同値式とする。空リストの場合、左辺は定義により true=true で真である。右辺の全称命題も、空リストに属する自然数がないので真である。

残りのリスト $T$ について命題が成立すると仮定し、先頭に $x$ を付けたリストを考える。allPass が true であることは Bool の論理積の定義により、次の二条件と同値である。

$$
c(x)=\mathrm{true},\qquad
\operatorname{allPass}(c,T)=\mathrm{true}.
$$

帰納仮定を第二条件に適用すると、条件は $c(x)=\mathrm{true}$ と「任意の $n\in T$ で $c(n)=\mathrm{true}$」になる。先頭付きリストの要素は、先頭 $x$ であるか残り $T$ に属するかのどちらかである。従って二条件から任意の要素での判定成功が従う。逆に全要素で成功すると仮定すれば、先頭を代入して第一条件を得て、残りに属する任意の要素にも適用して第二条件を帰納仮定から得る。論理積が true になるため allPass が true である。

空列と先頭付きリストの両方で成立するので、有限リストについて命題が成立する。
<!-- proof-end -->

空列でも全件成功となることに注意しましょう。これは一件も検査しなかったというだけで、実装の正しさを示す証拠ではありません。すべての自然数について正しいことを示すには、[有限な例示テストと全入力一致](../LVT1-01/index.md#prop-lvt1-01-test-boundary) で区別した全称命題が必要です。

## 3. 入力生成を変えて反例を探す

まず生成される入力を紙でも追えるよう、非負整数の開始値 $s$ と件数 $N$ により次の列を作ります。添字 $i$ は0から始め、16で割った余りを取ります。

$$
x_i=(s+5i)\bmod16,\qquad 0\le i<N.
$$

これは開始値で巡回列の位置をずらす方式です。コードの seed はこの開始値を表し、乱数生成器の内部状態を指定するものではありません。独立な乱数ではありません。まずこの方式で入力の生成と判定を切り離し、次に乱数で入力を選ぶ実験を行います。

~~~lean
def samples (seed count : Nat) : List Nat :=
  (List.range count).map (fun i => (seed + 5 * i) % 16)

def rangeCheck (f : Nat → Bool) (n : Nat) : Bool :=
  f n == decide (n ≤ 8)
~~~

List.range は0から count の直前までのリストを作り、map が各添字を入力に変換します。rangeCheck は関数の出力と仕様の Bool を比較します。正しい候補 correctRange は $n<9$、誤った候補 badRange は $n\le 9$ を判定します。

| 開始値 | 6個の入力 | badRange の反例 |
| --- | --- | --- |
| 0 | 0, 5, 10, 15, 4, 9 | 9 |
| 1 | 1, 6, 11, 0, 5, 10 | なし |

例えば開始値0の添字4では $5\cdot4=20$ で余り4、添字5では25の余り9です。開始値1の添字5では26の余り10です。badRange の誤りは9だけにあるので、同じ件数でも検出結果が変わります。開始値0で16個生成すると0から15が一度ずつ現れます。実際の列は

$$
0,5,10,15,4,9,14,3,8,13,2,7,12,1,6,11.
$$

全16値が相異なるので、この範囲の全件検査になります。ただし自然数全体の検査ではありません。

ここまでに具体的な入力の検査ができました。次に、正しい候補が生成列の外も含めて要求を満たすことを、任意の自然数を対象に確かめます。

<a id="prop-lvt4-02-correct-range"></a>

<!-- formal-statement-start -->
### 命題（範囲判定の全入力正当性）

任意の自然数 $n$ に対し、correctRange が $n<9$ の真偽を返し、rangeCheck がその値と $n\le8$ の真偽を比較するとする。このとき rangeCheck(correctRange,n) は true である。
<!-- formal-statement-end -->

**証明の見取り図**　自然数の8と9の間には別の自然数が存在しないため、二つの比較は同じ真偽を返します。

<!-- proof-start -->
### 証明

任意の自然数 $n$ を固定する。$n\le8$ の場合、$n\le8<9$ なので $n<9$ も真である。従って実測値と要求値はともに true である。

$n\le8$ が偽の場合、自然数であることから $n\ge9$。従って $n<9$ も偽であり、実測値と要求値はともに false である。どちらの場合でも二つの Bool は等しいので rangeCheck は true を返す。任意の自然数について成立する。
<!-- proof-end -->

Lean ではこの二場合を分けて検査します。

~~~lean
theorem correct_property (n : Nat) : rangeCheck correctRange n = true := by
  by_cases h : n ≤ 8
  · have h' : n < 9 := by omega
    simp [rangeCheck, correctRange, h, h']
  · have h' : ¬ n < 9 := by omega
    simp [rangeCheck, correctRange, h, h']
~~~

omega は自然数・整数の線形算術の証明を探すタクティクです。この二場合で使うのは整数の隣接する境界の比較だけです。この全称命題は有限列の成功から得たものではなく、入力を任意の自然数として証明したものです。

## 4. 乱数で選ぶ場合に反例を見逃す割合

0〜15から一つずつ値を選び、選んだ値を候補から取り除かず、各回の選択が他の回の値に影響しない状況を考えます。全16値が同じ割合で選ばれると仮定します。これがここで用いる独立一様抽出のモデルです。長さ $N$ のすべての列は同じ割合で現れ、重複も許します。

<a id="prop-lvt4-02-uniform-miss"></a>

<!-- formal-statement-start -->
### 命題（独立一様抽出での反例の見逃し）

有限入力集合 $D$ の要素数を $m\ge1$、固定された判定器が false を返す入力の個数を $b$ とする。$D$ から復元して独立一様に $N\ge1$ 回抽出するとき、反例を一件も得ない確率は次の値である。

$$
\left(\frac{m-b}{m}\right)^N.
$$
<!-- formal-statement-end -->

**証明の見取り図**　全入力列の個数と、すべての成分で反例を避けた列の個数を別々に数えます。

<!-- proof-start -->
### 証明

各回に $m$ 通りの候補があり、選択した値は次回の候補から除かれない。従って1回なら $m$ 通り、長さ $k$ の列それぞれに次の値を $m$ 通り付けられるので長さ $k+1$ では $m^k m=m^{k+1}$ 通りである。この繰り返しにより長さ $N$ の全列は $m^N$ 通りである。独立一様の仮定から各列は等しい確率を持つ。

反例でない入力は各回に $m-b$ 通りである。すべての回でそこから選ぶ列の個数も同じ数え上げにより $(m-b)^N$ 通りになる。$m\ge1$ なので全列の個数は正であり、求める確率は個数の比である。

$$
\frac{(m-b)^N}{m^N}
=\left(\frac{m-b}{m}\right)^N.
$$

反例が一つも存在しない場合 $b=0$ なら1、すべてが反例の場合 $b=m$ なら $N\ge1$ より0になる。
<!-- proof-end -->

badRange について $D=\{0,1,\ldots,15\}$ とすると、反例は9だけなので $m=16,b=1$ です。2回の抽出では全列256通り、9を一度も含まない列は225通りです。見逃しは225/256、少なくとも一件発見する割合は31/256です。回数を増やせば見逃しの割合は減りますが、有限回では0になりません。

もし生成範囲が0〜8だけであれば、その範囲には反例が一つもありません。何回抽出しても見逃しの確率は1です。反例が存在し得る入力を生成範囲に含めることが重要です。また、この式は開始値による先ほどの固定列には適用できません。例えば開始値0で16個なら必ず9を含みますが、独立一様抽出16回なら9を一度も選ばない列も存在します。

## 6. 演習と詳細解答

### Level A

### LVT4-02-A01 判定器の値

badRange の入力8、9、10で実測値、要求値、判定器の値を求めよ。

- Level: A

<!-- solution-start -->
#### 詳細解答

8では $8\le9$ と $8\le8$ がともに真なので実測・要求が true、判定も true。9では $9\le9$ が真、$9\le8$ が偽なので実測 true、要求 false、判定 false。10では両方の比較が偽なので実測・要求ともに false だが一致しており判定は true。よって反例は9だけである。
<!-- solution-end -->

### LVT4-02-A02 生成列

開始値2で4件生成せよ。式は $x_i=(2+5i)\bmod16$、$0\le i<4$ とする。

- Level: A

<!-- solution-start -->
#### 詳細解答

添字0、1、2、3を代入すると割られる数は2、7、12、17。前三つは16未満なのでそのまま余りとなる。17=16+1 から最後の余りは1。従って入力列は [2,7,12,1] である。9を含まないので badRange の反例は得られない。
<!-- solution-end -->

### LVT4-02-A03 空リスト

badRange の判定器を空リストで検査するとき、allPass と反例一覧の値を求めよ。全称命題は成立したか。

- Level: A

<!-- solution-start -->
#### 詳細解答

allPass の空リストでの値は true。反例一覧は、調べる入力が一つもないので空リストである。[生成入力列の全件成功条件](#prop-lvt4-02-all-pass) は空リストに属する入力についてのみ主張するので成立する。一方、すべての自然数に対する badRange の正しさは、9で判定が false になるため偽である。
<!-- solution-end -->

### LVT4-02-A04 重複

入力列 [9,8,9] に対して badRange の反例一覧を求めよ。

- Level: A

<!-- solution-start -->
#### 詳細解答

9では実測 true と要求 false が不一致、8では双方 true で一致し、最後の9も不一致である。failures は判定が false の要素を順番通りに残すので、結果は [9,9]。集合の要素数ではなくリストに記録するため重複も残る。
<!-- solution-end -->

### Level B

### LVT4-02-B01 通過した誤実装

開始値1で6件生成すると badRange が通ることを確かめ、全入力で正しくないことを示せ。

- Level: B

<!-- solution-start -->
#### 詳細解答

割られる数は1、6、11、16、21、26であり、16で割った余りは [1,6,11,0,5,10] となる。1、6、0、5は8以下なので実測・要求とも true。11、10は9より大きいので双方 false。従って [生成入力列の全件成功条件](#prop-lvt4-02-all-pass) により allPass は true。ところが9を別に入力すれば badRange は true、要求は false である。生成列に9がなかったため誤りを見逃した。
<!-- solution-end -->

### LVT4-02-B02 見逃しの割合

0〜15から独立一様に2回復元抽出する。9を一度も生成しない確率と少なくとも一度生成する確率を求めよ。0〜8から選ぶ場合も答えよ。

- Level: B

<!-- solution-start -->
#### 詳細解答

16値のうち反例は9の一値である。 [独立一様抽出での反例の見逃し](#prop-lvt4-02-uniform-miss) に $m=16,b=1,N=2$ を代入する。全列は $16\cdot16=256$ 通り、9を避ける列は $15\cdot15=225$ 通り。見逃しは225/256、発見は $(256-225)/256=31/256$。0〜8の場合は $m=9,b=0$ なので見逃しは $(9/9)^2=1$、発見は0である。生成範囲が異なれば確率も変わる。
<!-- solution-end -->

### LVT4-02-B03 任意の生成列

correctRange では、任意の有限自然数リストについて allPass が true になることを示せ。テスト結果から全称命題を推論したわけではないことも説明せよ。

- Level: B

<!-- solution-start -->
#### 詳細解答

[範囲判定の全入力正当性](#prop-lvt4-02-correct-range) の二場合を確認する。任意の自然数 $n$ を取る。$n\le8$ なら $n<9$ が真であり、$n>8$ なら自然数なので $n\ge9$、従って $n<9$ は偽である。どちらでも correctRange と要求 $n\le8$ の Bool が一致する。よって判定器は任意の $n$ で true である。

ここで任意のリスト $L$ を固定する。任意の $n\in L$ は自然数なので、上の全称命題をその $n$ に適用できる。[生成入力列の全件成功条件](#prop-lvt4-02-all-pass) の右辺が成立するから左辺も成立する。全称命題から有限検査の結果を導いたのであり、逆向きではない。
<!-- solution-end -->

### Level C

### LVT4-02-C01 生成器と要求の設計

開始値0で16件生成する検査と、0〜15から独立一様に3回抽出する検査を比較する。badRange の反例一覧と乱数実験の見逃し確率を求めよ。さらに判定器まで誤って $n\le9$ を要求する場合の問題点を述べ、修正後の正常系と誤実装の期待結果を設計せよ。

- Level: C

<!-- solution-start -->
#### 詳細解答

固定列は [0,5,10,15,4,9,14,3,8,13,2,7,12,1,6,11]。0〜15を一度ずつ含むので、8以下では実測・要求とも true、10以上では双方 false、9だけが不一致となる。反例一覧は [9]。correctRange は $n<9$ と $n\le8$ が自然数で同値なので全件成功となる。

独立一様抽出の場合、[独立一様抽出での反例の見逃し](#prop-lvt4-02-uniform-miss) に $m=16,b=1,N=3$ を代入する。

$$
16^3=4096,\qquad 15^3=3375.
$$

見逃しは3375/4096、発見は $(4096-3375)/4096=721/4096$。固定列と違い、3回の抽出では9を含まない場合がある。

判定器まで $n\le9$ を要求すると、badRange と常に同じ Bool を作るため反例は出ない。この判定器が検査している命題は元の要求ではない。判定器を独立な仕様 $n\le8$ に戻す。正常系では correctRange の固定列16件が全件成功し、意図した失敗系では badRange の反例が [9] となることを期待する。さらに失敗入力9を保存して単独で再実行できるようにする。これで生成器・要求・判定器それぞれの役割と、有限検査の保証範囲を区別できる。
<!-- solution-end -->

具体値と全称命題のLean検査は [ExerciseSolutions.lean](lab/ExerciseSolutions.lean) で確認できます。確率の数え上げは本文の論証を使い、同ファイルでは整数の分子・分母を確認します。
