1. Leanの計算・証明・エラーを試す

実際の教材ソースを読み込みます。コードを編集してから Lean Web を開くと、オンラインの Lean が検査し、InfoView に計算値・型・エラー・証明目標を表示します。

Lean Web で実行

Lean Web は外部のオンライン実行サービスです。開いた時点で編集内容が渡ります。機密コードは入力しないでください。提供されるLeanの版は教材の固定版と異なる場合があります。固定版や複数ファイルの確認は次の実行環境を使います。

2. Lake・複数ファイル・差分テストを実行する

GitHub Codespaces を開く

GitHubへのログインと利用枠が必要です。利用枠を超えると課金される場合があります。作成または再開したブラウザ版VS Codeの端末で以下を実行します。初回セットアップの完了を待ってから実行してください。



意図した失敗例は正常系から分けて実行します。Lean Web は単一ファイルの検査、Codespaces は固定版のLakeビルドと実行ファイル・外部言語のテストを担当します。
