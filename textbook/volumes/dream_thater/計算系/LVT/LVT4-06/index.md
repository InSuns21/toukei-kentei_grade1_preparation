## 1. 正解の値が分からなくても二つの実行を比較できる

ある入力に対する正解を個別に用意するのは大変です。しかし[三目並べの着手規則](../LVT3-06/index.md#def-lvt3-06-play)では、盤面と着手位置をともに180度回転しても、着手の合法性は変わりません。元の実行と回転後の実行に関係を要求することで、一方の結果だけでは分からない不整合を発見できます。一般に、入力を変換したときの出力間に仕様から導いた関係を要求する手法を考えます。入力変換とは入力を別の有効な入力へ写す関数であり、二値関係とは二つの出力の組のうち許す組を集めたものです。例えば等しさを要求するなら、許す組は同じ値を二つ並べた組です。

<a id="def-lvt4-06-metamorphic"></a>

<!-- formal-statement-start -->
### 定義（メタモルフィック関係）

入力集合 $D$ の各入力に対して必ず終了し、同じ入力には常に同じ $Y$ の値を返す関数 $f:D\to Y$ の仕様に対して、入力変換 $T:D\to D$ と、出力の二値関係 $R\subseteq Y\times Y$ を選ぶ。仕様が全ての $x\in D$ について

$$
(f(x),f(T(x)))\in R
$$

を要求するとき、この条件をメタモルフィック関係とする。メタモルフィックテストは具体的な入力 $x$ で両方を実行し、この条件を検査する。
<!-- formal-statement-end -->

<!-- definition-example-start: def-lvt4-06-metamorphic -->
**定義の確認**　自然数のリストの長さを返す関数を考える。$D$ は0を含む非負整数の全有限リスト、$Y$ は0を含む非負整数、$T$ は逆順にする操作、$R$ は二つの数が等しい関係である。長さを数える操作は有限リストで必ず終了し、値は一意に決まる。長さ $k$ のリストでは、逆順は位置 $i$（0から $k-1$）を $k-1-i$ に写し、同じ操作を二度行うと元の位置に戻る。空リストも空リストのままである。従って逆順は $D$ 内の変換で、要素数を保存するため全入力で要求が成立する。[1,2,3] と [3,2,1] の長さはともに3。この入力の検査は成功する。一方、常に0を返す関数でも関係だけは成立する。正解を保証するには長さそのものの仕様も必要である。
<!-- definition-example-end -->

## 2. 三目並べの回転対称性

[三目並べの状態](../LVT3-06/index.md#def-lvt3-06-board) を $s=(b,p)$（盤面と手番）とします。マス番号は上段が0,1,2、中段が3,4,5、下段が6,7,8です。180度回転は番号 $i$ を $8-i$ に写します。回転前の $i$ の印を回転後の $8-i$ に置き、手番は変えません。この状態を $\rho(s)$ と書きます。外部入力の着手 $n$ は Lean の `Nat`、すなわち0を含む非負整数です。$n$ が9未満なら $8-n$ に写し、9以上なら $n$ のままにします。これを $r(n)$ と書きます。範囲外を合法な位置に写してはいけません。

[三目並べの着手規則](../LVT3-06/index.md#def-lvt3-06-play) の結果は [Option型](../LVT1-03/index.md#def-lvt1-03-option) で、拒否なら `none`、成功なら新状態 $t$ を包んだ `some(t)` です。以下の「可換性」とは、先に着手して結果を回転する場合と、先に入力を回転して着手する場合が一致することです。

<a id="prop-lvt4-06-rotation"></a>

<!-- formal-statement-start -->
### 命題（着手の180度回転との可換性）

[三目並べの着手規則](../LVT3-06/index.md#def-lvt3-06-play) play を用いる。任意の状態 s（9マスと手番）および非負整数 n に対し、ρ(s) はマス i の印を 8−i に移し手番を保存する状態、r(n) は n が9未満なら 8−n、そうでなければ n とする。play(s,n) が none なら play(ρ(s),r(n)) も none である。play(s,n) が some(t) なら play(ρ(s),r(n)) は some(ρ(t)) である。
<!-- formal-statement-end -->

**証明の見取り図**　盤面の勝利線、満盤、添字の範囲、着手先が空かどうかを順番に保存します。合法な場合は印を書き込む位置と次の手番まで照合します。

<!-- proof-start -->
### 証明

$0\le i\le8$ なら $0\le8-i\le8$ であり、

$$
8-(8-i)=i.
$$

従って回転は9マスの全単射（各マスがただ一つのマスに対応し、全マスが対応先になる写像）である。$\rho(s)$ の盤面を $b_\rho$ と書くと、$b_\rho(8-i)=b(i)$ であり、上の等式から任意の回転後の位置 $j$ について $b_\rho(j)=b(8-j)$ となる。Lean の [Fin型](../LVT1-05/index.md#def-lvt1-05-fin-index) では番号欄 $i$ と $i<9$ の証明を組にする。回転先も0〜8なので同じ型の添字を構成できる。

[三目並べの勝利条件](../LVT3-06/index.md#def-lvt3-06-win) に現れる8本の線を回転すると次のようになる（線内の順序は勝利判定に影響しない）。

| 元の線 | 回転後の線（昇順） |
|---|---|
| 0,1,2 | 6,7,8 |
| 3,4,5 | 3,4,5 |
| 6,7,8 | 0,1,2 |
| 0,3,6 | 2,5,8 |
| 1,4,7 | 1,4,7 |
| 2,5,8 | 0,3,6 |
| 0,4,8 | 0,4,8 |
| 2,4,6 | 2,4,6 |

各線の印は回転先で一致するので、任意のプレイヤーについて勝利線があることは回転後にも成立する。回転は自分自身が逆変換なので逆も成立する。満盤とは空マスがないことであり、9マスの全単射により回転前後で同値である。従って終局判定は保存される。

[三目並べの着手規則](../LVT3-06/index.md#def-lvt3-06-play) の枝を順に比較する。終局なら両方で none。終局でなく n≥9 なら r(n)=n≥9 なので両方で none。終局でなく $n<9$ なら $0\le r(n)=8-n<9$ であり、$\rho(s)$ の $r(n)$ の印は $s$ の $n$ の印に等しい。占有されていれば両方で none、空なら両方で着手が成功する。

最後の場合、[一マス更新の保存性](../LVT3-06/index.md#prop-lvt3-06-write) により、元の着手結果 t は n に現在の手番の印を書き、他のマスを保存し、手番を交代する。任意の回転後のマス $j$ を取る。$j=8-n$ なら $8-j=n$ なので、どちらの実行も元の手番の印を置く。$j\ne8-n$ なら $8-j\ne n$ なので、元の着手でも回転後の着手でも対応するマスを保存する。よって j の印は両経路で一致する。手番の交代も両方で同じなので、回転後の着手結果は ρ(t) である。
<!-- proof-end -->

例えば履歴 [0,4] の後で X が2に着手すると、元の盤面では X が0,2、O が4にある。回転した履歴は [8,4]、着手は6となり、X が8,6、O が4にある。次の手番はどちらも O です。合法性だけでなく、結果の全マスと手番を比較できます。[メタモルフィック関係](#def-lvt4-06-metamorphic) の入力集合は状態と自然数の組、変換は (s,n) を (ρ(s),r(n)) に写す操作です。出力の関係 R は none 同士、または some(t) と some(ρ(t)) の組からなります。いつも拒否する誤実装もこの回転関係を満たすため、絶対的な正解を調べるテストも残します。

## 3. テストそのものを試す

テストが全部成功したとき、実装に欠陥がないのか、テストが弱いのかを区別したくなります。そこで正しいとみなしている実装の規則を一つ変え、元のテストがその変更を拒否できるか確かめます。変えた実装を変異体と呼びます。前提となる [単体テスト](../LVT4-01/index.md#def-lvt4-01-unit-test) と同じように、固定した入力と期待値を用い、テストごとに同じ条件から実行します。観測とは、返り値全体や受理の真偽など、テストが判定に使う結果です。

<a id="def-lvt4-06-mutation"></a>

<!-- formal-statement-start -->
### 定義（変異テストと変異スコア）

共通の入力集合と観測方法を固定する。基準実装と全変異体は各入力で有限時間内に終了し、観測結果が一意に決まるものとする。有限個のテストの集合 $S$ が基準実装に対して全て成功するとする。各テストは独立に同じ初期条件から実行し、成功・失敗は指定入力の観測結果だけで決まる。有限集合 $M$ は指定された変更で作った変異体からなる。各テストを変異体にも適用し、少なくとも一つが失敗する変異体の集合を $K(S)$ とする（検出された変異体）。変異体のうち、固定した観測結果が基準実装と全入力で同じものは、この観測に関する同値変異体である。

$|A|$ は有限集合 $A$ の要素数を表す。同値変異体の集合 $E$ を確定でき、$M$ から $E$ を除いた集合 $M\setminus E$ が空でなければ、変異スコアは

$$
q(S)=\frac{|K(S)|}{|M\setminus E|}
$$

である。同値変異体ではどのテストも基準と同じ観測結果で成功するため、$K(S)\subseteq M\setminus E$ となる。従ってスコアは0以上1以下である。同値性が未確定なら、$M$ が空でない場合に総数に対する検出割合 $|K(S)|/|M|$ を報告して区別する。
<!-- formal-statement-end -->

<!-- definition-example-start: def-lvt4-06-mutation -->
**定義の確認**　入力集合を {0,1}、観測を返り値そのものとし、関数 f(x)=x を基準とする。常に0、常に1、入力をそのまま返す別コードの三つを変異体とする。すべての実装は二入力で終了し、一意な値を返す。入力0で期待値0を照合するテストは基準で成功する。常に1の変異体だけ失敗する。入力1では基準が1を返すので常に0は同値でなく、入力0では常に1も同値でない。三つ目だけは0,1の両方で基準と同じなので E に入る。従って q=1/(3−1)=1/2。入力1を追加すると常に0も検出して q=2/2=1 になる。
<!-- definition-example-end -->

三目並べでは観測を「着手を受理するか」という [Leanの真偽値型](../LVT2-01/index.md#def-lvt2-01-bool) の Bool に限定します。正しい play が some なら true、none なら false とします。次の三つの変異体を作ります。

- M1：終局判定を残し、範囲を調べるが、占有済みの検査を削除する。
- M2：終局判定を削除し、範囲と空マスだけを調べる。
- M3：終局判定を残すが、非負整数 n を9で割った余り（n mod 9、Lean では `n % 9`）に写してから空マスを調べる。範囲外拒否の代わりに折り返してしまう。

入力は基準実装で履歴を再生した状態と次の着手の組です。変異体で過去の履歴を再生するのではなく、同じ状態を与えます。T/F はそれぞれ true/false。各行は一つの入力、各列はその入力に対する実装の観測結果です。基準列と異なる値がある変異体の列を一度ずつ数えれば、検出集合の要素数が求まります。

| テスト（履歴；着手） | 基準 | M1 | M2 | M3 |
|---|---|---|---|---|
| a: []; 0 | T | T | T | T |
| b: [0]; 0 | F | T | F | F |
| c: []; 9 | F | F | F | T |
| d: [0,3,1,4,2]; 8 | F | F | T | F |

a は初期盤面の空マス、b は X が占めたマス、c は範囲外（9 mod 9=0）、d は X が0,1,2を占めて勝利した後の空マスです。d までの履歴は途中で終局していません。各変異体は基準と異なる出力の具体例を持つので、この観測で同値変異体はありません。全4件で3/3、a,bだけなら1/3、aのみなら0/3です。

<a id="prop-lvt4-06-monotone"></a>

<!-- formal-statement-start -->
### 命題（テスト追加による変異検出の単調性）

[変異テストと変異スコア](#def-lvt4-06-mutation) の条件を満たすテスト集合 S と U があり、S⊆U とする。入力集合、変異体集合 M、観測方法、同値変異体集合 E、各テストの初期条件と成功・失敗の判定を固定する。このとき K(S)⊆K(U) である。分母が正なら q(S)≤q(U) である。
<!-- formal-statement-end -->

**証明の見取り図**　S の中で失敗したテストは、U に追加した後にも存在する。その一件を検出の証人として使います。

<!-- proof-start -->
### 証明

任意の m∈K(S) を取る。[変異テストと変異スコア](#def-lvt4-06-mutation) の定義から、あるテスト t∈S が m で失敗する。S⊆U より t∈U である。同一の入力、観測、決定的な実行なので U でも t は m で失敗する。従って m∈K(U) となる。任意の m について成立するので包含が得られる。有限集合の包含から |K(S)|≤|K(U)|。共通の正の分母で割ると、

$$
\frac{|K(S)|}{|M\setminus E|}\le\frac{|K(U)|}{|M\setminus E|},
$$

すなわち $q(S)\le q(U)$ である。
<!-- proof-end -->

これはテストを消さず、変異体と判定を固定したときの話です。新たな変異体を追加して分母を変えた場合、検出割合が減ってもテストが弱くなったとは限りません。

## 4. 実行した経路と検出能力

変異を用意する前にも、テストがどの規則の分岐を通ったかを確認できます。対象の play は [着手入力の優先分類](../LVT4-04/index.md#def-lvt4-04-input-class) と同じ順序で終局、範囲外、占有済み、受理を区別します。ここで経路とは、実行時に通る処理の順序です。本講の計測では基準実装の最後に到達した枝を一つ記録し、その枝に至る経路を区別します。

<a id="def-lvt4-06-coverage"></a>

<!-- formal-statement-start -->
### 定義（経路カバレッジ）

計測する実装を固定し、計測対象として空でない有限経路集合 C を用意する。テスト集合 S をその実装で実行して訪れた対象経路の集合を V(S)⊆C とする。この計測での経路カバレッジは

$$
c(S)=\frac{|V(S)|}{|C|}
$$

である。経路は計測前に定め、同一経路の複数回訪問は一つと数える。
<!-- formal-statement-end -->

<!-- definition-example-start: def-lvt4-06-coverage -->
**定義の確認**　C を play の四つの終了経路（終局、範囲外、占有済み、受理）とする。a,b,a を基準実装で実行した場合、a は終局でも範囲外でも占有済みでもないため受理、b は非終局・範囲内だが占有済みなので拒否となる。従って V は受理と占有済みの二経路だけで C の部分集合である。重複を除くと2経路なのでカバレッジは2/4=1/2。テスト c は非終局だが範囲外、d は終局なので、a,b,c,d は全て異なる経路でカバレッジは4/4=1。ここで関数 $c(S)$ の c はカバレッジ、単独のテスト名 c は表の範囲外入力である。
<!-- definition-example-end -->

この計測は終了経路の網羅率であり、実際の行カバレッジ（実行行の割合）や分岐カバレッジ（各分岐の真偽の訪問割合）とは区別します。複合条件の内部の真偽や全履歴を数えたわけでもありません。

同じ a,b,c,d でも、出力を取得するだけで何も検査しないテストは、基準の4経路全てを通りますが、どの変異体も失敗させません。反対に、a,b,c,d の期待値を表の基準列に固定して照合すれば3体全てを検出します。

| テストの実行と判定 | 経路カバレッジ | 変異スコア |
|---|---:|---:|
| a の期待値を照合 | 1/4 | 0/3 |
| a,b の期待値を照合 | 2/4 | 1/3 |
| a,b,c,d を実行するだけ | 4/4 | 0/3 |
| a,b,c,d の期待値を照合 | 4/4 | 3/3 |

さらに3/3はこの3体だけに関する結果です。例えば「マス0だけ誤って拒否する」変異体なら a が検出できますが、「マス7だけ誤って拒否する」変異体なら上の4件の受理テストは0だけなので検出できません。回転によるテストや新しい期待値を追加する動機になります。

## 5. Leanで再現する

[実験ソース](lab/LvtStrength.lean) は LVT3-06 の play、after を利用します。`rotateInput` は $r(n)$ に対応し、範囲内だけ反転します。`rotateState` は $\rho(s)$ に対応し、新しい位置 i に元の位置 8−i の印を置きます。コードでの i は `Fin 9` であり、`rotateIndex` は番号欄 `i.val` と範囲の証明から新しい添字を構成します。これは第2節で得た $b_\rho(j)=b(8-j)$ を実装したものです。元の実行結果を回転した値と、回転した入力で実行した結果を比較する rotateCheck では、none 同士なら真、some 同士なら9マスのリストと手番がともに等しい場合だけ真です。片方だけ some なら偽になります。

~~~lean
def rotateInput (n : Nat) : Nat := if n < 9 then 8 - n else n

def accept (s : State) (n : Nat) : Bool := (play s n).isSome
~~~

三つの変異体は Bool を返します。観測を Bool に限定しているため盤面更新自体の誤りは検出できません。suite は a,b,c,d の入力を並べたものです。matrix は基準と3体の受理値を表の順に計算します。kills は基準と異なる行があるか調べ、covered は基準実装の各終了経路が少なくとも一回現れたかを四経路それぞれについて数えます。`route` の番号0,1,2,3は順に終局、範囲外、占有済み、受理を表します。`accept` の `.isSome` は Option の some を true、none を false に写します。重複入力を追加しても訪問済みの経路は増えません。

Lean の rotateInput_twice は全自然数で入力回転を2回行うと元に戻ることを証明します。盤面の可換性の全称命題については第2節の紙上証明を参照してください。実験はその命題の具体的な4入力と、履歴 [0,4] の後の2、履歴 [1,4] の後の7という合法着手の例を検査します。全称命題をコンパイルで証明したという意味ではありません。

~~~bash
cd "textbook/volumes/dream_thater/計算系/LVT/LVT4-06/lab"
lean --version
lake build
lake test
lake env lean LvtStrength.lean
lake env lean Failure.lean
~~~

固定版は Lean 4.35.0。正常系は LVT4-06 OK を表示し、#eval では受理の行列、検出数3、訪問経路数4を確認できます。最後のファイルは意図的に不正な等式を証明しようとする例です。Lean Web の版は固定版と異なる場合があります。Codespaces の利用にはログインと利用枠が必要です。

### Level A

### LVT4-06-A01 回転写像

着手 0,3,4,8,9,12 を回転し、もう一度回転せよ。

- Level: A

<!-- solution-start -->
#### 詳細解答

[着手の180度回転との可換性](#prop-lvt4-06-rotation) で定めた r を用いる。0,3,4,8 は9未満なので順に8,5,4,0となる。9,12 は範囲外なのでそのまま。再び r を作用させると8→0、5→3、4→4、0→8、9→9、12→12で、元の全入力に戻る。
<!-- solution-end -->

### LVT4-06-A02 勝利線

X が 0,3,6 を占めるとき、回転後の勝利線を求めよ。手番が O なら回転後の手番は何か。

- Level: A

<!-- solution-start -->
#### 詳細解答

回転先は 8−0=8、8−3=5、8−6=2。昇順に並べると 2,5,8 であり、[三目並べの勝利条件](../LVT3-06/index.md#def-lvt3-06-win) の右列である。回転はプレイヤーを交換しないので手番は O のまま。
<!-- solution-end -->

### LVT4-06-A03 変異の検出

テスト b,c だけで表の M1,M2,M3 のうちどれが検出されるか。

- Level: A

<!-- solution-start -->
#### 詳細解答

b は基準 F、M1 T、M2 F、M3 F なので M1 を検出する。c は基準 F、M1 F、M2 F、M3 T なので M3 を検出する。M2 は二件とも基準と同じ。検出集合は {M1,M3} で、分母は同値でない3体なので [変異テストと変異スコア](#def-lvt4-06-mutation) より2/3。
<!-- solution-end -->

### LVT4-06-A04 訪問の重複

a,a,c,c,c を実行したときの終了経路カバレッジと期待値照合による変異スコアを求めよ。

- Level: A

<!-- solution-start -->
#### 詳細解答

a は受理、c は範囲外。訪問した異なる経路は2個で対象は4個だから [経路カバレッジ](#def-lvt4-06-coverage) は2/4=1/2。a ではどの変異体も基準と同じであり、c では M3 だけが真になり基準と異なる。従って [変異スコア](#def-lvt4-06-mutation) は1/3。5回という実行数は分子に使わない。
<!-- solution-end -->

### Level B

### LVT4-06-B01 回転後の着手

履歴 [1,4] の後に着手7を与える。元の盤面と回転後の盤面について着手結果の印と手番を求めよ。

- Level: B

<!-- solution-start -->
#### 詳細解答

履歴の二手は X が1、O が4で、いずれも空マスへの着手で勝利線はない。7は空で範囲内なので、[合法着手の必要十分条件](../LVT3-06/index.md#prop-lvt3-06-success) から受理され、X が1,7、O が4、他は空、次の手番は O となる。回転すると履歴 [7,4]、着手1。X が7に、O が4に置いた後、1が空なので X が1に置く。全マスの印と手番は元の結果を回転したものに一致する。[着手の180度回転との可換性](#prop-lvt4-06-rotation) の成功の場合の具体例である。
<!-- solution-end -->

### LVT4-06-B02 同値変異体を除外する

三目並べの受理判定に、空マス判定を二重に連言する変異体 M4 を加える。全4件のテストでの変異スコアと単純な検出割合を求めよ。

- Level: B

<!-- solution-start -->
#### 詳細解答

終局と範囲外の分岐は変わらない。残る非終局・範囲内の入力では空マス条件を P とすると元は P、変更後は [連言](../LVT2-02/index.md#def-lvt2-02-and) P かつ P である。P が真なら両方真、偽なら両方偽。全入力で受理値が等しいので M4 は同値変異体である。M1,M2,M3 は b,d,c でそれぞれ検出される。従って [変異テストと変異スコア](#def-lvt4-06-mutation) の分母は4−1=3、スコアは3/3=1。単純な検出割合は3/4である。同値性を証明したため除外できる。
<!-- solution-end -->

### LVT4-06-B03 対称性を満たす欠陥

常に none を返す関数が回転関係を満たすことを示し、その欠陥を検出するテストを一つ作れ。

- Level: B

<!-- solution-start -->
#### 詳細解答

任意の s,n について元の出力は none、回転した入力の出力も none。[メタモルフィック関係](#def-lvt4-06-metamorphic) に第2節で指定した R を用いると (none,none) は R に含まれるので、全入力で条件を満たす。しかし初期状態で0は範囲内で空であり、終局でもない。[合法着手の必要十分条件](../LVT3-06/index.md#prop-lvt3-06-success) から play(initial,0) は some となるべきである。この受理値が true であることを検査するテストなら、常に none の実装は false となって失敗する。
<!-- solution-end -->

### Level C

### LVT4-06-C01 テスト集合を設計する

元の三変異体に「マス7だけを余分に拒否する」M4 を加える。a,b,c,d の期待値照合での変異スコアと終了経路カバレッジを求め、追加一件で全変異体を検出せよ。回転関係を使った検出方法も示せ。

- Level: C

<!-- solution-start -->
#### 詳細解答

M4 は元の受理判定が真かつ n≠7 のときだけ真とする。a は着手0なので M4 でも真。b,c,d は元から偽なので M4 でも偽。従って a,b,c,d では M1,M2,M3 の3体だけを検出する。初期盤面の7は空、範囲内、非終局なので、元は受理し M4 は拒否する。この証人があるため M4 は同値ではない。[変異スコア](#def-lvt4-06-mutation) は3/4、[経路カバレッジ](#def-lvt4-06-coverage) は四経路を通るので4/4。

初期盤面から7を着手するテスト e を加え、受理値 true を要求すると M4 が失敗する。[テスト追加による変異検出の単調性](#prop-lvt4-06-monotone) から既存3体も検出されたままなので4/4となる。e の基準経路は受理で既に a が訪問しており、カバレッジは4/4のままである。

別法として初期盤面に1を着手する実行と回転先7を比較する。初期盤面は回転しても同じで、[着手の180度回転との可換性](#prop-lvt4-06-rotation) より両方が受理されるか両方が拒否されるはずである。M4 は1を受理するが7を拒否するため、この関係に違反する。ただしこの関係だけでは全拒否実装を排除できない（B03）。絶対的期待値と回転関係は併用する。
<!-- solution-end -->
