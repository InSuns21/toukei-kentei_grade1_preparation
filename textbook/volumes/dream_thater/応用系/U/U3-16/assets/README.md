# U3-16 BSM PDE 残差の再計算

## 内容と入力契約

無配当の $g(s)=s^2/K$ に対する BSM 古典解、Itô の二階項を省いた候補、
連続配当率 $q=0.01$ に適応する古典解、配当を無視した候補を比較します。
解析的な偏導関数から PDE の各項と残差（円／年）を求め、別経路で
中心差分の残差を計算します。Monte Carlo は用いず、時間離散化誤差と
丸め誤差だけを区別します。

既定値: $s_0=K=100$ 円、$r=0.03$ 年$^{-1}$、$\sigma=0.20$ 年$^{-1/2}$、
$T=1$ 年、$q=0$ または $0.01$ 年$^{-1}$。$s_0,K,T,\sigma>0$ と $q\ge0$ が必要です。

## 実行

Python 3.10 以降の標準ライブラリだけで動作し、通信・外部依存は不要です。
リポジトリルートから実行します。

## 誤差と検証

- 解析値の oracle: $\mathcal R[v]=0$、誤った時間指数の $\mathcal R[w]=\sigma^2w$、
  配当なしの解を $q>0$ に流用すると $\mathcal R_q=-2qw$。
- $t=0.5,s=100$ で中心差分を用い、$dt=0.08,0.04,0.02$ 年、
  株価差分幅 $ds=1$ 円／株を比較します。
- 中心差分の理論打切り誤差は $O(dt^2+ds^2)$。
  二乗価格では空間差分の誤差は厳密算術で0ですが、浮動小数の丸めは残ります。
  テストは時間刻み半減で誤差がほぼ4分の1になることを検証します。
- 計算量は1行当たり定数回の評価、メモリも $O(1)$。
  乱数・サンプルサイズ・統計的信頼区間はこの実験には該当しません。
- $t\pm dt$ が満期外にならないよう内部時点のみ数値微分します。
  満期支払額が滑らかでない商品では古典的な二階差分の端点評価を
  そのまま使わないでください。

この検証は教材の数式検算であり、金融商品の予測や売買推奨ではありません。
