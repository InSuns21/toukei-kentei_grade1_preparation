# U3-41 数値実験の再現方法

このディレクトリの jump_diffusion.py は Python 標準ライブラリだけで動き、Poisson 混合の欧州 call 価格と厳密なジャンプ拡散の満期標本 Monte Carlo を比較します。外部の金融相場は使いません。

    python3 jump_diffusion.py --samples 20000 --seed 20261115
    python3 jump_diffusion.py --samples 80000 --seed 20261115
    python3 jump_diffusion.py --samples 20000 --seed 20261115 --intensity 0

株価・権利行使価格・価格は円、満期は1年、金利と配当は連続複利年率、変動率は年の平方根に対する係数、ジャンプ強度は年率です。対数ジャンプ倍率の正規分布は平均 -0.08、標準偏差0.18です。

## 検証の読み方

- Poisson 混合式は N_T=n を条件にした正規積分を n=0..60 で足します。表示する残差上界は E[S_T 1_{N_T>60}] に基づく別の Poisson 分布の上側確率を、正の級数の初項と等比級数による保守的な上界で評価します。累積確率を1から引く数値的な桁落ちは避けています。
- MC は Poisson 回数と独立な正規乱数を生成し、同一のブラウン値に対する終端の厳密式を使います。刻み幅は存在しないため、時間離散化バイアスはありません。
- call 標本の不偏標本分散を n-1 で割る標本分散と、その平方根をさらに sqrt(n) で割る標本平均の推定標準誤差を区別します。
- MC 平均と解析価格の差はランダムなので、単一実験が解析値に完全一致する必要はありません。標本数4倍では典型的な標準誤差が1/2になります。
- 配当込みの無裁定チェックは E_Q[e^{-rT} S_T]=S0 e^{-qT} です。右辺は q を忘れた S0 ではありません。
- ジャンプ強度0では配当付き Black–Scholes の極限を再現します。ジャンプ倍率を固定して動かさず、強度のみを変えると、別の Q の選択に相当する点に注意します。
