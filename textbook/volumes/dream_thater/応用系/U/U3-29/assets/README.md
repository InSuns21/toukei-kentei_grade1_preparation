# U3-29 強・弱収束の再現実験

Python 3.10 以上、追加ライブラリなし。標準ライブラリの乱数を固定シードで実行します。

~~~sh
python textbook/volumes/dream_thater/応用系/U/U3-29/assets/gbm_convergence.py
python -m unittest discover -s textbook/volumes/dream_thater/応用系/U/U3-29/assets/tests -v
~~~

- モデルは GBM の $s_0=100$ 円、$\mu=0.08$ 年$^{-1}$、$\sigma=0.20$ 年$^{-1/2}$、$T=1$ 年。
- $n=2400$ 本の独立経路、$m=4,8,16,32,64,128$。$m=128$ の $N(0,1/128)$ 増分を各経路で生成し、粗い格子では隣接増分を加算して **Brown 運動そのものを共有**する。
- 厳密格子値は指数公式、Euler–Maruyama は一次左端更新、Milstein は $(\Delta W)^2-h$ の補正を使用。強誤差の平均二乗誤差（Mean Squared Error; MSE）は同一経路差の二乗平均、線形支払の弱偏りは差の標本平均とする。
- 強 MSE の理論値は [U3-28 有限刻みモーメント恒等式](../../U3-28/index.md#prop-u3-28-finite-mse)から計算する。理論と実測は混ぜず、実測の MSE と弱偏りには独立経路間の標本標準誤差を計算する。
- 細刻みの収束率判定では有限標本の揺れが支配し得る。テストは理論式そのものの刻み比、乱数固定再現性、6標準誤差以内の整合、および境界値を確認する。特定の乱数列に対する数学的保証とは呼ばない。
- 時間費用は素朴な全レベル処理で $O(nL m_{\max})$、$L$ はレベル数。全レベル同時のパス記憶は $O(m_{\max}+nL)$。
- 有限刻み理論 MSE は大数の差として計算するため、極細刻みでは丸め誤差が問題になる。観測用の分割数は128までに制限している。
- 表示する対数–対数図は同じ有限刻み理論式に基づく静止図であり、乱数を変えても図は変化しない。費用とモデルの仮定をそろえた比較である。
