# U3-10 Lookback 検証

Python 3.10 以降の標準ライブラリだけで動く。価格の通貨は円、預金倍率は1期間当たり $R=21/20$。年率・暦日換算、外部データ、乱数・外部パッケージは用いない。

章ディレクトリから次のコマンドで実行する。

    python3 assets/lookback_tree_check.py
    python3 -m unittest discover -s assets/tests -v

## 独立する二つの計算

- 全列挙は Python の product で $2^N$ 本の経路を作り、各経路の株価と最大値を順次更新し、$Q$ の経路確率で直接和を取る。
- 圧縮法は整数指数 $(Z,H)$ の**到達可能状態のみ**を前進生成してから、満期受取額を後ろ向きの二子平均で評価する。全経路の確率・受取額を経路単位では列挙しない。

両者の受取額定義は固定行使価格最大値参照 call $(M_N-K)_+$。$S_0=100,u=5/4,d=4/5,R=21/20,K=110$。$ud=1$ が圧縮格子表現の前提である。

## 確認する不変量

- $q=(R-d)/(u-d)=5/9$、$0<q<1$、$ud=1$。
- $N=2$ の価格は $582500/35721$ 円、$N=3$ は $155912500/6751269$ 円。
- $N=3$ の時点2における $UD$ と $DU$ は同じ株価 $100$ 円だが、条件付き価格は $100/7$ 円と $500/63$ 円。
- $N=0$ は即時受取額、到達できる最高値より高い $K$ では価値0。
- $N=0,\ldots,6$ に対して二実装が有理数として厳密に一致。時点ごとの状態数と全経路数を出力する。

正しい丸め誤差評価を行うために浮動小数点へ変えるのは出力表示の最終段階だけであり、内部の全演算は Fraction である。
