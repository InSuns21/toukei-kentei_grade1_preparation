# U3-27 再現実験

Python 3.10 以降・標準ライブラリのみで実行できます。入力ファイル、商用API、数値計算パッケージは不要です。

~~~sh
python textbook/volumes/dream_thater/応用系/U/U3-27/assets/ito_integral_diagnostics.py
python -m unittest discover -s textbook/volumes/dream_thater/応用系/U/U3-27/assets/tests -v
~~~

ブラウザ上の講義内 Python パネルも同じソースを読み込みます。初回は Pyodide の通信が必要な場合があります。T=1、固定シード 20261114、各 m で2048独立標本路。1標本路では半刻みの独立な N(0,T/(2m)) 増分を2m個作り、左端 Itô 和、真の時刻中点和、両端の算術平均を**同じ Brown 運動**から求めます。行ごとの m は別の乱数列を使います。m=32 固定の n=256/1024/4096 は別々の独立な実験です。

数学的ベンチマーク：左端和と Itô 厳密値の平均二乗誤差（Mean Squared Error; MSE） は T²/(2m)、真の時刻中点和と Stratonovich 厳密値の MSE は T²/(4m)。中点和と Itô 厳密値との差の期待値は T/2、両端算術平均和は Stratonovich 厳密値に**任意の刻みで代数的に一致**します。MSE の推定値は無作為なので理論値に完全一致せず、出力する標準誤差（Standard Error; SE）、すなわち SE(MSE) がモンテカルロ推定の誤差の規模です。テストは恒等式を厳密な許容差で検査し、乱数実験は推定標準誤差の6倍を許容します。

計算量：各 m・n の組で時間 O(mn)、保存する誤差配列は O(n)、1経路の半増分を構築するための一時記憶は O(m)。計測値の誤差棒は近似的な記述に使い、有限 n の絶対誤差保証ではありません。

最後に、大きな定数 c=10¹² を加えた被積分過程 c+W の左端和から cW_T を引く実験があります。数学的には中心化した W の左端和と等しいものの、浮動小数点数では大きい数の差を取る際に有効桁が失われ得ます。この差は **確率積分の離散化誤差ではなく丸め・桁落ち**です。厳密な機械ごとの出力値をテストの合否には使いません。
