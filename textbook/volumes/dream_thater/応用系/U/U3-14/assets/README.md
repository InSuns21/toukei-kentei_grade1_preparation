# U3-14 幾何 Brown 運動の分布検算

## 再現条件

- Python 3.10 以降。追加ライブラリ不要。
- 金額：円、時間：年、$\mu$：年$^{-1}$、$\sigma$：年$^{-1/2}$。
- 基準値：$S_0=100$ 円、$\mu=0.08$、$\sigma=0.20$、$T=1$ 年。
- 標本：50000経路、固定シード20261113。各経路の満期値は $S_T=100\exp(0.06+0.20Z)$（$Z\sim N(0,1)$）から直接生成。
- 有限標本の標本分散には不偏分母 $n-1$ を使う。理論分散は確率分布の分散。
- 対数増分と株価を同じ数値軸として比較しない。それぞれの理論平均・分散を比較する。
- 時間刻みを使わないので SDE の時間離散化誤差は0。サンプリング誤差は残る。

## 計算の独立検査

理論 oracle は Python 側では標準ライブラリの指数関数・正規分布関数で計算します。単体テストは、対数ドリフト $0.06$、対数分散 $0.04$、株価平均 $100e^{0.08}$、株価分散 $10000e^{0.16}(e^{0.04}-1)$、$P(S_1>S_0)=\Phi(0.3)$ を別式と照合します。

Monte Carlo 検証では、理論の標本平均標準誤差 $\sqrt{\operatorname{Var}(S_1)/n}$ および二値比率の標準誤差 $\sqrt{p(1-p)/n}$ の5倍を許容します。理論基準値との浮動小数レベルの完全一致は要求しません。$\sigma=0$ と $T=0$ では点質量として処理し、連続密度の分母に0を代入しません。

本ページの式が基準であり、試行結果だけを数学的な証明として使いません。収束次数や Euler 法との比較は U3-28、U3-29 で扱います。
