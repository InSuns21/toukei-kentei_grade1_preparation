# U3-15 数値検証

## 目的と前提

定数係数の無配当 GBM と預金 $B_t=e^{rt}$ を用いて、$P$ 下の正規乱数に
$Z_T=\exp(-\theta W_T^P-\theta^2T/2)$ の重みを掛けたとき、
$E_P[Z_T]=1$、$E_P[Z_Te^{-rT}S_T]=S_0$、二乗支払額の
$Q$ 下の割引期待値が複製費用に等しいことを検証します。

標準設定: $S_0=K=100$ 円、$T=1$ 年、$\mu=0.08$ 年$^{-1}$、
$r=0.03$ 年$^{-1}$、$\sigma=0.20$ 年$^{-1/2}$、乱数シード 20261113。
Python 3.10以降の**標準ライブラリのみ**を使用し、外部ネットワークは不要です。

## 再現手順

リポジトリのルートから:

    python textbook/volumes/dream_thater/応用系/U/U3-15/assets/risk_neutral_check.py

    python -m unittest discover -s textbook/volumes/dream_thater/応用系/U/U3-15/assets/tests -p "test_*.py" -v

出力表は理論値、標準正規密度の数値積分、50000 標本の加重平均、
理論標準誤差で規格化した標本誤差（z-score）を示します。

## 誤差と境界

- 理論 oracle は指数正規モーメントから導出した値で、近似誤差を含みません。
- 数値積分は標準正規軸の $[-9,9]$ を16000等分した中点則で、
  区間外の裾を切り落とし、刻み幅誤差もあります。
- Monte Carlo は固定シードの正規標本です。観測平均の標準誤差は、
  各重み付き量の**$P$ 下の厳密な分散**の平方根を $\sqrt n$ で割った値です。
  各統計量は6標準誤差以内を回帰テストとします（確率的な基準）。
- $P$ の下で単に割り引いた株価の平均は $100e^{0.05}$ 円であり、
  $Q$ による $100$ 円と一致しません。この差を標本誤差と混同しません。
- $T\le0$、$s_0\le0$、$\sigma\le0$、$K\le0$ は入力契約外です。
  $\sigma=0$ の裁定反例は講義本文で別に扱い、ゼロ除算しません。

この実験は**終端分布からの直接生成**であり SDE の時間離散化誤差はありません。
数値結果は投資判断や将来株価の予測ではありません。
