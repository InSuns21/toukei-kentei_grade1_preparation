# U3-09 のブラウザ実行・ローカル検算

この章は離散二項木の上側障壁への接触を含む判定であり、時点の間の連続的経路は仮定しない。すべての金額は円、$S_0=100$、$u=6/5$、$d=4/5$、$R=21/20$（1期間倍率）、$K=90$、$H=120$、$q=5/8$ とする。無配当、rebate なし、満期 $N$ に一度だけ決済する。

## 公開ページ内で再実行

講義本文の Python file lab を開き「このページで実行」をクリックする。公開中の同一 barrier_tree_check.py を Pyodide Worker で実行する。初回の Pyodide 読み込みには通信が必要で、15秒でタイムアウトする場合は再実行する。計算用の追加ライブラリや外部 API は不要。ブラウザ実行は手元のローカル Python 環境を使用しない。

## ローカルでの再実行

Python 3.10 以上の標準ライブラリのみ。作業位置は講義 U3-09 ディレクトリとする。

~~~sh
python3 assets/barrier_tree_check.py
python3 -m unittest discover -s assets/tests -v
~~~

検算の期待値：

| 期間 N | 監視日 M | in（円） | out（円） | vanilla（円） |
| --- | --- | ---: | ---: | ---: |
| 2 | 0,1,2 | 1000/49 | 125/98 | 2125/98 |
| 2 | 0,2 | 1875/98 | 125/49 | 2125/98 |

$N=3$ の時点2、満期まで1期間の条件付き out 価値は UD が0円、DU が15円。異なる計算法（全経路列挙と拡張状態の後退帰納）がすべて完全一致することがテストの検証条件。$N=1,2,3,4$ の各監視日程と in/out/vanilla を比較する。

二項モデルの状態を全経路列挙すると $O(N2^N)$ 時間、フラグ付き後退計算は状態キャッシュを用いることで $O(N^2)$ 時間と記憶量で評価できる。演習とブラウザの基準例は $N\le3$ であり、標準的な CPU と少量のメモリで完了する。乱数や数値反復は使わず、許容誤差は**有理数の完全一致**（ゼロ）。図は概念を示す模式図であり、シミュレーション結果のプロットではない。

単調性検証は同一の $N,u,d,R,K,H,Q$ の下で、監視日だけ変更する。Pyodide の読み込みや環境制限で実行できない場合も、本文の受取額表および手計算から価格が再現できる。
