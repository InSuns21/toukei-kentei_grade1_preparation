# U3-11 CRR・三項木の格子検証

Python **3.10 以上**、標準ライブラリのみ。外部データ・乱数・API・追加依存パッケージは不要。株価と受取額は **円**、満期 $T$ は **年**、$r$ は年率の連続複利、$\sigma$ は年$^{-1/2}$、各分割の預金倍率は $R=e^{rT/N}$ とする。無配当・無摩擦・正の評価用確率というモデル仮定を満たすときだけ価格を出す。

## 何を独立に照合するか

1. `price`：満期格子の各 $H(S_{N,j})$ から後退帰納し、二項では2子、三項では3子で価格を求める。全経路を列挙しない。
2. `square_closed_form`：各期の $E_Q[M^2]$ を直接求めて $S_0(E_Q[M^2]/R)^N$ を計算する。格子後退ループは使用しない。
3. `benchmark`：Taylor 展開から証明した極限 $S_0 e^{(r+\sigma^2)T}$ を独立計算する。

基準例は $S_0=100$ 円、$T=1$ 年、$r=0$、$\sigma=0.2$、受取額 $S_N^2/S_0$。解析極限は $104.0810774192\ldots$ 円。$N=1,2,4,8,16,32,64$ の両格子価格、絶対誤差、全層節点数、計算時間（ミリ秒）を表示する。時間は実測であり、ブラウザ・マシン・実行回に依存する。出力先は標準出力、図は不要なため生成しない。

テスト5件では、すべての確率が正で和が1、$E_Q[M]=R$、後退計算と独立二乗モーメント法の一致、call の極端な行使価格と $K=0$ の境界、粗すぎる刻みの拒否、二乗商品における格子倍増時の誤差半減を検査する。**二乗商品の収束次数を非滑らかな call に一般化しない**。検証は Python double 精度の範囲であり、極端に大きい $N$ や $\sigma$ では指数関数の丸め・オーバーフローが起こり得る。

## 計算量

後退計算は二項 $(N+1)(N+2)/2$ 節点、三項 $(N+1)^2$ 節点を処理し、時間 $O(N^2)$、メモリ $O(N)$。これは**満期株価のみ**に依存する商品についての上界で、経路依存商品には追加状態が必要となる。
