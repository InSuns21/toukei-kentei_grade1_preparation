# U3-26 再現手順

Python 3.10 以上・標準ライブラリのみ。カレントディレクトリを問わず次のコマンドで実行できます。

~~~sh
python textbook/volumes/dream_thater/応用系/U/U3-26/assets/monte_carlo_pricing.py
~~~

乱数シードは 20261114 に固定し、正規乱数は Python の random.Random.gauss を使用します。観測数 256・1024・4096・16384 は同一乱数列の先頭部分を共有するため、異なる n の推定値は独立ではありません。被覆率の反復実験は、各 n について連続する独立な疑似乱数標本群を 400 組生成します。これは理論的な被覆確率の**確率的な実測**であり、必ず 95% に一致するものではありません。

数値の独立基準：Black–Scholes 欧州 call 9.413403383853 円、割引 payoff の標準偏差は約 14.110881 円。連続平均 Asian（行使価格0、年率金利3%、配当利回り0、満期1年）の価格は 98.514888171639 円。離散右端平均 m=4,16,64 の理論価格との差は順に 0.369892619、0.092386569、0.023091231 円です。これらの数値は確率経路のシミュレーションを用いず数式から算出し、標本平均とは別に比較します。

各 Asian 観測点の GBM は対数増分を厳密に発生させています。そこで現れる m 依存の系統差は **平均という時間積分を有限和に置き換えることによるもの**であり、Euler–Maruyama 法などの SDE 経路離散化誤差ではありません。後者は U3-28 で扱います。

ブラウザ上の Python 実行は初回に Pyodide の読み込みが必要な場合があります。オフライン時はローカル Python を利用してください。
