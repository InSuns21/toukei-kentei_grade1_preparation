# U3-68 執行バックテスト・TCA 数値ラボ

- Python 3.10 以上、標準ライブラリのみ。外部マーケットデータや API キーは不要。
- ブラウザでは講義の `python-file-lab` を実行する。初回は Pyodide の読み込みに通信が必要。
- ローカル: `python assets/execution_tca.py --paths 240 --seed 20261119`
- ストレス: `python assets/execution_tca.py --paths 240 --seed 20261119 --stress`
- 内蔵チェック: `python assets/execution_tca.py --self-test`
- 自動テスト: `python -m unittest discover -s assets/tests -v`（講義ディレクトリから）
- 乱数生成は `random.Random(seed)`。統計指標は各 seed のサンプルを固定したときに再現可能。
- 実行計算量は、観測経路数 `M` に対しておよそ `O(M N + N Q^3)`（現行の小規模 AC 動的計画は `O(N Q^2)`、よって合計 `O(MN + NQ^2)`）、作業領域はおよそ `O(MN+NQ)`。N=4、Q=12、デフォルト M=240。
- 新規図は作らず、同一試行に対する「市場気配・注文・約定・残在庫・累積IS」を同期した表として出力する。文字情報だけでも意味が追えるため。
- 95%平均区間は独立経路に対する正規近似であり、有限標本保証、モデル選択バイアス、執行可能性の保証はない。
- 各経路は実確率 P 下の合成株価から生成するが、オプションの各時点の理論中値はリスク中立 Q による Black–Scholes 公式で評価する。
- 反実仮想の約定は、数量上限・固定半スプレッド・線形影響を使うシミュレーションにすぎない。実際の板・約定順・注文による反応は再現していない。
