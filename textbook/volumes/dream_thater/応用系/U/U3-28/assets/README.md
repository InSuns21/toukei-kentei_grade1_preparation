# U3-28 数値再現（厳密 GBM / Euler–Maruyama / Milstein）

Python 3.10 以上、標準ライブラリのみで実行可能。入力市場データ、外部API、追加パッケージは不要。

~~~sh
python textbook/volumes/dream_thater/応用系/U/U3-28/assets/gbm_schemes.py
python -m unittest discover -s textbook/volumes/dream_thater/応用系/U/U3-28/assets/tests -v
~~~

公開ページの Python パネルは同じ gbm_schemes.py を実行する。初回の Pyodide 起動にネットワークが必要な場合がある。

- 既定値は S0=100, mu=0.08, sigma=0.20, T=1。年単位、シード 20261114。m=4,16,64 ごとに独立な1800本の経路を生成する。各経路内では三手法が m 個の同一増分を共有する。刻み間のデータは別の乱数実現であり、単一路の単調減少は主張しない。
- 正規増分は N(0,h) を標準偏差 sqrt(h) で生成。時間計算量 O(mn)、生成した1経路の増分 O(m)、平方誤差などの配列 O(n)。
- 厳密GBMとの強誤差は同一路終端値の差の二乗を経路間平均する。平均二乗誤差（Mean Squared Error; MSE）推定の標準誤差も出す（RMSE の標準誤差ではない）。符号付き差の標本平均は、試験関数 phi(s)=s に限った弱誤差を推定する。
- 独立の検査基準：正規分布の指数モーメントで導いた有限刻みの厳密 MSE と、平均偏り S0((1+mu*h)^m - exp(mu*T))。テストは標本の揺れに合わせて MSE・符号付き平均差の標準誤差の6倍を許容する。特定の乱数実現の桁一致は要求しない。
- 付属 SVG は m=4,8,16,32,64 で**厳密な有限刻みMSE式**の平方根を計算して描いた理論線であり、標本実測ではない。縦軸は円単位の対数目盛。実測行は標本ゆらぎを含み理論線上に一致しない。
- 丸め誤差：大きな m では理論 MSE 式が近い大数の差になるため桁落ちすることがある。非常に小さい真の MSE に対する機械精度の保証としてこの数式を使用しない。`exact_terminal_mse` は丸めによる微小な負値のみ0へ補正する。
