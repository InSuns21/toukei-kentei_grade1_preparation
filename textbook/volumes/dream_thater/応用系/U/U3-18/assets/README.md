Python 3.10 以降、標準ライブラリのみ、外部データ・追加パッケージ不要です。リポジトリのルートで実行します。

    python textbook/volumes/dream_thater/応用系/U/U3-18/assets/black_scholes_check.py

    python -m unittest discover -s textbook/volumes/dream_thater/応用系/U/U3-18/assets/tests -p "test_*.py" -v

ブラウザの講義パネルは同じ \`black_scholes_check.py\` を Python/Pyodide で実行します。既定値は \`s=K=100\` 円、\`r=0.03\` 年$^{-1}$、\`sigma=0.2\` 年$^{-1/2}$、\`tau=1\` 年です。必須条件は \`s,k,sigma,tau>0\` と有限パラメータです。CRR ではさらに \`d<R<u\` が必要で、成り立たなければ刻み数を増やします。

## 誤差の分離

- **閉形式**：\`math.erfc\` で $\Phi$ を計算する解析値。Oracle は $C=9.413403383853016$ 円、$P=6.457956738703842$ 円です。
- **数値積分**：行使境界 $z=-d_2$ で区間を分ける Simpson 法（4096等分）。被積分関数の折れ目は積分区間の内部に置きません。切断は行使境界から10正規標準偏差以上の位置で、上記既定値では尾積分の切捨て誤差が約 $10^{-20}$ 円以下、離散化誤差は $O(h^4)$（分割後の滑らかな積分）。テストでは解析値との絶対誤差を $2\cdot10^{-6}$ 円以内に設定します。過度のパラメータでの指数オーバーフローを抑える一般用途の数値ライブラリではありません。
- **CRR 木**：$N=25,100,400$ の時刻後退評価。時間離散化・格子への行使価格の位置に由来する偏りは残り、$N$ を増やしても単調に誤差減少するとは限りません。演算回数 $O(N^2)$、配列メモリ $O(N)$。
- **独立検算**：call/put それぞれの正規積分、put–call parity 残差、価格範囲、密度恒等式、デルタの中心差分、ゼロ変動率極限をテストします。乱数由来の標本誤差はありません。

このモデルは欧州型・無配当・定数係数を前提とした教材用の合成例であり、実市場価格の推奨ではありません。
