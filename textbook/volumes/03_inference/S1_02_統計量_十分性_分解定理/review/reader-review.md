# S1-02 読者粒度レビュー

## 判定

**PASS**。十分統計量を「分解定理の形を覚える章」にせず、統計量の定義 → 条件付き分布による十分性 → 分解定理 → 代表分布 → 最小十分性、の順で意味から追える構成になっている。

## 確認事項

### 導入と説明順

- 冒頭で「母数情報を失わず標本を圧縮する」という十分性の役割を示している。
- 統計量の定義を十分統計量より先に置き、未知母数を含む式は統計量ではないことを明示している。
- 標本全体も形式的には統計量・十分統計量になり得るため、十分性の本質が低次元への情報圧縮にあることを説明している。
- 条件付き分布の定義を先に示してからネイマンの分解定理へ進むため、公式の意味を後付けせずに読める。

### 代表例の選び方

- ベルヌーイ分布では「成功回数が同じなら成功順序は母数情報を持たない」という離散的な直感を使っている。
- ポアソン分布・指数分布では積を整理して標本和が現れる標準パターンを反復している。
- 一様分布では、密度係数だけでなく支持領域の指示関数が母数情報を持つことを独立節で強調している。
- 正規分布では「分散既知」と「平均・分散とも未知」を分け、必要な十分統計量の次元が変わることを示している。

### 誤解しやすい点への配慮

- 十分統計量だから不偏・一致・効率的とは限らないことを明示している。
- 一対一変換なら十分性を保つ一方、さらに粗い変換は母数情報を落とし得ることをベルヌーイ標本の具体的な条件付き確率で示している。
- $U(0,\theta)$ で支持領域の母数依存を落とす誤答を明示的に防いでいる。
- 連続型の条件付き分布には一点への条件づけの注意があることを短く示し、必要以上に測度論へ脱線していない。

### 次章への接続

- 指数型分布族を「なぜ和が十分統計量として繰り返し現れるのか」を説明する位置に置いている。
- 同じ同時密度を、次章では観測値を固定して母数の関数として読むと予告し、尤度・最尤推定への切り替えが明確。
- 完備性、Rao--Blackwell化、レーマン・シェッフェの定理はこの章で主題化せず、推定量評価の後続章へ残しているため過積載になっていない。

### 演習

- Level A 4題は統計量の定義、ベルヌーイ、ポアソン、一様分布の基本判定を扱う。
- Level B 4題は指数分布を条件付き密度から確認し、正規分布の1母数・2母数ケース、一対一でない変換による情報損失を扱う。
- Level C 4題は最小十分性の尤度比判定、ガンマ分布、指数型分布族を扱う。
- Level D 1題は同じ標本平均を持つ2標本点の反例から、平均だけでは正規分布の平均・分散に十分でないことを示し、その後に2次元最小十分統計量まで組み立てる。
- 30分ドリルは幾何分布で分解定理・最小十分性・不十分な圧縮を一続きに確認する。
- 各通常演習は問題直後に詳細解答・本番答案・20点採点基準を置いている。

## 結論

初見読者が「なぜ標本和や最大値だけ残せばよいのか」を、条件付き分布と同時分布の分解の両方から理解できる。fatal / major / minor = 0 / 0 / 0。
