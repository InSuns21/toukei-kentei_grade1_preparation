# I2-02 数理査読

## 判定

- fatal: 0
- major: 0
- minor: 0

## 確認項目

### 1. 信頼区間・被覆確率・信頼係数

- 母数は固定、区間端点が標本に依存する確率変数という頻度論的立場を明示した。
- 被覆確率を `P_θ(L(X)≤θ≤U(X))` と定義した。
- 信頼係数は `inf_θ C(θ)≥1-α` という保証水準として定義し、「各θで正確に1-α」となる場合と区別した。
- 観測後の固定区間に95%の母数確率を付与しないことを明記した。

### 2. ピボット量による構成

- 未知母数に分布が依存しない `Q(X,θ)` の確率不等式を母数について反転する一般原理を記載した。
- 正規平均既知分散、t、カイ二乗、指数分布、一様分布で同じ原理を反復している。

### 3. 正規母平均

- 既知分散: `√n( X̄-μ )/σ ~ N(0,1)` から正規分位点区間を導出した。
- 未知分散: 正規母集団の下で `√n( X̄-μ )/S ~ t_{n-1}` を使い、有限標本で厳密なt区間を導出した。
- 自由度 `n-1` と `S²` の定義は整合している。

### 4. 正規母分散

- `(n-1)S²/σ² ~ χ²_{n-1}` を使用した。
- 逆数を取るため分位点の順序が反転することを式で説明した。
- 標準偏差の区間は平方根の単調増加性により正しく移送している。

### 5. 片側区間

- 両側では各裾 `α/2`、片側では片側に `α` を置くことを明示した。
- 上側・下側信頼限界の符号を確認した。

### 6. 漸近区間

- I2-01 の漸近正規性からワルド型区間を構成した。
- 有限標本で名目被覆率を厳密には保証しないことを明示した。
- 二項比率では `p̂=0,1` で幅が0になる問題を含め、境界付近の不安定性を過小評価していない。

### 7. 単調変換

- 単調増加では `[g(L),g(U)]`、単調減少では `[g(U),g(L)]` とした。
- 指数分布の平均寿命 `1/λ` で端点反転を確認した。
- 元の区間の直接変換とデルタ法による局所近似を区別した。

### 8. 指数分布

- 率母数表示で `S~Gamma(n, rate=λ)`、`2λS~χ²_{2n}` を使用した。
- 厳密区間 `[χ²_{2n,α/2}/(2S), χ²_{2n,1-α/2}/(2S)]` は正しい。
- 最尤推定量 `n/S` のワルド型標準誤差 `λ̂/√n` と整合する。

### 9. 一様分布

- `M=X_(n)` に対し `P(M≤m)=(m/θ)^n` を使用した。
- `R=M/θ` の分布関数 `r^n` はθに依存しないためピボット量である。
- `P(a≤R≤b)=b^n-a^n` の反転から `[M/b,M/a]` を得ている。
- `b=1, a=α^{1/n}` では `[M,Mα^{-1/n}]` となり、被覆確率は正確に `1-α`。

## 結論

公式範囲の定義、有限標本の厳密構成、大標本近似、非正則例まで数理的な未解消事項なし。
