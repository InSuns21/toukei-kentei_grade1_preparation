# S1-03 読者粒度レビュー

## 判定

**PASS**。統計検定1級の独習者が、抽出法の名称だけでなく「何が無作為か」「何を推定するか」「設計によって分散がどう変わるか」を途中式から追える構成になっている。

## 確認事項

### 導入と説明順

- 冒頭で、研究の種類・標本調査法・標本サイズ設計を一つの章で扱う理由を示している。
- 研究設計 → 有限母集団の考え方 → 単純無作為抽出 → 層化抽出 → 二段階抽出 → 一般の不等確率抽出 → 比推定 → 標本サイズ → 設計効果、の順で一般化している。
- 「有限母集団の値を固定し、誰が標本へ入るかをランダムと考える」という標本抽出論独特の見方を、公式より先に説明している。

### 用語の導入

- 実験研究・観察研究・調査を最初に具体例で区別している。
- 無作為割付と無作為抽出を表で対比し、因果比較と母集団への一般化という役割の違いを説明している。
- 目標母集団・抽出台帳・標本、包含確率、一次抽出単位、有限母集団補正、設計効果などは初出時に意味を説明している。
- 公式範囲の「完全無作為抽出」という表現を残しつつ、数式では定義が明確な単純無作為抽出（非復元）を基本モデルとしているため、語だけが独り歩きしない。

### 導出の再現性

- 標本平均の不偏性は $I_i$ の期待値から1行ずつ導出している。
- 有限母集団補正は結論だけを暗記させず、異なる抽出指示変数が負に相関する理由から分散式まで導いている。
- 層化抽出は重み付き平均の意味から分散式へ進み、比例配分とNeyman配分を数値例で比較している。
- 二段階抽出は各段階の抽出率の逆数を掛ける流れを示し、Horvitz--Thompson推定量への橋渡しになっている。
- 標本サイズ式は完成公式だけでなく、許容誤差の半幅条件から代数的に解いている。

### 誤解しやすい点への配慮

- 「無作為割付した標本だから母集団代表性もある」という誤解を避けている。
- 「大標本なら偏りも消える」という誤解を避け、標本誤差とカバレッジ誤差・無回答バイアスを分離している。
- 比推定量について、補助情報を使う利点だけでなく有限標本では一般に厳密不偏でないことを明示している。
- 回収率補正は必要回答数を確保するための計画であり、無回答バイアスを自動的に除くものではないと説明している。

### 演習

- Level A 4題は用語判定、有限母集団補正、標本サイズ、逆確率重みを単独で確認する。
- Level B 4題は単純無作為抽出の導出、層化分散、Neyman配分、二段階抽出を扱う。
- Level C 4題は標本サイズと回収率、比推定、Horvitz--Thompson一般導出、設計効果を扱う。
- Level D 1題は層化配分から推定・分散・回収率・非標本誤差までを統合している。
- 30分ドリルは主要公式を横断し、100点形式で採点できる。
- 各通常演習は問題直後に詳細解答・本番答案・20点採点基準を配置している。

## 結論

初見読者が「抽出法の名前を覚える章」ではなく、「標本設計に応じて推定量と分散を組み立てる章」として読み進められる。fatal / major / minor = 0 / 0 / 0。
