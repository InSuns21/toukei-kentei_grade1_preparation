# I4-02 読者粒度レビュー

## 判定

**PASS**。fatal 0 / major 0 / minor 0。

## 確認した観点

### 導入・説明順

- 「欠測・打ち切り・切断は値がないように見えても尤度への寄与が違う」という具体的な入口から始まり、用語だけを先に列挙していない。
- 欠測機構の分類後に観測データ尤度の周辺化を置き、その後で「混合分布では対数の中に和が残る」という困難を示してから期待値最大化法へ入るため、アルゴリズムが突然出てこない。
- E-step / M-step は一般式の直後に2成分正規混合の責任度・重み付き平均へ落としており、抽象式と手計算の対応が追える。

### 初出概念

- 完全無作為欠測・無作為欠測・非無作為欠測は条件付き確率の式と具体例を併記している。
- 「無作為欠測」は全員同じ確率で欠測する意味ではなく、観測済み変数への依存を許すことを明記している。
- 観測データ尤度は「見えない値を適当に埋める」のではなく、和・積分で消去する操作として導入している。
- 責任度は「各観測を各成分へ何割割り当てるか」という重みとして説明し、専門語だけで進めていない。
- 尤度単調性は KL ダイバージェンスを用いた発展項目だが、先に具体的な反復計算を終えてから配置されているため説明順は適切である。

### 不完全データの区別

- 欠測・打ち切り・切断を表で比較し、観測単位の存在と値について残る情報を分離している。
- 指数寿命の右打ち切りでは、未故障個体の寄与が密度ではなく生存確率であることを具体的に計算させている。
- 左切断では条件付き密度を示し、標本選択を無視した尤度との差が明確である。

### 演習

- A 4題 / B 4題 / C 4題 / D 1題で、定義判定 → 周辺化 → E-step/M-step → 尤度単調性・診断へ段階化されている。
- 問題文は必要な分布・母数・数値近似を各問題内に再掲しており、章頭を読み返さないと着手できない依存を避けている。
- 通常演習は詳細解答・本番答案・20点満点の採点基準を持つ。
- D問題は25〜30分で、観測尤度、E-step、M-step、単調性、初期値依存を一つの答案へ接続する本番型になっている。

### 単一代入

- 平均値で埋める方法を単に「悪い」と断定せず、偏差平方和は増えないのに分母だけ増えるため分散が縮むことを式で示している。
- 補完値の不確実性を無視することが問題だと説明しており、手順暗記で終わっていない。
