# P4-02 確率変数の収束・大数則・中心極限定理

本章は、標本平均がなぜ安定し、なぜ正規近似が使えるかを、仮定と式を省略せずに学ぶ。確率収束、概収束、分布収束を区別し、大数の法則（LLN）と中心極限定理（CLT）を同一の標本モデルでつなぐ。

章内のLevel Cは一つのモデルを4〜6小問で掘り下げ、最後に推定・近似確率へ接続する。過去問本文は転載せず、09で公式問題集への導線だけを示す。

分布の台・母数・確率質量関数・確率密度関数と略語は [分布・略語の共通索引](../../../../references/distribution-notation-guide.md) でも確認できる。
