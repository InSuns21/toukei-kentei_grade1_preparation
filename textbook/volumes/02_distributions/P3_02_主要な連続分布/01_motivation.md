# 動機と試験での位置づけ

連続分布は推測統計の部品です。正規分布は標本分布と漸近理論、Gamma・Beta分布は尤度とBayes推測、指数・Weibull分布は信頼性、対数正規分布は正値データ、Logistic分布は二値回帰へつながります。Cauchy分布は「密度が対称でも平均が存在するとは限らない」という反例です。

統計検定1級では、分布名を答えるだけでは部分点が小さくなります。本番答案では次の順序を守ります。

1. 台とパラメータ化を宣言する。
2. 正規化定数または変数変換を示す。
3. 求める確率・モーメント・ハザードを計算する。
4. 積分の収束条件と母関数の存在範囲を書く。

特にGamma分布は本章で率パラメータ$\beta$を採用します。尺度パラメータ表記との取り違えを防ぐため、答案冒頭で密度を一度書きます。
