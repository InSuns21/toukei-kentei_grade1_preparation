# P3-02 主要な連続分布

各分布の台・母数・確率密度関数は`02_definitions.md`、`03_theorems.md`、`06_exercises.md`冒頭に再掲します。共通索引は`references/distribution-notation-guide.md`です。

## この章で解けるようになる問題

密度の形を暗記するだけでなく、台、パラメータ化、正規化、平均分散、母関数の存在範囲、生存関数・ハザードを一つの答案にまとめます。25分でGamma・Beta積分、対数変換、寿命分布を処理し、分布を選ぶ根拠まで書けることを目標にします。

## 前提知識チェック

1. P2-01: 密度を積分して確率と累積分布関数を求める。
2. P2-02: $E[X^r]$ とモーメント母関数の定義を使う。
3. F0-01: 置換積分と広義積分の収束を判定する。
4. P1-02: 条件付き確率と無記憶性を式で示す。
5. P3-01: 離散分布との生成機構の違いを説明する。

## 学習目標

- 9分布の台・パラメータ・密度・平均・分散を再現する。
- Gamma関数とBeta関数で正規化・モーメントを計算する。
- 正規標準化、指数の無記憶性、Weibullのハザードを使う。
- Cauchyでは平均が存在せず、対数正規では正のモーメント母関数が発散することを見抜く。
- Level Cを30分以内に提出答案へ閉じる。

合格基準はLevel B 85%以上、Level C 70%以上、30分ドリル70点以上です。
