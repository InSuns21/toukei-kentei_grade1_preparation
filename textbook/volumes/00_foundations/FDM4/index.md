# FDM4 差分法 IV：移流拡散と風上化

FDM1–FDM3 では、熱方程式を題材に

\[
\text{離散化}
\longrightarrow
\text{安定性}
\longrightarrow
\text{整合性}
\longrightarrow
\text{収束}
\]

という数値 PDE の基本線を作りました。

熱方程式では、空間差分の中心にあるのは拡散です。ところが流れに乗って量が運ばれる **移流** が入ると、事情が変わります。連続問題の解は滑らかでも、中心差分で作った離散解が格子点ごとに符号を変えることがあります。

この章の中心問いは、

> **移流が拡散より強いとき、なぜ中心差分は振動し、風上差分はそれを抑えられるのか。**

です。

直接の前提は [FDM3 の離散最大値原理と収束の考え方](../FDM3/index.md#thm-fdm3-discrete-maximum)です。

> **この章の停止線**  
> 本章では一次元・定係数の定常移流拡散問題を使い、中心差分、風上差分、格子 Péclet 数、非物理振動、数値拡散までを閉じます。SUPG などの有限要素安定化は後続 FEM7 で扱い、ここへ逆輸入しません。

---

## 0. 移流と拡散が競合すると何が起こるか

まず、区間 \(0<x<L\) で

\[
-\kappa u''(x)+a u'(x)=f(x),
\qquad
\kappa>0,
\]

を考えます。

- \(-\kappa u''\) は拡散を表す。
- \(a u'\) は速度 \(a\) による移流を表す。

\(\kappa\) が大きければ拡散が強く、解は滑らかになりやすいです。逆に \(|a|/\kappa\) が大きいと、移流方向に情報が運ばれ、境界近くに急な変化が集中することがあります。

<a id="def-fdm4-advection-diffusion"></a>
<!-- formal-statement-start -->
### 定義（一次元定常移流拡散問題）

定数

\[
\kappa>0,
\qquad
a\in\mathbb R
\]

と関数 \(f\) に対し、

\[
\boxed{
-\kappa u''+a u'=f
\qquad
(0<x<L)
}
\]

に Dirichlet 境界条件

\[
\boxed{
u(0)=g_0,
\qquad
u(L)=g_L
}
\]

を課した境界値問題を **一次元定常移流拡散問題**という。
<!-- formal-statement-end -->

<!-- definition-example-start: def-fdm4-advection-diffusion -->
### 例：指数型の境界層を直接解く

**定義の確認**として、

\[
f=0,
\qquad
a>0,
\qquad
u(0)=0,
\qquad
u(L)=1
\]

を考えます。

方程式は

\[
-\kappa u''+a u'=0.
\]

\(v=u'\) と置くと

\[
-\kappa v'+av=0,
\]

したがって

\[
v'=\frac{a}{\kappa}v.
\]

よって

\[
v(x)=C e^{ax/\kappa}.
\]

積分して

\[
u(x)=A+B e^{ax/\kappa}.
\]

境界条件から

\[
A+B=0,
\]

\[
A+B e^{aL/\kappa}=1.
\]

従って

\[
B=\frac1{e^{aL/\kappa}-1},
\qquad
A=-B,
\]

なので

\[
\boxed{
u(x)
=
\frac{e^{ax/\kappa}-1}
{e^{aL/\kappa}-1}
}.
\]

\(aL/\kappa\) が大きいと、\(x=L\) の近くまで \(u\) は小さく、右端付近で急に 1 へ上がります。

移流方向が右向き \(a>0\) なので、急変は流出側 \(x=L\) に集まっています。
<!-- definition-example-end -->

この急な変化を粗い格子で捉えようとすると、離散化の性質が前面に出ます。

## 1. 一次微分を中心から見るか、風上から見るか

格子を

\[
x_j=jh,
\qquad
h=\frac LJ,
\qquad
j=0,\ldots,J
\]

とします。

<a id="def-fdm4-first-differences"></a>
<!-- formal-statement-start -->
### 定義（中心一次差分と風上一次差分）

格子関数 \(V_j\) に対し、内部格子点 \(x_j\) で

\[
\boxed{
D_0V_j
=
\frac{V_{j+1}-V_{j-1}}{2h}
}
\]

を **中心一次差分**という。

また移流速度 \(a\neq0\) に対し、

\[
\boxed{
D_{\mathrm{up}}V_j
=
\begin{cases}
\dfrac{V_j-V_{j-1}}{h},
& a>0,\\[1.2ex]
\dfrac{V_{j+1}-V_j}{h},
& a<0
\end{cases}
}
\]

を **風上一次差分**という。
<!-- formal-statement-end -->

「風上」とは、流れが来る側を見るという意味です。

- \(a>0\)：情報は左から右へ流れるので左側 \(j-1\) を使う。
- \(a<0\)：情報は右から左へ流れるので右側 \(j+1\) を使う。

<!-- definition-example-start: def-fdm4-first-differences -->
### 例：\(u(x)=x^2\) で両者を比べる

\(a>0\) とします。

厳密微分は

\[
u'(x_j)=2x_j.
\]

中心一次差分は

\[
\begin{aligned}
D_0u_j
&=
\frac{(x_j+h)^2-(x_j-h)^2}{2h}\\
&=
\frac{4x_jh}{2h}\\
&=
2x_j.
\end{aligned}
\]

したがって二次関数では厳密です。

一方、風上一次差分は

\[
\begin{aligned}
D_{\mathrm{up}}u_j
&=
\frac{x_j^2-(x_j-h)^2}{h}\\
&=
\frac{2x_jh-h^2}{h}\\
&=
2x_j-h.
\end{aligned}
\]

よって

\[
\boxed{
D_{\mathrm{up}}u_j-u'(x_j)=-h
}.
\]

中心差分は左右を対称に使うため一次の Taylor 誤差が相殺されます。風上差分は片側だけを見るので、その相殺が起こりません。
<!-- definition-example-end -->

Taylor 展開すると、滑らかな \(u\) に対して

\[
\boxed{
D_0u_j
=
u'(x_j)
+
\frac{h^2}{6}u^{(3)}(x_j)
+
O(h^4)
}
\]

です。

一方 \(a>0\) の風上差分では

\[
\boxed{
D_{\mathrm{up}}u_j
=
u'(x_j)
-
\frac h2u''(x_j)
+
\frac{h^2}{6}u^{(3)}(x_j)
+
O(h^3)
}.
\]

したがって精度だけを見ると、

- 中心一次差分：二次精度
- 風上一次差分：一次精度

です。

ここだけを見ると中心差分の方が優れているように見えます。しかし移流卓越では「高次精度」だけでは十分ではありません。

## 2. 格子 Péclet 数が移流と拡散の比を測る

連続問題の係数 \(a,\kappa\) だけではなく、格子幅 \(h\) も含めて競合の強さを測ります。

<a id="def-fdm4-grid-peclet"></a>
<!-- formal-statement-start -->
### 定義（格子 Péclet 数）

一次元定常移流拡散問題に対して

\[
\boxed{
Pe_h
=
\frac{|a|h}{2\kappa}
}
\]

を **格子 Péclet 数**という。
<!-- formal-statement-end -->

文献によっては因子 \(2\) を入れず

\[
\frac{|a|h}{\kappa}
\]

を格子 Péclet 数と呼ぶこともあります。本章では、中心差分の係数符号が

\[
Pe_h=1
\]

でちょうど変わるように上の規約を採用します。

<!-- definition-example-start: def-fdm4-grid-peclet -->
### 例：格子を半分にすると \(Pe_h\) も半分になる

\[
a=4,
\qquad
\kappa=1,
\qquad
h=1
\]

なら

\[
Pe_h
=
\frac{4\cdot1}{2\cdot1}
=
2.
\]

格子幅を

\[
h=\frac12
\]

へ半分にすると

\[
Pe_h
=
\frac{4\cdot(1/2)}{2}
=
1.
\]

さらに

\[
h=\frac14
\]

なら

\[
Pe_h=\frac12.
\]

同じ PDE でも、格子を細かくすると格子スケールでは拡散の相対的な影響が強くなります。
<!-- definition-example-end -->

## 3. 中心差分で離散化する

以後、まず

\[
a>0
\]

とします。\(a<0\) は左右を反転すれば同じ議論になります。

二階微分には FDM1 の中心二階差分

\[
\delta_{xx}U_j
=
\frac{U_{j+1}-2U_j+U_{j-1}}{h^2}
\]

を使います。

<a id="def-fdm4-centered-scheme"></a>
<!-- formal-statement-start -->
### 定義（中心差分型移流拡散スキーム）

一次元定常移流拡散問題

\[
-\kappa u''+a u'=f,
\qquad
a>0
\]

に対し、

\[
\boxed{
-\kappa
\frac{U_{j+1}-2U_j+U_{j-1}}{h^2}
+
a
\frac{U_{j+1}-U_{j-1}}{2h}
=
f_j
}
\]

を **中心差分型移流拡散スキーム**という。
<!-- formal-statement-end -->

\(Pe_h=ah/(2\kappa)\) と置き、両辺へ \(h^2/\kappa\) を掛けると

\[
\boxed{
-(1+Pe_h)U_{j-1}
+
2U_j
-
(1-Pe_h)U_{j+1}
=
\frac{h^2}{\kappa}f_j
}.
\]

ここが本章の最重要式の一つです。

左隣の係数に対応する重みは

\[
1+Pe_h>0,
\]

右隣の係数に対応する重みは

\[
1-Pe_h.
\]

したがって

\[
Pe_h\le1
\]

なら両方が非負ですが、

\[
Pe_h>1
\]

では右隣の重みが負になります。

この符号変化が、中心差分の非物理振動と直結します。

## 4. \(Pe_h\le1\) なら中心差分は最大値原理を保つ

FDM3 では FTCS の係数が凸結合になると最大値原理が得られました。

ここでも同じ「係数の符号」が働きます。

<a id="thm-fdm4-centered-maximum"></a>
<!-- formal-statement-start -->
### 定理（中心差分型移流拡散スキームの離散最大値原理）

\[
a>0,
\qquad
\kappa>0,
\qquad
Pe_h=\frac{ah}{2\kappa}\le1
\]

とする。

中心差分型移流拡散スキーム

\[
-(1+Pe_h)U_{j-1}
+
2U_j
-
(1-Pe_h)U_{j+1}
=
\frac{h^2}{\kappa}f_j
\]

で

\[
f_j\ge0,
\qquad
U_0\ge0,
\qquad
U_J\ge0
\]

が成り立つなら、

\[
\boxed{
U_j\ge0
\qquad
(j=0,\ldots,J)
}
\]

である。

特に、同じ境界値を持つ離散問題の解は一意である。
<!-- formal-statement-end -->

### 証明の見取り図

もし内部に負の最小値があるとします。

\(Pe_h\le1\) なら左右隣接点へ掛かる二つの重みは非負です。最小点では

\[
U_j-U_{j-1}\le0,
\qquad
U_j-U_{j+1}\le0
\]

なので離散作用素は非正になります。

一方、右辺は非負です。等号しか残らない場合も、最小値が左隣へ伝播して最終的に非負境界へ到達するため矛盾します。

<!-- proof-start -->
### 証明

\[
P=Pe_h
\]

と略記します。

反対に、ある内部格子点で負の最小値

\[
m<0
\]

を取ると仮定します。

その最小点を \(j_*\) とすると

\[
U_{j_*}=m,
\]

\[
U_{j_*-1}\ge m,
\qquad
U_{j_*+1}\ge m.
\]

中心差分作用素の左辺は

\[
\begin{aligned}
&-(1+P)U_{j_*-1}
+
2U_{j_*}
-
(1-P)U_{j_*+1}\\
&=
(1+P)(U_{j_*}-U_{j_*-1})
+
(1-P)(U_{j_*}-U_{j_*+1}).
\end{aligned}
\]

\(P\le1\) だから

\[
1+P>0,
\qquad
1-P\ge0.
\]

また最小点なので

\[
U_{j_*}-U_{j_*-1}\le0,
\qquad
U_{j_*}-U_{j_*+1}\le0.
\]

従って

\[
-(1+P)U_{j_*-1}
+
2U_{j_*}
-
(1-P)U_{j_*+1}
\le0.
\]

しかし差分方程式の右辺は

\[
\frac{h^2}{\kappa}f_{j_*}\ge0.
\]

したがって両辺が一致するには

\[
f_{j_*}=0
\]

かつ、正の係数 \(1+P\) に掛かる項が0でなければなりません。

よって

\[
U_{j_*-1}=U_{j_*}=m.
\]

同じ議論を \(j_*-1\) へ繰り返すと

\[
U_{j_*-2}=m,
\]

さらに繰り返して

\[
U_0=m<0
\]

を得ます。

これは仮定

\[
U_0\ge0
\]

に矛盾します。

従って内部に負の最小値は存在せず、

\[
U_j\ge0.
\]

一意性については、同じ境界値を持つ二つの解 \(U,V\) の差

\[
W=U-V
\]

を考えます。

\(W\) は

\[
f_j=0,
\qquad
W_0=W_J=0
\]

の斉次問題を満たします。

上の結果を \(W\) に適用すると

\[
W_j\ge0.
\]

さらに \(-W\) に適用すると

\[
-W_j\ge0,
\]

従って

\[
W_j=0.
\]

ゆえに

\[
U=V.
\]
<!-- proof-end -->

### どこで \(Pe_h\le1\) を使ったか

証明で必要だったのは

\[
1-Pe_h\ge0
\]

です。

つまり \(Pe_h>1\) になると、右側格子点の重みが負になり、最小値原理の証明機構そのものが壊れます。

## 5. \(Pe_h>1\) では中心差分解が交互振動する

証明が使えなくなるだけではありません。

実際に格子解が振動します。

<a id="prop-fdm4-centered-oscillation"></a>
<!-- formal-statement-start -->
### 命題（移流卓越時の中心差分解の交互振動）

\[
a>0,
\qquad
f=0,
\qquad
U_0=0,
\qquad
U_J=1
\]

とし、

\[
P=Pe_h>1
\]

とする。

中心差分型移流拡散スキームの内部点方程式は

\[
-(1+P)U_{j-1}
+
2U_j
-
(1-P)U_{j+1}
=
0
\]

である。

\[
\boxed{
q=\frac{1+P}{1-P}
}
\]

と置くと \(q<-1\) であり、離散解は

\[
\boxed{
U_j
=
\frac{q^j-1}{q^J-1}
}
\]

と書ける。

特に \(J\) が偶数なら、奇数番目の内部格子点で

\[
U_j<0
\]

となり、連続解 \(0<u(x)<1\) には存在しない交互振動が現れる。
<!-- formal-statement-end -->

### 証明の見取り図

定係数二階漸化式なので

\[
U_j=\lambda^j
\]

を代入して特性根を求めます。

二つの根は

\[
1,
\qquad
q=\frac{1+P}{1-P}.
\]

\(P>1\) では \(q<0\) なので、\(q^j\) が格子点ごとに符号を変えます。

<!-- proof-start -->
### 証明

\[
U_j=\lambda^j
\]

を斉次差分方程式へ代入すると

\[
-(1+P)\lambda^{j-1}
+
2\lambda^j
-
(1-P)\lambda^{j+1}
=
0.
\]

\(\lambda^{j-1}\neq0\) として割ると

\[
-(1+P)
+
2\lambda
-
(1-P)\lambda^2
=
0.
\]

従って

\[
(1-P)\lambda^2
-
2\lambda
+
(1+P)
=
0.
\]

\(\lambda=1\) は根です。

もう一つの根は根の積から

\[
\lambda_2
=
\frac{1+P}{1-P}
=
q.
\]

従って一般解は

\[
U_j=A+Bq^j.
\]

境界条件 \(U_0=0\) から

\[
A+B=0,
\qquad
A=-B.
\]

さらに \(U_J=1\) から

\[
-B+Bq^J=1,
\]

\[
B(q^J-1)=1.
\]

従って

\[
B=\frac1{q^J-1},
\]

ゆえに

\[
U_j
=
\frac{q^j-1}{q^J-1}.
\]

\(P>1\) なら

\[
1-P<0,
\qquad
1+P>0,
\]

なので

\[
q<0.
\]

さらに

\[
|q|
=
\frac{1+P}{P-1}
>1.
\]

\(J\) が偶数なら

\[
q^J-1>0.
\]

奇数 \(j\) では

\[
q^j<0
\]

だから

\[
q^j-1<0.
\]

従って

\[
U_j<0.
\]

連続解は

\[
u(x)
=
\frac{e^{ax/\kappa}-1}
{e^{aL/\kappa}-1}
\]

であり、

\[
0<u(x)<1
\qquad
(0<x<L)
\]

です。

したがって負の格子値は連続問題の挙動ではなく、離散化が作った非物理振動です。
<!-- proof-end -->

### 例：\(Pe_h=2,\ J=4\)

\[
P=2
\]

なら

\[
q
=
\frac{1+2}{1-2}
=
-3.
\]

従って

\[
U_j
=
\frac{(-3)^j-1}{(-3)^4-1}
=
\frac{(-3)^j-1}{80}.
\]

各点で

\[
U_0=0,
\]

\[
U_1
=
\frac{-3-1}{80}
=
-\frac1{20}
=
-0.05,
\]

\[
U_2
=
\frac{9-1}{80}
=
0.1,
\]

\[
U_3
=
\frac{-27-1}{80}
=
-0.35,
\]

\[
U_4=1.
\]

つまり

\[
\boxed{
0,\ -0.05,\ 0.10,\ -0.35,\ 1
}
\]

です。

連続解は \(0\) と \(1\) の間を単調に変化するのに、中心差分解は負値を何度も作っています。

## 6. 風上差分で移流方向を離散化する

\(a>0\) なら移流は左から右へ進みます。

そこで

\[
u'(x_j)
\]

を左側から

\[
\frac{U_j-U_{j-1}}h
\]

で近似します。

<a id="def-fdm4-upwind-scheme"></a>
<!-- formal-statement-start -->
### 定義（風上差分型移流拡散スキーム）

\[
a>0
\]

の一次元定常移流拡散問題に対し、

\[
\boxed{
-\kappa
\frac{U_{j+1}-2U_j+U_{j-1}}{h^2}
+
a
\frac{U_j-U_{j-1}}h
=
f_j
}
\]

を **風上差分型移流拡散スキーム**という。

\(a<0\) では移流項に前進差分

\[
(U_{j+1}-U_j)/h
\]

を用いる。
<!-- formal-statement-end -->

\(a>0\) で

\[
\beta
=
\frac{ah}{\kappa}
=
2Pe_h
\]

と置きます。

両辺へ \(h^2/\kappa\) を掛けると

\[
\boxed{
-(1+\beta)U_{j-1}
+
(2+\beta)U_j
-
U_{j+1}
=
\frac{h^2}{\kappa}f_j
}.
\]

中心差分と違い、

\[
1+\beta>0,
\qquad
1>0
\]

はどれだけ \(\beta\) が大きくても符号を変えません。

## 7. 風上差分は任意の格子 Péclet 数で最大値原理を保つ

<a id="thm-fdm4-upwind-maximum"></a>
<!-- formal-statement-start -->
### 定理（風上差分型移流拡散スキームの離散最大値原理）

\[
a>0,
\qquad
\kappa>0
\]

とする。

風上差分型移流拡散スキーム

\[
-(1+\beta)U_{j-1}
+
(2+\beta)U_j
-
U_{j+1}
=
\frac{h^2}{\kappa}f_j,
\qquad
\beta=\frac{ah}{\kappa}\ge0
\]

で

\[
f_j\ge0,
\qquad
U_0\ge0,
\qquad
U_J\ge0
\]

なら、任意の \(h>0\)、すなわち任意の格子 Péclet 数に対して

\[
\boxed{
U_j\ge0
}
\]

が成り立つ。

特に離散問題の解は一意である。
<!-- formal-statement-end -->

### 証明の見取り図

中心差分の証明と同じ最小値論法を使います。

違いは、風上差分では

\[
1+\beta,
\qquad
1
\]

が常に正なので、\(Pe_h\le1\) のような条件が不要なことです。

<!-- proof-start -->
### 証明

内部に負の最小値

\[
U_{j_*}=m<0
\]

があると仮定します。

最小性から

\[
U_{j_*-1}\ge m,
\qquad
U_{j_*+1}\ge m.
\]

左辺は

\[
\begin{aligned}
&-(1+\beta)U_{j_*-1}
+
(2+\beta)U_{j_*}
-
U_{j_*+1}\\
&=
(1+\beta)(U_{j_*}-U_{j_*-1})
+
(U_{j_*}-U_{j_*+1}).
\end{aligned}
\]

二つの差はどちらも非正で、

\[
1+\beta>0
\]

なので

\[
-(1+\beta)U_{j_*-1}
+
(2+\beta)U_{j_*}
-
U_{j_*+1}
\le0.
\]

一方、

\[
\frac{h^2}{\kappa}f_{j_*}\ge0.
\]

よって等号しかあり得ず、

\[
U_{j_*-1}=U_{j_*}=m.
\]

これを左へ繰り返すと

\[
U_0=m<0
\]

となり、

\[
U_0\ge0
\]

に矛盾します。

従って

\[
U_j\ge0.
\]

一意性は中心差分の場合と同じく、二解の差 \(W\) と \(-W\) に最大値原理を適用して

\[
W=0
\]

を得ればよいです。
<!-- proof-end -->

### 例：\(Pe_h=2,\ J=4\) でも単調になる

中心差分で振動した同じ設定

\[
Pe_h=2
\]

を考えます。

このとき

\[
\beta=2Pe_h=4.
\]

斉次風上差分方程式は

\[
-5U_{j-1}+6U_j-U_{j+1}=0.
\]

特性方程式は

\[
\lambda^2-6\lambda+5=0,
\]

したがって根は

\[
1,
\qquad
5.
\]

境界条件

\[
U_0=0,
\qquad
U_4=1
\]

から

\[
\boxed{
U_j
=
\frac{5^j-1}{5^4-1}
=
\frac{5^j-1}{624}
}.
\]

従って

\[
U_1=\frac4{624}\approx0.00641,
\]

\[
U_2=\frac{24}{624}\approx0.03846,
\]

\[
U_3=\frac{124}{624}\approx0.19872,
\]

\[
U_4=1.
\]

すべて

\[
0\le U_j\le1
\]

で、単調増加しています。

## 8. 風上化の代償は数値拡散である

風上差分は振動を抑えます。

しかし無料ではありません。

片側差分の Taylor 展開を見ると、元の PDE にはない拡散が追加されていることが分かります。

<a id="def-fdm4-numerical-diffusion"></a>
<!-- formal-statement-start -->
### 定義（数値拡散）

離散化を Taylor 展開して連続方程式として読み替えたとき、元の PDE にはない正の拡散係数が主誤差として現れる現象を **数値拡散**という。

風上一次差分では、その先頭の追加拡散係数は

\[
\boxed{
\kappa_{\mathrm{num}}
=
\frac{|a|h}{2}
}
\]

である。
<!-- formal-statement-end -->

<!-- definition-example-start: def-fdm4-numerical-diffusion -->
### 例：格子を半分にすると数値拡散も半分になる

\[
|a|=4,
\qquad
h=0.1
\]

なら

\[
\kappa_{\mathrm{num}}
=
\frac{4\cdot0.1}{2}
=
0.2.
\]

格子幅を

\[
h=0.05
\]

へ半分にすると

\[
\kappa_{\mathrm{num}}
=
\frac{4\cdot0.05}{2}
=
0.1.
\]

風上差分の余分な拡散は格子細分化で0へ消えるため、元の微分方程式との整合性は保たれます。
<!-- definition-example-end -->

<a id="prop-fdm4-modified-equation"></a>
<!-- formal-statement-start -->
### 命題（風上差分の修正方程式と数値拡散）

十分滑らかな \(u\) に対し、風上一次差分は

\[
\boxed{
D_{\mathrm{up}}u
=
u_x
-
\operatorname{sgn}(a)
\frac h2u_{xx}
+
O(h^2)
}
\]

を満たす。

従って風上差分型移流拡散作用素は

\[
\boxed{
-\kappa \delta_{xx}u
+
aD_{\mathrm{up}}u
=
-
\left(
\kappa+\frac{|a|h}{2}
\right)u_{xx}
+
au_x
+
O(h^2)
}
\]

と書ける。

したがって風上化は、先頭次数では元の拡散係数 \(\kappa\) を

\[
\boxed{
\kappa_{\mathrm{eff}}
=
\kappa+\frac{|a|h}{2}
}
\]

へ増やしていると解釈できる。
<!-- formal-statement-end -->

### 証明の見取り図

移流方向に応じた片側 Taylor 展開を行います。

\(a>0\) なら後退差分、

\[
a<0
\]

なら前進差分です。

どちらの場合も、\(a\) を掛けた一次誤差が

\[
-\frac{|a|h}{2}u_{xx}
\]

になります。

<!-- proof-start -->
### 証明

まず \(a>0\) とします。

Taylor 展開より

\[

=

-

+
\frac{h^2}{2}u_{xx}(x)
-
\frac{h^3}{6}u_{xxx}(x)
+

\]

従って

\[
\begin{aligned}

&=
\frac{u(x)-u(x-h)}h\\
&=
u_x
-
\frac h2u_{xx}
+
\frac{h^2}{6}u_{xxx}
+

\end{aligned}
\]

一方 \(a<0\) では前進差分を使います。

\[

=

+

+

\frac{h^3}{6}u_{xxx}(x)
+

\]

より

\[
D_{\mathrm{up}}u
=

+
\frac h2u_{xx}
+
\frac{h^2}{6}u_{xxx}
+

\]

二つをまとめると

\[
D_{\mathrm{up}}u
=
u_x
-
\operatorname{sgn}(a)
\frac h2u_{xx}
+

\]

ここへ \(a\) を掛けると

-

+

\end{aligned}
\]

従って先頭の追加拡散係数は

\[
\frac{|a|h}{2}.
\]

## 9. 「高精度」対「単調性」というトレードオフ

ここまでを整理します。

中心差分は

\[
D_0u
=
u_x+O(h^2)
\]

なので、局所精度は高いです。

しかし移流卓越

\[
Pe_h>1
\]

では係数符号が崩れ、離散最大値原理を失って非物理振動を作ります。

風上差分は

\[
D_{\mathrm{up}}u
=
u_x+O(h)
\]

なので一次精度へ落ちます。

その代わり、

\[
\kappa_{\mathrm{eff}}
=
\kappa+\frac{|a|h}{2}
\]

という追加拡散により、離散解の単調性を保ちやすくなります。

実際、修正方程式の実効格子 Péclet 数を

\[
Pe_h^{\mathrm{eff}}
=
\frac{|a|h}{2\kappa_{\mathrm{eff}}}
\]

と置くと、

\[
Pe_h
=
\frac{|a|h}{2\kappa}
\]

より

\[
\boxed{
Pe_h^{\mathrm{eff}}
=
\frac{Pe_h}{1+Pe_h}
<1
}.
\]

つまり先頭次数の見方では、風上差分は「格子 Péclet 数が1を超えない程度まで拡散を足している」と解釈できます。

これは非常に有用な見方ですが、代償として境界層や鋭い勾配を必要以上にぼかすことがあります。

---

## 10. 格子細分化というもう一つの解決法

中心差分そのものを捨てなくても、

\[
Pe_h
=
\frac{|a|h}{2\kappa}
\le1
\]

となるまで格子を細かくすれば、中心差分の係数符号は回復します。

\[
h=\frac LJ
\]

なので条件は

\[
\frac{|a|L}{2\kappa J}
\le1.
\]

従って

\[
\boxed{
J
\ge
\frac{|a|L}{2\kappa}
}
\]

が一つの目安です。

物理的 Péclet 数

\[
Pe
=
\frac{|a|L}{\kappa}
\]

を使えば

\[
\boxed{
J\ge\frac{Pe}{2}
}
\]

です。

移流が非常に強いと、この条件を満たすために多数の格子点が必要になります。

そこで実務では、

- 格子を十分細かくする
- 風上化する
- 高次風上法・流束制限を使う
- 有限要素法なら SUPG などで安定化する

という方向へ進みます。

本章では最初の二つまでを数学的に閉じました。

この粗さでは中心差分に非物理振動が現れる可能性があります。

<a id="ex-fdm4-b03"></a>
### FDM4-B03 数値拡散が実効格子 Péclet 数を下げる
- Level: B

風上差分の修正方程式で

\[
\kappa_{\mathrm{eff}}
=
\kappa+\frac{|a|h}{2}
\]

とする。

元の格子 Péclet 数を

\[
Pe_h
=
\frac{|a|h}{2\kappa}
\]

としたとき、

1. 
   \[
   Pe_h^{\mathrm{eff}}
   =
   \frac{|a|h}{2\kappa_{\mathrm{eff}}}
   \]
   を \(Pe_h\) だけで表せ。
2. 任意の \(Pe_h>0\) で \(Pe_h^{\mathrm{eff}}<1\) を示せ。
3. \(Pe_h=4\) のときの値を求めよ。
4. この計算が風上差分の振動抑制をどう説明するか述べよ。

<!-- solution-start -->
### 詳細解答

まず

\[
\frac{|a|h}{2}
=
\kappa Pe_h.
\]

従って

\[
\kappa_{\mathrm{eff}}
=
\kappa+\kappa Pe_h
=
\kappa(1+Pe_h).
\]

よって

\[
\begin{aligned}
Pe_h^{\mathrm{eff}}
&=
\frac{|a|h}
{2\kappa(1+Pe_h)}\\
&=
\frac{Pe_h}{1+Pe_h}.
\end{aligned}
\]

したがって

\[
\boxed{
Pe_h^{\mathrm{eff}}
=
\frac{Pe_h}{1+Pe_h}
}.
\]

\(Pe_h>0\) なら

\[
1+Pe_h>Pe_h.
\]

正数同士なので

\[
0
<
\frac{Pe_h}{1+Pe_h}
<
1.
\]

従って

\[
\boxed{
Pe_h^{\mathrm{eff}}<1
}.
\]

\(Pe_h=4\) なら

\[
Pe_h^{\mathrm{eff}}
=
\frac4{1+4}
=
\boxed{\frac45}.
\]

中心差分では \(Pe_h>1\) で隣接係数の符号が変わり、最大値原理が壊れました。

風上差分は先頭次数で

\[
\frac{|a|h}{2}
\]

だけ拡散を追加します。

その結果、修正方程式の実効格子 Péclet 数は常に1未満になります。

つまり風上差分は、移流卓越を弱める方向へ人工的に拡散を足し、単調性を回復していると解釈できます。

ただしその代償として、鋭い境界層を必要以上にぼかすことがあります。

## 11. まとめ

この章の中心式は三つです。

まず格子 Péclet 数

\[
\boxed{
Pe_h
=
\frac{|a|h}{2\kappa}
}.
\]

次に中心差分型移流拡散スキーム

\[
\boxed{
-(1+Pe_h)U_{j-1}
+
2U_j
-
(1-Pe_h)U_{j+1}
=
\frac{h^2}{\kappa}f_j
}.
\]

ここから

\[
\boxed{
Pe_h\le1
}
\]

なら離散最大値原理が働き、

\[
Pe_h>1
\]

では係数符号が崩れて交互振動が現れることを示しました。

風上差分では

\[
\boxed{
-(1+\beta)U_{j-1}
+
(2+\beta)U_j
-
U_{j+1}
=
\frac{h^2}{\kappa}f_j,
\qquad
\beta=\frac{ah}{\kappa}
}
\]

となり、任意の \(Pe_h\) で隣接係数の符号が保たれます。

その代償は

\[
\boxed{
\kappa_{\mathrm{num}}
=
\frac{|a|h}{2}
}
\]

の数値拡散です。

したがって FDM4 の要点は、

\[
\boxed{
\text{高い形式精度}
\neq
\text{良い離散解}
}
\]

であり、

\[
\boxed{
\text{移流卓越では、係数符号・単調性・数値拡散まで見る}
}
\]

ことです。

これで差分法 FDM1–FDM4 の主線は完結です。

次の FEM1 では、格子点で微分方程式を直接近似する差分法から離れ、Poisson 方程式を弱形式へ移して Galerkin 法を構成します。さらに後続 FEM7 では、本章と同じ移流卓越問題が有限要素法でどう現れ、安定化がどう導入されるかを扱います。
