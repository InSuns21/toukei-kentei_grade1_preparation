# 通常教材 粒度・構成レビュー計画

## 目的

通常教材 `textbook/` の既存章を、統計数理100大問・統計応用（理工学）80大問と同じ共通基準で読み直す。

比較基準は文字数ではなく、`EXERCISE_GUIDELINES.md` と `statistical-mathematics/core/40_fisher_information_delta_mle_efficiency.md` が示す**導出再現性**とする。

同時に、既存の分割章を `index.md` 1枚へ段階移行し、GitHub Pagesでは先行して全章を1単元1ページで表示する。

## 判定ラベル

- **PASS**: 初見の受験者が定義・仮定・途中計算・結論を追え、問題と詳細解答が対応している。
- **EXPAND**: 数学的には正しいが、主要な微分・積分・行列計算・母関数導出などに飛躍がある。
- **REWRITE**: 問題と解答の対応不足、暗記前提、定義不足、誤記・用語混在などがあり、局所追記では直しにくい。

レビュー済みという進捗状態と、この粒度判定は分ける。過去に `reviewed` でも、粒度レビューでは `EXPAND` になり得る。

## 1章ごとの確認項目

1. 導入: なぜ必要か、前提知識、到達点が分かるか。
2. 定義: 記号、台、母数範囲、存在条件が明記されているか。
3. 定理: 定理名だけでなく、必要条件と本問での条件確認があるか。
4. 例題: 非自明な微分・積分・平方完成・行列計算を飛ばしていないか。
5. 演習: 問題の直後に対応する解答があり、GitHub Pagesでは折りたためるか。
6. 詳細解答: 各小問について「出発点 → 条件 → 途中計算 → 結論」が追えるか。
7. 本番答案: 詳細解答との差が明確で、得点の核を残しているか。
8. 採点基準: 主要な導出へ点が割り当てられているか。
9. 用語: `references/terminology-guide.md` と一致するか。
10. 数式: KaTeX strictで表示できるか。


粒度監査・用語監査は候補抽出であり、検出件数だけで章を不合格にしない。

## 1ページ移行

- GitHub Pages: 全既存章をビルド時に1ページへ合成する。
- 新規章: `npm run new:chapter -- <ID>` で `index.md` 1枚を作る。
- 既存章: 粒度レビュー時に `index.md` へ内容を統合し、確認後に旧 `00_...md`〜`09_...md` を削除する。
- 旧ファイルへの既存リンクは移行中に確認し、削除前にリンク監査を通す。
