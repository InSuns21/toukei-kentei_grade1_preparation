### 集合論・数学基礎論

共通基礎の集合論で集合・写像・濃度・順序・選択公理・Zorn の補題まで学んだあと、**数学の対象そのものを集合・順序数・公理系から調べたい読者のための独立した発展分岐**です。解析・線形代数・確率・幾何を読むための必修前提にはしません。

1. [SET1 公理的集合論への入口：ZF と ZFC](textbook/volumes/dream_thater/基礎論系/SET/SET1/index.md)
2. [SET2 順序型と順序数：整列の長さを集合で表す](textbook/volumes/dream_thater/基礎論系/SET/SET2/index.md)
3. [SET3 超限帰納法：極限段階を含む帰納法](textbook/volumes/dream_thater/基礎論系/SET/SET3/index.md)
4. [SET4 超限再帰：以前の全段階から次を定義する](textbook/volumes/dream_thater/基礎論系/SET/SET4/index.md)
5. [SET5 累積階層と rank：集合はどの段階で現れるか](textbook/volumes/dream_thater/基礎論系/SET/SET5/index.md)
6. [SET6 基数：順序の長さと集合の大きさを分ける](textbook/volumes/dream_thater/基礎論系/SET/SET6/index.md)
7. [SET7 Hartogs の補題：選択公理なしで大きすぎる順序数を作る](textbook/volumes/dream_thater/基礎論系/SET/SET7/index.md)
8. [F0-00A3A 選択公理と Zorn の補題の同値性](textbook/volumes/dream_thater/基礎論系/F0/F0-00A3A/index.md)

この系列では、ZF / ZFC → 順序型・順序数 → 超限帰納法 → 超限再帰 → 累積階層・rank → 基数 → Hartogs → 選択公理・整列可能定理・Zorn の同値性 → 弱い選択原理・超フィルター、という主線を追い、最後に Hamel 基底・Hahn--Banach・Vitali 集合など既存科目へ戻って選択原理の使われ方を監査します。
