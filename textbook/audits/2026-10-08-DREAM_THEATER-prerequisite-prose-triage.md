## 範囲と方法

公開索引に掲載された443章について、本文中の他章へのMarkdownリンク、論証に用いる旨を示す近傍表現、各章の `chapter.yaml.prerequisites` と `knowledge.yaml.prerequisites` を照合した。通常教材の章も参照先として解決する。到達性は推移的な前提閉包で判断し、「直接」「推移的に既習」「前提から到達不能」を区別する。

自動抽出は**候補の棚卸し**であり、意味上の依存を確定する検証ではない。旧版ロードマップ、後続章で使われる自章の結果、補講への誘導、単なる比較を機械的に真の欠落と誤認し得る。概念名のみの引用やリンクのない導出は検出漏れがあり得るため、数学本文の全件査読を代替しない。

初回の粗い抽出では、到達不能候補58件、推移的に到達可能な言及356件、前提メタデータの不一致16章を報告した。この件数は**確定欠陥数ではない**。後続の検出器改良で後続章からの逆向き参照とロードマップを候補から除外した。

## 本文根拠から修正した欠落

### F0-00D1 ノルム・Banach

- 冒頭の標準通読ルートは `F0-00F2 → F0-00D1` まで先行するよう明記しており、有限次元ノルム同値の直接証明は F0-00E の基底・次元を使用する。
- 既存 `chapter.yaml` に F0-00E はあるが F0-00F2 がない。一方 `knowledge.yaml` に F0-00F2 はあるが F0-00E がない。
- **対応**：両方を `F0-00D, F0-00C2, F0-00E, F0-00F2` に合わせた。F0-00F2 は F0-00F1・F0-00E2 を前提とし、F0-00D1 を前提としないため、新たな循環は作らない。

### OPT4 Fenchel 共役・凸双対

- Level B **OPT4-B01** の問題で、F0-00D2D の Hölder の不等式を使用すると明記。詳細解答では
  `|y^T x| ≤ ||y||_q ||x||_p ≤ ||y||_q`
  を用い、その後に等号達成を構成する。
- **対応**：OPT4 の `chapter.yaml`・`knowledge.yaml` の直接前提に `F0-00D2D` を追加。演習の証明前提として必要だからであり、リンクが存在するだけで追加したものではない。

### F0-00P4A 一様可積分性・Vitali

- Level C **F0-00P4A-C01** は `Z_n=E[X|G_n]` と条件付き期待値を定義し、P3A の単調性から `-E[|X||G_n] ≤ Z_n ≤ E[|X||G_n]` を使用する。
- 元の `knowledge.yaml` は P3A を予告参照としていたが、Level C の出題・詳細解答で**既知の定義と定理を実際に使用**する以上、前提へ指定する方が学習者に正確である。
- **対応**：両方の直接前提を `F0-00P4, F0-00D2B, F0-00P3A` に整理。元の knowledge にあった P2A の直接指定は、本章での直接列挙より既存前提経由の到達を利用する扱いに変更。P3Aの条件付き期待値について、使用実態と矛盾する `forward_references` は削除した。

### MOD2 Smith 標準形・PID 上有限生成加群

- 学習目標に「LA4 の Jordan 構造への接続を説明できる」が含まれる。本文10.2節は「LA4 で証明した Jordan 構造と照合する」と明記し、基本因子 `(x-λ)^e` と Jordan ブロックの対応を、LA4 の存在証明を再掲せず説明する。
- **対応**：MOD2 の `chapter.yaml` と `knowledge.yaml` に `LA4` を直接前提として追加。LA4 の前提は LA3C・F0-00F であり、MOD2を要求しないため循環はない。

## 修正不要と判定した代表候補

- **MQ1 → QM5**：QM1のような先行一般論とは異なり、MQ1の `QM6` が `QM5` を前提にしている。**MQ1 → QM6 → QM5** と到達可能なので、QM5を重複して直近の前提へ足す必要はない。
- **CA2 → CA7/CA8/CA10、CA3 → CA7/CA9**：後続章が先行章の定理を使う接続説明。現在章が後続理論に依存しているわけではない。
- **RA7 → F0-00C1**：後段の完全証明先を明示した結果先行参照。RA7の証明責務と後段の依存を混同しない。
- **NPDE7 → NPDE6**：逆時間 rescaling との比較。言及される方程式をNPDE7の新しい証明の前提と決めつけない。
- **F0-00R系列**：系列全体の案内であり、列挙された全章を案内ページの prerequisite に追加しない。

## 実施形態・限界

- GitHub上の現行本文・chapter.yaml・knowledge.yamlを照合した同一担当の複数観点による監査。第三者の独立査読ではない。
- 数理再計算を行った対象は上記確定3件に関連する論証・演習の**依存使用箇所**であり、443章の全証明・全演習を独立に再計算したことは意味しない。
- CIは推移閉包、明示引用、前提メタデータ差分を継続的に可視化する。報告の WARN / 候補件数をゼロにするためだけに前提を追加しない。
