# DREAM THEATER：前提メタデータ差分14章と引用候補12件の再査読

作業日：2026-10-08。作業対象は PR #860 後の main。**この文書は査読履歴であり、現在の依存関係・執筆規約の正本ではない**。正本は対象章の本文・`chapter.yaml`・`knowledge.yaml`・knowledge DAG。

## 判定規準

1. 本文の証明や演習で、前章の未証明の結果を実際に使う場合は `chapter.yaml` の前提閉包から到達させる。
2. `chapter.yaml` は公開ページの読者向け1階層表示に使う。単に後続への案内があるだけの章を前提にしない。
3. `knowledge.yaml` の canonical concept `requires` は、本文で理論を再証明していても既出概念の所有者を指す場合がある。読者向けの前提と一律に同一視しない。
4. 既存の直接前提を経由して到達できる場合、別名の先行章を機械的に追加しない。明確な数学上の役割がある既存の直接前提は維持する。
5. 監査スクリプトの引用判定は自然言語ヒューリスティックであり、結果に意味上の依存を自動追加しない。

## 12件の引用候補

12件は9組の（引用元、リンク先）に集約された。本文の指定箇所をそれぞれ確認したところ、**現在章の証明・演習でリンク先の未習定理を適用している事例ではない**。

| 引用元 → 先 | 判定 |
| --- | --- |
| EVOL3 → NS1 | NS1で扱う構成は本章で「逆輸入しない」と明記 |
| F0-00P3B → F0-00P3C | 「次に進む」の予告 |
| LA1 → RNG1 | R/Cの体に限定し、一般体は後段で扱うという対象範囲の明示 |
| NPDE7 → NPDE6 | 長時間漸近と有限時刻blow-upの rescaling の比較 |
| RA6A → RA7 | RA6Aの局所可逆性が後続の変数変換で利用されるという正方向の接続 |
| RA7 → F0-00C1（3件） | コンパクト性・連続性の完全証明を後段の既存講座へ送る結果先行参照 |
| SET10 → F0-02C6 | Hahn–Banach の定理が必要とする選択原理の強さを説明する用途例 |
| SET10 → FA4 | Tychonoff のコンパクトHausdorff版と完全版の選択公理強度を区別するための比較 |
| SET7 → F0-00A3（2件） | 選択公理・Zorn 系列への章末導線 |

これらの例外は `textbook/dream-theater-prerequisite-audit-exceptions.yaml` に具体的な引用文脈の短い照合文字列と査読理由を登録。引用の文章が変わり、同じリンクを実際の論証に使い始めたら例外の文脈照合から外れて再警告される。

## 監査と限界

新しい未査読の差分・到達不能引用候補は `scripts/audit-dream-theater-prose-prerequisites.mjs --strict` がエラーとして検出する。登録された例外は判定済みとして別件数に集計される。検出器はリンク付きで理由表現を含む行を扱うだけで、**リンクのない暗黙の数学的依存、独立証明の数学的真偽、全章の全演習の正しさまで保証しない**。概念依存の既存CIは継続する。

同一担当の読解・到達性調査と別観点の記述文脈確認による査読であり、第三者の独立数理査読を実施したとは称しない。変更章の数学本文（`index.md`）は改変していないため、今回の査読は**依存関係を利用する本文上の箇所**を対象とし、14章の全定理・全演習解答の紙上再計算は行っていない。既存章の包括的数理査読は別の責務として残る。
