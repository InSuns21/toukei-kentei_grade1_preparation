~~~text
RA/MECH → TH → SM ────────────┐
確率論 → INFO → ITD ← TH/SM   │
QM → QINF ────────────────────┤
SREL → GR I→II ← LORG ────────┤
SREL/QM → QFT I→II ← HPDE     │
GR＋QFT＋HPDE → QCURV ────────┼→ BHT → BHI I→II
GR＋QFT II＋QINF＋BHT → HOLO ──┘          ↑     ↑
                                      INFO   HOLO
~~~

- 章ID・前提の全体衝突監査、未実装PLANの利用停止線、物理的仮定の整合は各講義着手時に確認する。本ルートファイルは個別科目の完了を代替しない。
