# DREAM THEATER 集合論・数学基礎論コース計画

作成日: 2026-09-29  
状態: planned

## 0. 位置づけ

本計画は、選択公理・順序数・超限帰納法・超限再帰と、その周辺の公理的集合論を体系的に学ぶ独立科目を設計する。

**この科目は DREAM THEATER の共通基礎には置かない。**

共通基礎の「集合・位相空間論」は、学部数学で広く必要になる集合・写像・関係・可算性・濃度・順序・位相を担当する。本科目はその先で、

> 数学の対象そのものを、集合・順序数・公理系から調べる理論科目

として分岐する。

したがって、解析・線形代数・確率・幾何などを読むために本科目の完走を要求しない。

## 1. この科目を新設する理由

現行 F0-00A3A「選択公理と Zorn の補題の同値性」では、完全な構成のために

- 順序数
- Replacement を含む ZF の集合形成
- 超限再帰定理
- Hartogs 補題

を使用している。

しかし、これらを canonical に導入する前提章が現在の DREAM THEATER にはない。

そのため現状は、

~~~text
選択公理
  ↓
A3A で超限再帰を使う
  ↓
しかし超限再帰そのものは未習
~~~

という依存の穴がある。

本科目ではこの穴を埋め、最終的に

~~~text
ZF / ZFC
  ↓
順序数
  ↓
超限帰納法
  ↓
超限再帰
  ↓
累積階層・rank
  ↓
基数
  ↓
Hartogs
  ↓
選択公理・整列可能定理・Zorn の同値性
~~~

を prerequisite だけから追えるようにする。

## 2. 前提

必須候補:

- 共通基礎「集合・位相空間論」のうち、集合・写像・集合族・関係・可算性・濃度・順序・整列
- 数学的帰納法
- 基本的な論理記号と証明法

位相空間論の後半は原則として prerequisite にしない。

実解析・線形代数・測度論も prerequisite にしない。

本科目のために共通基礎へ順序数や ZF を逆輸入しない。

## 3. 科目構成案

ID は実装前に既存 ID / dream-theater-index / knowledge DAG を確認して確定する。以下では仮に **SET1--SET10** とする。

### SET1 公理的集合論への入口

中心問い:

> 「集合を好きな条件で集めてよい」とすると、なぜ問題が起きるのか。

扱う候補:

- 素朴集合論と公理的集合論
- Russell のパラドックス
- 集合と proper class の位置付け
- ZF / ZFC という公理体系
- 外延性公理
- 空集合の存在
- 対公理
- 和集合公理
- 冪集合公理
- 無限公理
- 分出公理図式
- 置換公理図式
- 正則性公理
- 選択公理は ZF とは別に加えること

ここでは一階述語論理の形式体系を全面展開しない。公理図式が「一つの公理」ではないことは説明する。

### SET2 順序型と順序数

中心問い:

> 整列集合の「長さ」を集合そのものとして表せるか。

扱う候補:

- 整列集合
- 順序同型
- 順序型
- 推移的集合
- von Neumann 順序数
- \\(0,1,2,\\ldots\\)
- \\(\\omega\\)
- 後続順序数
- 極限順序数
- 順序数の比較可能性
- 任意の順序数の元も順序数であること
- 順序数全体が集合ではないことの位置付け

直接例として有限順序数、\\(\\omega\\)、\\(\\omega+1\\) を具体的に比較する。

### SET3 超限帰納法

中心問い:

> 自然数上の帰納法を、任意の整列された段階へどう一般化するか。

扱う候補:

- 数学的帰納法との比較
- 超限帰納法の定理
- 最小反例による証明
- 後続段階
- 極限段階
- strong induction との関係
- 順序数上の命題を超限帰納法で証明する具体例

「後続段階だけ確認すればよい」という誤解を避け、極限段階で何を確認するかを重点化する。

### SET4 超限再帰

中心問い:

> すべての以前の段階を使って次の対象を定義するにはどうすればよいか。

扱う候補:

- 自然数上の再帰との比較
- 超限再帰定理
- \\(F(\\alpha)=G(F|_\\alpha)\\) 型の定式化
- 存在と一意性
- 後続段階と極限段階
- 順序数の加法
- 順序数の乗法
- 順序数冪
- 定義が循環していないことの確認

順序数演算は計算技法の網羅を目的とせず、「超限再帰で何を作れるか」の代表例として扱う。

### SET5 累積階層と rank

中心問い:

> ZF の集合宇宙を段階的に眺めると何が見えるか。

扱う候補:

- \\(V_0=\\varnothing\\)
- \\(V_{\\alpha+1}=\\mathcal P(V_\\alpha)\\)
- 極限順序数 \\(\\lambda\\) に対する \\(V_\\lambda=\\bigcup_{\\beta<\\lambda}V_\\beta\\)
- 累積階層
- 集合の rank
- 正則性公理との接続
- 各集合がどこかの \\(V_\\alpha\\) に現れること
- finite rank の具体例

「極限段階では以前の段階を全部合併する」という超限構成の感覚をここで定着させる。

### SET6 基数と濃度

共通基礎で学ぶ「全単射による濃度」を、本科目では順序数と接続する。

扱う候補:

- 基数
- 初期順序数としての基数
- \\(\\aleph_0\\)
- \\(\\aleph_1\\) 以降の位置付け
- 基数の比較
- 基数の加法・乗法・冪
- Cantor の定理
- \\(2^\\kappa\\)
- 順序数と基数の違い

連続体仮説は主張の意味まで紹介してよいが、独立性証明を本科目の必修範囲にしない。

### SET7 Hartogs の補題

中心問い:

> 選択公理なしでも、ある集合へ単射できない順序数を作れるか。

扱う候補:

- 部分集合上の整列関係
- 整列集合の順序型
- Replacement の役割
- Hartogs 数
- Hartogs の補題の完全証明
- 「\\(X\\) より長すぎる順序数」が AC なしで作れること
- AC から整列可能定理を導く際の停止保証

この章を、現行 F0-00A3A で使っている Hartogs 補題の canonical owner とする候補。

### SET8 選択公理・整列可能定理・Zorn の補題

中心問い:

> 見た目の違う三つの原理が、なぜ同じ強さなのか。

扱う:

- 選択公理
- 整列可能定理
- Zorn の補題
- Zorn \\(\\Rightarrow\\) AC: 部分選択関数の極大化
- AC \\(\\Rightarrow\\) 整列可能定理: 選択関数 + Hartogs + 超限再帰
- 整列可能定理 \\(\\Rightarrow\\) Zorn: greedy maximal chain
- 各方向で何を仮定しているか
- 循環論法になっていないことの確認

既存 F0-00A3A の内容を canonical asset として最大限再利用する。

実装時の第一候補は、F0-00A3A の stable ID / URL を維持したまま、本科目の SET8 相当として公開所属と prerequisites を組み替えることである。

### SET9 弱い選択原理

中心問い:

> 「選択公理を使う / 使わない」の二択だけで数学を分類できるのか。

扱う候補:

- 可算選択
- 有限集合族に対する選択
- 従属選択公理 DC
- ultrafilter lemma
- Boolean prime ideal theorem の位置付け
- ZF / ZF+DC / ZFC の違い
- どの含意を証明し、どれを位置付けだけに留めるかの明示

集合論の独立性理論を未習の段階では、証明できない非含意を「明らか」と書かない。

### SET10 選択公理は普通の数学のどこに現れるか

抽象的な同値性だけで終わらせず、既存 DREAM THEATER へ戻す出口章とする。

候補:

- Hamel 基底
- Hahn--Banach
- 極大イデアル
- ultrafilter
- Tychonoff の定理
- Vitali 型非可測集合
- 選択原理を使わず明示的に選べる場合との比較

各例について、

1. 何を選ぶ必要があるか
2. どの選択原理を使っているか
3. 証明のどこで必要か
4. 失うとどの構成が止まるか

を局所的に説明する。

## 5. 共通基礎にしないことの明文化

dream-theater-standard-math-core.md の共通基礎には、本科目を必修順として挿入しない。

本科目の標準的な入口は、

~~~text
集合・位相空間論の集合論部分
  ↓
集合論・数学基礎論
~~~

とする。

後続の通常科目は、本科目を読まなくても進めるようにする。

例:

- 関数解析で Zorn を使う → F0-00A3 を prerequisite にすればよい。
- 測度論で Vitali 集合を扱う → 必要な AC の位置付けを局所説明し、本科目 SET10 は発展参照にできる。
- 位相で Tychonoff を扱う → その証明が強い選択原理を使うなら、定理の依存を明示する。
- 順序数そのものを使う理論 → 本科目を prerequisite にしてよい。

## 7. 数理論理との境界

本科目は「数学基礎論」という名を含むが、初回実装で次を全面展開しない。

- 一階述語論理の完全な形式化
- Gödel の完全性定理
- Löwenheim--Skolem の定理
- Gödel の不完全性定理
- 構成可能宇宙 \\(L\\) の精密理論
- forcing
- Cohen による CH / AC 独立性証明
- large cardinal 理論

これらは将来、需要があれば別系列「数理論理・公理的集合論 II」として計画する。

本科目では、

> AC や CH の独立性を証明するにはモデル理論・内部モデル・forcing など、さらに別の理論が必要になる

という位置付けまでに留めてよい。

## 9. 完成条件

- 順序数を集合として定義し、有限順序数・\\(\\omega\\)・後続・極限を具体例から説明できる。
- 超限帰納法で、後続段階と極限段階を区別して証明を再構成できる。
- 超限再帰定理の仮定と結論を述べ、少なくとも順序数演算または累積階層を実際に構成できる。
- 累積階層 \\(V_\\alpha\\) と rank を追える。
- 基数と順序数を混同しない。
- Hartogs 補題を AC に依存せず証明できる。
- AC \\(\\Leftrightarrow\\) 整列可能定理 \\(\\Leftrightarrow\\) Zorn の証明を、未習概念なしで追える。
- 可算選択・DC・完全な AC が同一ではないことを説明できる。
- 選択公理が Hamel 基底、Hahn--Banach、Vitali 集合などでどこに現れるかを局所的に説明できる。
- 本科目を DREAM THEATER の共通基礎の必修にしていない。
