# DREAM THEATER 機械学習 I・II（ML1・ML2）

分冊: 2026-10-11  
状態: planned（科目固有の実装は未着手）

## 中心問いと直接依存

LA/RA、最適化、確率論の該当結果。ML1 → ML2という連続系列を1つのPLANとする。ML2で情報幾何・Wassersteinの理論を利用するとき、未実装の定理を既知扱いしない。

**本科目の正本：** 予測と最適化、潜在変数・変分推論・深層表現。
