> **講義数は全68講で確定する。** 二項モデルから入り、期待値・PDE の価格付けを照合し、木・有限差分・Monte Carlo・Fourier の数値誤差を評価する。American と経路依存商品の両方を扱い、VaR／ES／ストレス・リスク配賦・信用リスクを経て、最適執行へ至る。各講義の本文・必要な視覚教材・数値検証・査読を**同一作業単位**で完成させ、全講完了後の**科目全体の横断監査は1回だけ**実施する。

## 1. 中心問い・到達水準

**何をいくらで売買することが無裁定なのか。** 価格の不確実性があるとき、(a) 複製できる請求権の価格をどう決めるか、(b) 複製・閉形式が使えないときどんな数値手段で価格と誤差を出すか、(c) 実際に保有した場合の損失分布と極端損失をどう測るか、(d) 流動性のある現実市場でどう執行するかを、同じモデルを使って追跡する。

学習者は修了時に次を再現する。

1. **離散→連続**：1期間二項モデルで裁定・複製・リスク中立確率を導出し、多期間・American・経路依存商品へ拡張した後、Brown 運動／SDE に移行する。
2. **二通りの価格付け**：所定の仮定・終端境界条件の下で、複製／delta hedge から導く PDE と、リスク中立期待値（Feynman–Kac）から導く価格を、適用条件とともに対応づける。
3. **商品**：European、American、Bermudan、算術平均 Asian、Barrier、Lookback の価格と、早期行使／経路依存のために増える状態変数を説明する。**American は行使時刻の最適化を含むが、payoff 自体が必ず経路依存とは限らない**と明確に区別する。
4. **数値計算**：二項／三項木、陽・陰・Crank–Nicolson 差分、American 相補問題、Monte Carlo／分散減少／Brownian bridge／LSM、Fourier／校正の誤差・安定性・計算量・再現性を比較する。
5. **リスク管理**：リスク中立測度 $Q$ による**価格付け**と実確率 $P$ による**将来損失評価**を混同せず、VaR、ES、尾部推定、依存性、バックテスト、ストレス、リスク配賦、ES 最適化、信用・流動性リスクまで数値計算する。
6. **執行**：板・成行／指値・TWAP／VWAP／POV・市場インパクト・リスクをモデル化し、Almgren–Chriss、板の回復、約定確率、状態依存制御と複数資産の最適執行を計算する。実際の出来高を事前に知っていたかのような先読みを避け、TCA とバックテストで執行前後の費用・リスクを評価する。

金融商品の売買判断・規制対応の認証や収益保証を目的としない。すべての数値例には**単位・通貨・年率換算・日数規約・配当／金利・監視頻度・モデル仮定**を置く。

## 4. 各講の実装契約：本文・計算・図を同じPRで完成させる

- **本文の固定導線**：Mission → 既習の手計算例 → できないこと → 新概念の言葉による導入 → formal statement（対象・仮定・結論）→ 完全な導出 → 数値実装 → 誤差と破綻条件 → 演習・全詳細解答 → 次講への橋。高校生でも初見の専門語が意味より先に登場しない順序を採る。
- **自立性**：各講の全主要定義に条件を確認する直接例を添え、主要定理・補題・証明・仮定・適用点を本人が再現できる粒度で記述する。他講の結果を使う文・見取り図・証明・詳細解答は実在する stable anchor へ結果名でリンクする。prerequisite 外の結果の逆輸入を禁止する。
- **演習**：理由付き例外のない限り Level A 4題、B 3題、C 1題以上。全問に詳細解答。数値講義は**入力→アルゴリズム→中間値→停止・収束判定→解釈**まで必ず検証し、主要誤り（リスク中立と実確率の混同、時間方向、無配当 American call、行使 look-ahead、原子のある ES）を問題化する。題数を合わせるだけで止めない。
- **価格付け実験共通入力**：基準例として $S_0=100$, $K=100$, $T=1$ 年, $r=0.05$, $\sigma=0.20$, $q=0$ を基本に、商品別の障壁・観測日・行使機会・配当は別途定義する。比較時は**同一商品・同一計時規約・同一監視条件・同一モデル**だけを同じ表で比べる。
- **数値ベンチマーク**：手計算が可能な小規模二項木と、条件が一致する Black–Scholes 公式を独立の oracle とする。American／経路依存の解析公式がない場合は格子細分化、独立実装、確率的上下界、他手法比較で検証し、解析的な厳密値が存在すると装わない。MC 誤差（統計）と時間・空間離散化誤差（系統）を分け、収束・失敗例まで提示する。
- **リスク計算共通入力**：`loss = −(portfolio value at horizon − current value + cash flows)` のように符号とキャッシュフローを定義し、$P$ 下の保有期間損失を測る。VaR の分位点 convention、ES の分位点積分・ties、信頼水準、推定サンプル、独立／系列依存、再価格モデルを明記する。$\mathrm{VaR}_{\alpha}(L)=\inf\{x:P(L\leq x)\geq\alpha\}$、$\mathrm{ES}_{\alpha}(L)=(1-\alpha)^{-1}\int_\alpha^1\mathrm{VaR}_u(L)\,du$ を基準とし、離散原子を単純な「VaR を超えた損失の標本平均」と同一視しない。
- **数値計算の正本は実行可能な Python ソース**：実装講義では独習者が取得・実行・改変できる `.py` を章内 `assets/` に置き、図・表はそのコードから再生成できるようにする。初期二項木など標準ライブラリで十分な場合は外部依存を不要とし、必要に応じて NumPy／SciPy／Matplotlib を使う。アルゴリズムの擬似コード・数学的導出は Python を読まなくても再現できる粒度で本文に残す。乱数シード、標本数、刻み、停止許容誤差、検証 oracle、計算量（時間とメモリ）、極端なパラメータでの失敗を記録し、異なる手法の比較では共通乱数の採否を示す。ブラウザでの JavaScript/TypeScript や Python-in-browser は**教育的に操作性が必要な場合だけの補助**とし、Python と重複する数値アルゴリズムの常時二重保守は求めない。

- **可視化**：掲載する数値グラフ・比較表は Python から SVG／PNG／CSV 等として決定論的に書き出せるようにする。本文には読み方・モデル仮定・入力値・単位・検証ポイントを記載。ユーザー向けには生成済み静図と代替テキストを必ず提供し、Python が動かない閲覧環境でも数学的説明が閉じるようにする。Python の画像は作図規約に合わせてレイアウト・モバイル表示・線種・ラベルの視認性を別途点検する。
- **テスト**：`pytest` または Python 標準の `unittest` を採用し、正本の閉形式／手計算、複製関係、境界ケース、確率の正規化、負の損失符号の取り違え、VaR と ES のタイ処理を含める。格子・反復法は収束と停止残差、Monte Carlo は固定 seed に加え**統計的誤差と系統誤差を別々に評価**し、乱数の単一実現の浮動小数一致だけで合格させない。LSM や VaR/ES バックテストは学習・評価のデータ分離を検証する。
- **CI と費用**：講義PRで該当 Python テストと代表的な図表再生成の**軽量スモークテスト**を実行し、重い格子細分化／多数経路ベンチマークはコマンドを分けて必要な検証時に実行可能とする。既存CIに Python 実行ゲートがなければ、**講義実装と同じ作業単位で必要な最小限のゲートを追加**してから完成扱いにする。結果は許容誤差・計算環境・実測時間とともに記録する。
- **例外**：理論のみ・手計算のみの章は Python 実装を強制しない。必要な場合に限ってブラウザ側で再計算・操作できる補助UIを追加するが、Python 正本と数値一致するクロスチェックを付ける。Python にしかない公式や前提は置かず、証明・主要中間式は Markdown の本文に記す。

## 5. 最終の科目全体監査は一度だけ

**講をまたぐ作業は段階的に行い、科目全体の一括監査は全68講の実装が終わった後に1回だけ行う。** 個別PRで必須の数学・図・コード査読を省略して最後へ押し付けない。

1. **各講のPR**：本文・必要と判断した図／操作コンテンツ・演習解答・再実行可能な Python 数値ソースとテスト・章メタデータ・公開目次更新を同一PRに入れる。変更区分に応じた chapter gate、`npm run validate:textbook:changed`、`validate:textbook-knowledge:changed`、`validate:dream-theater-concepts:changed`、`validate:dream-theater-exercise-counts`、該当する SVG quality/layout、実ブラウザ表示、公開 link check を実施。常に該当系列 manifest を更新する。**別の完了章の追跡監査は明示依頼時以外しない。**
2. **講をまたぐ整合を執筆時に記録**：共有する数値ベンチマークの入力規約・oracle と定義担当、$P/Q$、複利・金利・時間の統一を毎講確認。新たな未解決問題だけを小さな TODO として追跡する。**フェーズ末の全科目再読・全件再計算を定例化しない。**
3. **第68講完成後の唯一の横断監査**：全68講の learning objective 充足、主要定理の canonical owner・依存方向・初出順、章間 stable anchor、商品ごとの PDE／期待値／tree／MC の仮定一致、モデル別数値誤差、リスク $P/Q$ と損失符号、公開目次、採用した図・アニメーションの導線、未解決 TODO、manifests／計画位置を**科目全体について1巡**確認する。統合 Python 数値 benchmark suite を実行し、価格付け・リスク・執行の代表例を独立再計算する。
4. **監査で重大欠陥が見つかったとき**：該当講と依存箇所だけを修正・再計算・再表示検証し、横断監査の指摘表で close を確認する。**科目全体の監査を最初から繰り返さない**。ただし全体の結論を無効化する広域欠陥なら必要な範囲を再確認し、未解決のまま完了扱いにしない。
5. **終了条件**：68/68 completed、全講の独習粒度・実演習・数値検証と採用図の gate、最終の横断監査1件の指摘対応、routing／公開導線・planの移動／manifest一致・CI がすべて成立して初めて `plan_done/` へ移動する。初期設計の確定のみでは `plans/` のまま。

## 6. 主要参考書・原典（章立ての照合に使用）

教材本文・問題・図の転載はせず、章立てと数学的到達点の検証に用いる。

1. Steven E. Shreve, *Stochastic Calculus for Finance I: The Binomial Asset Pricing Model* (Springer, 2004), [出版社目次](https://link.springer.com/book/10.1007/978-0-387-22527-2)。第01〜11講の二項・状態価格・American・ランダムウォークの導線。
2. Steven E. Shreve, *Stochastic Calculus for Finance II: Continuous-Time Models* (Springer, 2004), [書誌・目次](https://books.google.co.jp/books?id=O8kD1NwQBsQC)。第12〜25講の Brown 運動・Itô・Black–Scholes・Feynman–Kac・エキゾチック・最適停止を照合。
3. John C. Hull, *Options, Futures, and Other Derivatives*, 11th ed. (Pearson, ©2022), [出版社目次](https://www.pearson.com/en-us/subject-catalog/p/options-futures-and-other-derivatives/P200000005938/9780136939979)。商品の定義・実務慣行の確認に併用。
4. Paul Glasserman, *Monte Carlo Methods in Financial Engineering* (Springer, 2003), [出版社目次](https://link.springer.com/book/10.1007/978-0-387-21617-1)。第26〜37講とリスク管理の確率積分近似・経路生成・分散減少・LSM・Greeks。
5. Paolo Brandimarte, *Numerical Methods in Finance and Economics*, 2nd ed. (Wiley, 2006), [出版社目次](https://onlinelibrary.wiley.com/doi/book/10.1002/0470080493)。tree・有限差分・Monte Carlo・最適化の実装／誤差比較。
6. Alexander J. McNeil, Rüdiger Frey, Paul Embrechts, *Quantitative Risk Management*, revised ed. (Princeton UP, 2015), [出版社目次](https://press.princeton.edu/books/hardcover/9780691166278/quantitative-risk-management)。第44〜58講の VaR、ES、時系列・尾部・依存性・市場リスク・信用リスク。
7. R. T. Rockafellar, S. Uryasev, “Optimization of Conditional Value-at-Risk” (2000), [Journal of Risk](https://doi.org/10.21314/jor.2000.038)。第57講の ES 最適化。
8. R. Almgren, N. Chriss, “Optimal Execution of Portfolio Transactions” (2001), [Journal of Risk](https://doi.org/10.21314/jor.2001.041)。第61〜63講の市場インパクト・在庫・執行フロンティア。
9. Basel Committee, *Minimum capital requirements for market risk* (2019), [BIS公式資料](https://www.bis.org/publications/201901-standards-minimum-capital-requirements-market-risk)。第46・55講の ES の制度上の位置づけを**理論値・規制計算法と混同せず**紹介する場合の一次資料。規制の具体値・適用状況は執筆時に最新版と法域を再確認する。

10. Álvaro Cartea, Sebastian Jaimungal, José Penalva, *Algorithmic and High-Frequency Trading* (Cambridge University Press, 2015), [出版社の目次](https://assets.cambridge.org/97811070/91146/frontmatter/9781107091146_frontmatter.pdf)。第59〜68講の連続時間執行、指値／成行の選択、出来高目標・HJB 適用を照合。
11. Larry Harris, *Trading and Exchanges: Market Microstructure for Practitioners* (Oxford University Press, 2003), [出版社](https://academic.oup.com/book/52292)。第59〜61講の板・注文方式・市場マイクロストラクチャの入口。
12. Anna A. Obizhaeva, Jiang Wang, “Optimal Trading Strategy and Supply/Demand Dynamics” (*Journal of Financial Markets*, 2013), [NBER 著者公開稿](https://www.nber.org/papers/w11444)。第64講の板の回復と一時的インパクト。

13. Peter E. Kloeden, Eckhard Platen, *Numerical Solution of Stochastic Differential Equations* (Springer, 1992), [出版社目次](https://link.springer.com/book/10.1007/978-3-662-12616-5)。第27〜30講の既習確率積分に基づく数値近似、Itô–Taylor、強・弱近似と高次法。

15. Michael B. Giles, “Multilevel Monte Carlo Path Simulation” (*Operations Research*, 2008), [原著](https://doi.org/10.1287/opre.1070.0496) と “Multilevel Monte Carlo Methods” (*Acta Numerica*, 2015), [原著](https://doi.org/10.1017/S096249291500001X)。第31講の多重レベルの結合、計算量と誤差の検証。
