ATOPはFour Frontiersの前提補講から大学標準の独立科目へ変更する。元の14講は未実装なので番号を再設計し、後続2計画を同時に更新する。前案36講から42講に確定。I 12講、II 15講、III 15講。全42講に必要な図の企画を割り当て、計85の図題（パネルではなく教育的な観察対象）。枚数の水増しを強制せず、数学的な意味を保てる場合は統合可。図の制作・査読は講義実装時に行う。

## 3. 正式シラバス・図の制作計画

各図題は本文中の観察・検算とセットで実装する。図を理解するために未定義の専門語を先取りしない。比較図はラベル、矢印、向き、対応点を固定する。以下の図題間のセミコロンは独立した観察対象を表す。各章の主証明が後続を使う場合は先行して補題を証明するか、記述を明示的な予告／証明保留にする。

| ATOP40 | Brouwerの領域不変性 | 連続単射の局所閉球への制限、境界球面の補集合二成分と閉球像の補集合の連結性から像が開になることを証明。n=1は単調性、n=0は自明。次元不変性との相互関係 | 閉球と境界球面の像；無限遠点を含む外部成分と内部像 |
| ATOP41 | de Rham比較定理 | GEO9の複体・Poincaré補題・ホモトピー公式を再利用。滑らかな特異鎖・通常鎖の比較、積分とStokes、局所比較と貼り合わせでコンパクト滑らか多様体の同型を証明。一般の非コンパクトは局所有限被覆/層の論証を明示、wedge/cupの比較も条件を区別 | 円周の1形式と基本1サイクルの積分；良い被覆の重なりと比較図式 |

## 4. 図の作図契約と検証

- [DREAM THEATER執筆規約 §4.1.1](../DREAM_THEATER_AUTHORING_STANDARD.md)・[SVG品質ガイド](../DREAM_THEATER_SVG_QUALITY_GUIDE.md)を正本とする。各図題の学習者の問い・数学的な不変条件・対応する定義や証明ステップ・誤読しやすい反例を作図前に記録する。
- **辺同一視・多角形・商**：同じ文字と対応矢印の両方で貼り合わせを示す。トーラス、Kleinの壺、実射影平面を同じ辺の向きにしない。切断・貼り直しは対応の連続性と逆操作を記録。三次元中の絵にKleinの壺の自己交差が見える場合、抽象商の交点ではないと明示。
- **ホモトピー・被覆**：始点・終点・固定する部分、パラメータの方向を明記。持上げの初期条件、シートの交わらなさ、基底の同じ近傍との対応を示す。無限被覆は有限部分のみの模式図と明示。
- **単体・鎖・符号**：頂点順序、誘導境界の向き、基底・境界行列を一致させる。重心細分の個数、プリズムの単体分解、shuffleの符号を式から再計算。切除とMVの領域は開集合の仮定を満たす図を選ぶ。
- **写像度・双対性**：向きの規約、局所符号と合計次数、cup/capの前面後面と次数、双対セル・交叉の対応を検算。一般の多様体を3次元に埋め込めるかのように描かない。Jordan/Schoenflies、領域不変性は図だけで証明したとしない。
- **資産仕様**：章固有の図は `<chapter>/assets/<意味ある名前>.svg` に自作原典。viewBox、xmlns、data-layout-lint="strict"、title、desc、意味を伝えるMarkdown alt、本文中の直前直後の読み方。線種・矢印・記号を併用し色のみに依存しない。外部資産・スクリプト・foreignObject・装飾的な重複図を避ける。
- **検査**：`npm run validate:svg-layout:changed -- --base <sha>` と `npm run validate:svg-quality:changed -- --base <sha>`、Pagesリンク検証。通常幅と幅360px程度、モノクロ、必要なら原寸SVGを実レンダリングで確認。境界・矢印・ラベルの切れや重なり、数学的に必要な交差、同一視・向き・添字を独立再計算。自動検証だけで視覚査読完了としない。
- **図の数は目的で管理**：85図題は企画上の観察対象であって85個のファイルを固定ノルマにしない。対応する本文の証明・例・演習が全図題を満たすことを章の査読記録で示す。教育的に統合できる図は統合、複雑な変形の中間段階は追加してよい。実装を伴う対話型ラボは必須にしない。静止図で意味が完結すること。

## 5. 到達点と証明の停止線

- I：基本群・被覆空間分類・van Kampen・コンパクト曲面の分類の構成を追える。曲面分類の一意性はIIでEuler標数の不変性を閉じるまで明示的な証明責務として残す。全位相曲面の三角形分割可能性は原典引用可。有限三角形分割の存在を図から当然としない。
- II：単体／特異／胞体ホモロジーを比較定理込みで扱い、写像度・Brouwerの別証明・毛玉・Lefschetz定理・次元不変性を閉じる。Lefschetzは有限多面体に範囲を固定、一般ANRは引用境界。
- III：UCT・Künneth・cup/cap・PoincaréおよびPoincaré–Lefschetz双対性・Borsuk–Ulam・Jordan/Brouwer領域不変性・de Rham比較の標準的核心証明を閉じる。一般コンパクト集合のAlexander双対性でČechの構成を全展開しない場合でも、局所可縮集合・任意の埋込み球面に使う必要な比較と定理の論理鎖は明示し、核心を省略しない。高次ホモトピー理論、一般スペクトル系列、結び目理論全般、微分トポロジーの横断性、一般Schoenflies問題は対象外。
- 各講A4/B3/C1以上、全問詳細解答（42講の形式的下限A168/B126/C42、計336題）。既存正本の参照・formal statement・証明粒度・用語の先行導入・図の品質・CI・独立数理/読者粒度査読を全て満たす。講数が証明責務を満たせない場合は理由を残して変更する。
