# Lorentz計量 $(-+++)$ 統一・移行チェックリスト

この文書は編集・査読用。読者向けの規約と変換表は [`../dream-theater-lorentz-conventions.md`](../dream-theater-lorentz-conventions.md) が正本。

## 移行対象と順序

- 既に $(-+++)$ を採用：LORG、GR、HPDE、QCURV（既存定義と式は原則保持）。
- 旧 $ (+---) $ の主な対象：SREL1–SREL9、QFTの既存各章、およびこれらを具体式として参照するGR等の交差参照。
- 変更前に `rg -n 'diag\}\(1,-1,-1,-1\)|\(\+,-,-,-\)|\(\+---\)|\+---|p\^2=m\^2|Box_' textbook/volumes/dream_thater` 等で候補を洗い出し、**全数式を意味ごとに判定**する。マッチ行数を移行済み章数の代用にしない。
- 完了済み章でも上記が残る場合は、その章の旧規約が必要な比較説明なのか、未移行の計算なのかを区別する。

安全な移行単位は、定義を所有する章と直接依存する章・演習・証明を追跡できる系列単位。SREL2の計量定義を先に変え、旧SREL3/QFT1を何も直さずに「統一完了」と宣言してはならない。

## 必須の式の再計算

1. 計量成分と逆行列、四元速度・四元運動量の上げ下げ、$u^2=-c^2$ と $p^2=-m^2c^2$ を確認する。
2. 固有時、粒子作用、四元力、流体射影、応力エネルギーテンソルの符号と物理的な正値を確認する。
3. $∂^\mu$、$\Box_g$、自由Klein–Gordonの作用・Euler–Lagrange式、伝播関数の極・質量殻・$i\varepsilon$ を確認する。
4. 曲率作用素は既存GR/GEOのものを保持し、$R$・曲率結合・共形結合の各式を再導出する。
5. Maxwell場の $F^{\mu\nu}$ と $F_{\mu\nu}$、$E,B$ の成分定義、$F_{\mu\nu}F^{\mu\nu}$、電流結合、保存量の符号を確認する。
6. Dirac行列の $\{\gamma^\mu,\gamma^\nu\}=2\eta^{\mu\nu}I$、随伴、スラッシュ記法、スピノルの内積、スピン和・伝播関数を**新規約の表現から**再構成する。
7. 散乱のMandelstam変数（$s,t,u$）、断面積と位相空間、Wick回転とEuclid規約を確認する。物理的不変量を正値に保つための定義変更を明記する。
8. 定義・命題・証明・直接例・全演習解答を実数値や小さな行列で検算し、prerequisite・安定リンク・章内の表記切替を再確認する。
