# DREAM THEATER 講義粒度・分割監査

この文書は、DREAM THEATER 本編・確率論補講・Encore II〜Vについて、**一つの講義ページへ内容を詰め込みすぎていないか**を監査するための正本です。

証明・定義・具体例・演習を増補すると、内容そのものは充実しても、一ページの中に複数の独立した講義が同居してしまうことがあります。したがって今後は、内容不足だけでなく **講義粒度の過大さ** も品質問題として扱います。

---

## 1. 基本方針

ページの長さそのものでは分割しません。

分割判断の中心は、

> **このページは一つの主要な問いに答える一講義としてまとまっているか。**

です。

一つの講義の中では、原則として

```text
問い
 ↓
必要な定義
 ↓
主要命題
 ↓
証明・導出
 ↓
具体例
 ↓
A/B中心の演習
 ↓
次講への接続
```

という一つの学習サイクルが閉じることを目標とします。

---

## 2. 分割を検討する条件

次のうち複数が当てはまる場合、そのページを **分割候補** とします。

1. **主要な問いが複数ある**
   - 例：「積分をどう定義するか」と「極限と積分をいつ交換できるか」が同じページで独立して展開される。
2. **主要定理群が独立した論理鎖を複数作る**
   - 例：MCT → Fatou → DCT と、Tonelli → Fubini がそれぞれ別の講義として成立する。
3. **前半だけで後続章へ進める読者と、後半まで必要な読者が明確に分かれる**。
4. **定義・例・演習を本編並みに補うと、一つのページ内にA/B演習セットを複数置く必要がある**。
5. **途中で前提知識の種類が大きく変わる**
   - 例：測度の基本概念から積測度、さらにBanach/Hilbert空間へ移る。
6. **章内参照が「前半の講義」「後半の講義」と実質的に分離している**。
7. **一部だけを再読したい読者にとって、URL・見出し単位では粗すぎる**。

---

## 3. 分割しない条件

次の場合は長くても一講義のまま残せます。

- 一つの中心定理を証明するために多数の補題が必要なだけである。
- 例や演習が多いが、全て同じ主要概念を反復している。
- 分割すると各ページが定義だけ・証明だけ・演習だけになり、学習サイクルが壊れる。
- 前半と後半を分離すると循環参照や不自然な前提関係が生じる。

したがって **行数・文字数の閾値だけで機械分割しない** ことを明示します。

---

## 4. 分割時の互換性ルール

既存ページを分割する場合、原則として旧URLを壊しません。

### 4.1 既存URLを残す

既存の `F0-00D2` のようなページは、次のどちらかとして残します。

- シリーズの第1講
- シリーズの入口兼ロードマップ

旧URLから新しい各講義へ直接たどれるようにします。

### 4.2 IDは連番で増設する

既存の読み順を保つ場合、

```text
D2 → D2A → D2B → D2C → ...
```

のように枝番を使います。

既存の後続IDを一斉改名してリンクを壊すことは避けます。

### 4.3 manifest / Facade / roadmap / prerequisites を同時更新する

分割時は最低限、

- `textbook/dream-theater-index.json`
- `textbook/dream-theater.md`
- 基礎論ロードマップ
- 各 `chapter.yaml` の `prerequisites`
- 関連する監査正本

を同期します。

DREAM THEATER目次CIにより、新設講義の目次掲載漏れも検出させます。

## 5. D2の判定：分割推奨

現行D2は一ページに、

1. σ代数・測度
2. 測度0・a.e.
3. 可測関数
4. 単関数とLebesgue積分の構成
5. MCT / Fatou / DCT
6. 積σ代数・積測度 / Tonelli / Fubini
7. `L^p` / Hölder / Minkowski
8. `L^2` 完備性
9. 確率論・Hilbert空間への接続

を持っています。

これらは少なくとも **複数の独立した学習サイクル** に分かれます。本編並みに定義・完全証明・具体例・A/B演習を補うと、一講義としては明確に過積載です。

したがってBatch 2では、D2を単純に長文化せず、次の6講義へ分割することを基本案とします。

```text
D2   測度空間・測度0・a.e.・可測関数
 ↓
D2A  単関数からLebesgue積分を構成
 ↓
D2B  単調収束定理 → Fatouの補題 → 優収束定理
 ↓
D2C  積測度 → Tonelliの定理 → Fubiniの定理
 ↓
D2D  Lp空間 → Hölderの不等式 → Minkowskiの不等式
 ↓
D2E  L2完備性（Riesz--Fischer）→ Hilbert空間への橋
```

完全基礎論ルートでは、測度そのものの構成を知りたい読者だけ

```text
D2 → D3 → D4 → D5 → D2A
```

と寄り道できるようにします。

標準ルートでCarathéodory構成を必修化しません。

## 6. 既存基礎論の遡及監査

D2だけを特例扱いせず、**既存のF0基礎論も章粒度を遡って監査**します。

### 第1優先：既に大幅増補した章

Batch 1で教材密度を大きく上げたため、まず次を再監査します。

- F0-00B：距離空間・開集合・閉集合・収束
- F0-00C：連続写像・コンパクト性・最大最小
- F0-00D：Cauchy列・完備性・無限次元

ここでは **内容が多いから即分割** とはしません。

例えばCが

```text
連続性 → compactness → Weierstrass → 最近点存在
```

という一つの存在証明の物語として自然に読めるなら、一講義のまま残せます。一方、演習や補題まで含めた結果、前半・後半が独立講義として明瞭に分かれるなら分割候補へ移します。

### 第2優先：標準基礎論ルート全体

次に標準ルートを遡って監査します。

```text
F0-00
 → A → A2 → B → C → D
 → D2系列
 → E → E2 → F → G
 → F0-02 → 02A → 02B
 → C1 → C2 → C3 → C4 → C5 → C6 → C7
```

各章について、

- 一つの主要な問いにまとまっているか
- 学習サイクルが何周あるか
- 独立した演習セットが複数必要になっていないか
- 後続の一部だけが章後半へ依存していないか

を記録します。

### 第3優先：Probability / Encore II〜V

標準基礎論の後、確率論補講・Encore群にも同じ基準を適用します。

特に名称に複数の大テーマが並ぶ章、主要定理が2系統以上ある章を優先して確認します。

## 7. 監査結果の状態

各講義を次のいずれかに分類します。

| 状態 | 意味 |
|---|---|
| `OK` | 一講義として自然。分割不要。 |
| `WATCH` | 現状は読めるが、証明・演習増補後に過積載になる可能性がある。 |
| `SPLIT` | 独立した学習サイクルが複数あり、分割を推奨。 |
| `MERGE` | 逆に薄すぎて隣接講義との統合を検討。 |

初期判定は次とします。

| 講義 | 初期判定 | 理由 |
|---|---|---|
| F0-00D2 | **SPLIT** | 測度基礎・積分構成・収束定理・積測度・Lp・L2完備性が独立した学習サイクル。 |
| F0-00B | WATCH | Batch 1で大幅増補。距離→開閉→収束→閉包が一つの基礎線として維持できるか再確認。 |
| F0-00C | WATCH | compactness周辺の主要定理と存在証明が多い。一本の物語として保てるか再確認。 |
| F0-00D | WATCH | 完備性と無限次元の反例・有限次元ノルム同値が一講義に収まるか再確認。 |

---

## 8. Batchへの組込み

今後の各Batchでは、対象章について次の順で作業します。

```text
1. 未定義語監査
2. 講義粒度監査
3. 必要なら先に分割
4. 定義・命題・定理の自己完結化
5. 主要証明の補完
6. 具体例の追加
7. A/B中心の演習追加
8. 読み順を再通読
9. metadata / roadmap / manifest / CI確認
```

**先に巨大ページを完成させてから分割するのではなく、粒度監査を証明・演習増補より前に行う**ことを原則とします。

これにより、D2のように「内容不足を直そうとして一ページが教科書一冊になる」ことを防ぎます。
