# DREAM THEATER 講義粒度・分割監査

この文書は、DREAM THEATER 本編・確率論補講・Encore II〜Vについて、**一つの講義ページへ内容を詰め込みすぎていないか**を監査するための正本です。

証明・定義・具体例・演習を増補すると、内容そのものは充実しても、一ページの中に複数の独立した講義が同居してしまうことがあります。したがって、内容不足だけでなく **講義粒度の過大さ** も品質問題として扱います。

---

## 1. 基本方針

ページの長さそのものでは分割しません。

分割判断の中心は、

> **このページは一つの主要な問いに答える一講義としてまとまっているか。**

です。

一つの講義の中では、原則として

```text
問い
 ↓
必要な定義
 ↓
主要命題
 ↓
証明・導出
 ↓
具体例
 ↓
A/B中心の演習
 ↓
次講への接続
```

という一つの学習サイクルが閉じることを目標とします。

---

## 2. 分割を検討する条件

次のうち複数が当てはまる場合、そのページを **分割候補** とします。

1. **主要な問いが複数ある**
   - 例：「積分をどう定義するか」と「極限と積分をいつ交換できるか」が同じページで独立して展開される。
2. **主要定理群が独立した論理鎖を複数作る**
   - 例：MCT → Fatou → DCT と、Tonelli → Fubini がそれぞれ別の講義として成立する。
3. **前半だけで後続章へ進める読者と、後半まで必要な読者が明確に分かれる**。
4. **定義・例・演習を本編並みに補うと、一つのページ内にA/B演習セットを複数置く必要がある**。
5. **途中で前提知識の種類が大きく変わる**。
6. **章内参照が「前半の講義」「後半の講義」と実質的に分離している**。
7. **一部だけを再読したい読者にとって、URL・見出し単位では粗すぎる**。

---

## 3. 分割しない条件

次の場合は長くても一講義のまま残せます。

- 一つの中心定理を証明するために多数の補題が必要なだけである。
- 例や演習が多いが、全て同じ主要概念を反復している。
- 分割すると各ページが定義だけ・証明だけ・演習だけになり、学習サイクルが壊れる。
- 前半と後半を分離すると循環参照や不自然な前提関係が生じる。

したがって **行数・文字数の閾値だけで機械分割しない** ことを明示します。

---

## 4. 分割時の互換性ルール

既存ページを分割する場合、原則として旧URLを壊しません。

### 4.1 既存URLを残す

既存ページは、次のどちらかとして残します。

- シリーズの第1講
- シリーズの入口兼ロードマップ

旧URLから新しい各講義へ直接たどれるようにします。

### 4.2 IDは枝番で増設する

既存の読み順を保つ場合、

```text
D2 → D2A → D2B → D2C → ...
```

のように枝番を使います。既存の後続IDを一斉改名してリンクを壊すことは避けます。

### 4.3 manifest / Facade / roadmap / prerequisites を同時更新する

分割時は最低限、

- `textbook/dream-theater-index.json`
- `textbook/dream-theater.md`
- 基礎論ロードマップ
- 各 `chapter.yaml` の `prerequisites`
- 関連する監査正本

を同期します。

## 5. 旧D2の判定：SPLIT済み

旧F0-00D2には、

1. σ代数・測度
2. 測度0・a.e.
3. 可測関数
4. 単関数とLebesgue積分の構成
5. MCT / Fatou / DCT
6. 積σ代数・積測度 / Tonelli / Fubini
7. `L^p` / Hölder / Minkowski
8. `L^2` 完備性
9. 確率論・Hilbert空間への接続

が同居していました。

これらは複数の独立した学習サイクルに分かれるため、Batch 2で次の6講義へ分割しました。

```text
D2   測度空間・測度0・a.e.・可測関数
 ↓
D2A  単関数からLebesgue積分を構成
 ↓
D2B  単調収束定理 → Fatouの補題 → 優収束定理
 ↓
D2C  積測度 → Tonelliの定理 → Fubiniの定理
 ↓
D2D  Lp空間 → Hölderの不等式 → Minkowskiの不等式
 ↓
D2E  L2完備性（Riesz--Fischer）→ Hilbert空間への橋
```

完全基礎論ルートでは、測度そのものの構成を知りたい読者だけ

```text
D2 → D3 → D4 → D5 → D2A
```

と寄り道します。標準ルートでCarathéodory構成を必修化しません。

## 6. B / C / D の遡及監査結果

Batch 1で大幅増補したF0-00B/C/Dを再監査しました。

結果は次です。

```text

 ↓

 ↓

 ↓

 ↓
D1  ノルム・Banach・有限次元と無限次元             [OK]
 ↓

```

### F0-00B：OK

距離 → 開球 → 開閉集合 → 点列収束 → 「閉集合は極限を逃さない」 → 内部・閉包・境界、という一つの問いにまとまっています。

後半の閉包も前半の点列収束・閉性を使って同じ学習サイクルを閉じており、別講義へ切るとむしろ定義だけの薄いページが生じます。したがって分割しません。

### 旧F0-00C：SPLIT済み

旧Cには、

1. 連続とは何か
2. コンパクトとは何か
3. コンパクト性を存在証明へどう使うか

という三つの独立した問いがありました。

したがって、

```text
C   連続写像・連続性の同値条件
 ↓
C1  コンパクト性・点列コンパクト性・Bolzano--Weierstrass・Heine--Borel・連続像
 ↓
C2  Weierstrass・有限直積・コンパクト集合間距離・最近点
```

へ分割しました。

C1は「コンパクト性の定義・判定・保存」、C2は「コンパクト性による存在証明」という別々の学習サイクルです。

### 旧F0-00D：SPLIT済み

旧Dには、

1. コーシー列と完備距離空間
2. ノルム・Banach空間
3. 有限次元のノルム同値・完備性
4. 無限次元で閉有界集合がコンパクトとは限らないこと

が同居していました。

前半は距離空間の完備性、後半はベクトル空間へノルムを入れた後の有限/無限次元比較で、問いも必要な前提も変わります。

したがって、

```text
D   コーシー列・完備距離空間
 ↓
D1  ノルム・Banach・有限次元ノルム同値・無限次元反例
```

へ分割しました。

D1の有限次元ノルム同値証明はWeierstrassの最大最小定理を使うため、F0-00C2も前提として明示します。

## 8. 次の遡及監査

A/A2も同じ基準で再監査し、A→A/A1、A2→A2/A3へ分割しました。次は標準基礎論ルートの残りを監査します。

```text
A → A1 → A2 → A3  [再監査・分割済み]
E → E2 → F → G
F0-02 → 02A → 02B

```

最後の系列は `F0-02C1...C7` を指し、今回新設した `F0-00C1/C2` とは別系列です。

その後、Probability / Encore II〜Vへ進みます。

各章について、

- 一つの主要な問いにまとまっているか
- 学習サイクルが何周あるか
- 独立した演習セットが複数必要になっていないか
- 後続の一部だけが章後半へ依存していないか

を記録します。

## 9. Batchへの組込み

今後の各Batchでは、対象章について次の順で作業します。

```text
1. 未定義語監査
2. 講義粒度監査
3. 必要なら先に分割
4. 定義・命題・定理の自己完結化
5. 主要証明の補完
6. 具体例の追加
7. A/B中心の演習追加
8. 読み順を再通読
9. metadata / roadmap / manifest / CI確認
```

**先に巨大ページを完成させてから分割するのではなく、粒度監査を証明・演習増補より前に行う**ことを原則とします。

これにより、「内容不足を直そうとして一ページが教科書一冊になる」ことを防ぎます。
