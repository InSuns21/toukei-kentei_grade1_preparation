## 目的・既存教材との差分

**中心問い:** 整数の一意分解が数体で壊れるとき、イデアル・局所化・完備化・類体論によって何を取り戻し、無限円分塔の算術をどう準備するか。

既存の \`NT1〜10\` は初等整数論、\`ANT1〜8\` は解析的整数論、\`MF1〜8\` は古典的モジュラー形式である。これらに **代数的整数論全体・局所体・Artin相互法則の完成系列はない**。\`FLD\` のGalois理論、\`RNG\` の環論、\`AG1\` の整拡大・Noether環の実在する部分を再利用し、既存の証明を複製しない。

到達点: 整数環の構造、判別式と分岐、イデアル類群・単数定理、局所体の分岐・ノルム、局所／大域類体論の**正確な対象・仮定・結論と構成上の核心**、円分体・Hilbert類体と無限塔への移行を説明・計算できる。

### 既習／補強の順序

- ANF1〜8: \`RNG\`, \`FLD\`, \`NT\`、必要なら \`AG1-04〜06\` の整拡大・局所化・Noether性の完成部分。
- ANF9〜13: ANF1〜8、有限拡大のGalois理論と位相／完備化に必要な既習 \`RA\` の部分。
- ANF14〜18: ANF9〜13と群作用／群コホモロジーの**初出をこの系列内で定義**する。未導入のTateコホモロジーやBrauer群を暗黙前提にしない。
- ANF19〜22: ANF14〜18、既存 \`ANT3\` の指標、\`ANT2\` のEuler積（解析類数公式の章ANF8では必要箇所だけ）。

### 代表的な独立再計算と外部入力の位置

- 類群とHilbert類体：K=Q(√−5) について判別式は −20、Minkowski上界は (2/π)√20 ≒ 2.847。ノルム2の非主素イデアル (2,1+√−5) が類群の非自明元で二乗は (2) に等しい。ANF22のノルム3素イデアルは a²+5b²=3 に整数解がないため非主。Cl(K)≅C₂ と Artin同型を使うと Hilbert類体上の指数は e=1、剰余次数 f=2、上の素イデアル数 g=1。ANF6→ANF22の数理接続を再計算した。
- 逆極限と円分塔：奇素数pに対し v_p((1+p)^(p^n)−1)=n+1。p=3,n=1 なら 4³−1=63=3²·7。素数冪円分体のGalois群の位数 (p−1)p^n からHensel持上げで得る Δ_n（位数p−1）を除けば次数p^nとなり、制限写像は自然なmod p^n還元。ANF9・10・18→ANF22の仮定と記法を確認。
- 局所から大域：ANF14のHilbert 90、ANF16のノルム群、ANF17の有限局所相互法則、ANF20の大域Artin写像・類体存在、ANF21の下降判定を実本文で接続確認。**一般の局所相互法則・大域相互法則と剰余類体存在は外部の中心定理**であり、ANF17/ANF20/ANF21はその証明責務を明示。ANF22で法(1)のCl_(1)(K)=I_K/P_Kを使う際、外部定理を独自に完全証明したとは称しない。
