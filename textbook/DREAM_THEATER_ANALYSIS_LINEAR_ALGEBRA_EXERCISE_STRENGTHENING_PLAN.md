# DREAM THEATER：解析・線形代数 演習強化計画

作成日: 2026-09-23

## 0. 目的

この文書は、DREAM THEATER の実解析・線形代数系列について、既存の本文・定理・証明を理解するだけでなく、学習者が紙上で主要操作を再現できるよう演習面を強化するための設計台帳である。

参照する外部書籍は次とする。

- 杉浦光夫・清水英男・金子晃・岡本和夫『解析演習』東京大学出版会
  - https://www.utp.or.jp/book/b302122.html
- 齋藤正彦『線型代数演習』東京大学出版会
  - https://www.utp.or.jp/book/b302056.html

公開されている目次・内容紹介は、**論点の広さ、演習の配置、基礎から発展へ進む構成を監査するための benchmark** として使う。

問題文・解答を転載、数値だけ変更、設定だけ変更して再利用することはしない。DREAM THEATER に置く問題は、既存 learning objective と prerequisite から独立に作成する。

## 1. 基本方針

DREAM THEATER の各章には原則として Level A 4題 / Level B 3題 / Level C 1題と詳細解答がある。

したがって「演習強化」を、

- 全章の問題数を一律に増やす
- 類題を大量に追加する
- 教科書演習を順番に移植する

こととは定義しない。

強化の主眼は次の3点とする。

1. **操作密度**：定理名を答えるだけでなく、計算・構成・証明を実際に行わせる。
2. **累積性**：1章内だけで閉じず、過去の複数章を同時に使う。
3. **失敗例**：仮定を外したとき何が壊れるかを自力で構成させる。

## 2. 『解析演習』から採る設計思想

公開目次では、

- 数列と極限
- 一変数・多変数微分
- Taylor 展開
- 極値
- 陰関数・条件付き極値
- 一変数積分
- 広義積分
- 一様収束・項別微積分
- パラメータ積分
- Fourier 級数
- 重積分
- 変数変換
- 線積分・面積分
- Green / Gauss / Stokes
- 微分形式・ベクトル解析

までが、節ごとの演習と章末問題を伴って配置されている。

DREAM THEATER ではこの「局所演習 + 累積章末問題」の二層構造を参考にする。

ただし、

- 多様体は GEO
- Fourier 級数は FOU
- 線積分・面積分・積分定理は VC
- 複素ベクトル解析は既存関連系列

を canonical とし、RA 演習へ重複収録しない。

## 3. 『線型代数演習』から採る設計思想

公開目次では、

- ベクトル・直線・平面
- 行列・線形変換
- 基本変形・階数・連立一次方程式
- 内積
- 行列式
- 特性多項式・固有値
- 線形空間・線形写像・基底・部分空間
- Jordan 標準形・最小多項式
- 対称変換・二次形式
- 複素計量線形空間の正規変換

までを、節単位の基礎問題と章単位の総合問題で反復する構成になっている。

DREAM THEATER では LA1--LA6 が抽象理論まで進んでいるため、

- 計算
- 抽象化
- 基底変更
- 不変量
- 応用

を往復させる演習へ強化する。

## 4. 強化対象の分類

各章の演習を次の5種類で監査する。

### Type 1：定義を直接検証する問題

例：

- 与えられた関数列が一様収束するか量化記号から判定する。
- 与えられた部分集合が部分空間か公理から確認する。
- 与えられた作用素が Hermitian / unitary / normal のどれか判定する。

定義問題でも、名称当てだけではなく少なくとも1回は条件を計算する。

### Type 2：標準計算を最後まで行う問題

例：

- 広義積分の収束判定を実行する。
- Jacobian を計算して変数変換する。
- 基本変形から階数・核・像を求める。
- 特性多項式・最小多項式・Jordan 鎖を計算する。

途中式を隠さない。

### Type 3：定理を使うための仮定確認問題

例：

- 一様収束と各点収束のどちらしか得られないか確認する。
- 逆関数定理の Jacobian 非退化条件を検証する。
- スペクトル定理を使える作用素か判定する。

「定理名を知っている」ではなく「この対象へ本当に適用できるか」を問う。

### Type 4：反例・境界例を作る問題

例：

- 各点収束するが一様収束しない関数列。
- 条件収束級数の再配列。
- 対角化できないが特性多項式が分解する行列。
- normal でない行列について直交固有基底が得られない例。

失った仮定と壊れた証明機構まで解答で説明する。

### Type 5：複数章を接続する総合問題

例：

- 陰関数定理 + Hessian + 条件付き極値。
- 変数変換 + Gaussian 積分 + 行列式。
- Jordan 標準形 + 線形 ODE。
- 二次形式 + 固有値 + 最適化。
- SVD + 最小二乗。
- 固有空間分解 + 行列指数。

本計画で最も増やしたいのは Type 5 である。

## 5. 実解析系列の演習強化

### Phase RA-E1：既存 RA1--RA8 の問題型監査

各 chapter.yaml の

- learning_objectives
- problem_patterns
- exercise_counts

を一覧化し、各 learning objective が少なくとも1題の演習で実際に使われるかを確認する。

特に次を重点監査する。

- RA1 / RA1A：収束判定の使い分けと境界例
- RA2：epsilon-delta / 一様連続の量化順序
- RA3：Taylor remainder と誤差評価
- RA4 / RA4A：可積分性判定と広義積分の片側処理
- RA5：一様収束・積分交換・微分交換
- RA6A：逆関数・陰関数・Lagrange 未定乗数
- RA7：Jacobian と領域変換
- RA8：Arzelà--Ascoli / Stone--Weierstrass の適用条件

### Phase RA-E2：局所演習の不足補強

問題数の一律増加はしない。

既存 A4/B3/C1 の中で learning objective が未使用なら、弱い類題を置換することを優先する。

追加する場合も、

- Level A：定義検証・単一技能
- Level B：定理適用・反例・複数段計算
- Level C：複数章統合・証明再構成

の役割を崩さない。

### Phase RA-E3：累積 review set

章とは別に、複数章を横断する review set を作る候補とする。

仮称：

- RA-R1「極限・級数・連続」
- RA-R2「微分・Taylor・極値」
- RA-R3「積分・広義積分・一様収束」
- RA-R4「多変数微分・陰関数・変数変換」
- RA-R5「関数族・近似・後続解析への橋」

各 review set は 6--10 題程度を候補とし、同じ小技の反復ではなく技能の組合せを変える。

### Phase RA-E4：実解析から PDE への橋問題

新しい実解析・調和解析強化計画と接続し、次のような問題を用意する。

- Gaussian の尺度変換と積分値
- |x|^{-alpha} の局所可積分性
- convolution estimate
- approximate identity
- Sobolev 型 scaling
- heat kernel の Lp-Lq 指数計算
- Riesz potential の scaling

PDE 本編で初見計算を大量発生させないことが目的である。

## 6. 線形代数系列の演習強化

### Phase LA-E1：LA1--LA6 の問題型監査

重点項目：

- LA1：実・複素線形性の判定
- LA2：直和・商空間・第一同型定理
- LA3A：双対・annihilator・双対写像
- LA3B / LA3C：行列式の構成と計算
- LA3D / LA3E：抽象行列式・テンソル積・外積代数
- LA4：最小多項式・一般化固有空間・Jordan 標準形
- LA5：随伴・Hermitian / unitary / normal
- LA6：二次形式・慣性法則・polar decomposition・SVD

抽象定義だけ理解して計算技能が空洞化していないか、逆に計算だけで構造を読ませていないかを両方向から監査する。

### Phase LA-E2：計算と抽象の往復

同じ題材を、

1. 行列表示で計算する。
2. 基底に依らない言葉へ読み替える。
3. 基底変更後も何が不変か確認する。

という3段階で扱う問題を増やす。

例：

- 行列の rank-nullity を計算し、第一同型定理へ読み替える。
- 具体行列の行列式を計算し、体積倍率として説明する。
- Jordan form を求め、最小多項式から同じ構造を確認する。
- Hermitian 行列を対角化し、二次形式の符号を判定する。

### Phase LA-E3：累積 review set

仮称：

- LA-R1「行列・連立一次方程式・線形写像」
- LA-R2「行列式・固有値・不変量」
- LA-R3「線形空間・商・双対」
- LA-R4「最小多項式・Jordan 構造」
- LA-R5「内積・スペクトル・二次形式・SVD」

各 review set は 6--10 題程度を候補とする。

### Phase LA-E4：他系列への橋問題

線形代数を単独科目で閉じない。

候補：

- Jordan form と線形 ODE
- 固有値と反復法
- SVD と最小二乗
- 正定値二次形式と凸最適化
- 行列式と多変数変数変換
- 外積代数と微分形式
- Hermitian / unitary と量子統計
- 行列指数と Markov 連鎖

canonical theorem は LA 側を参照し、応用先で同じ線形代数を再証明しない。

## 7. 問題作成ルール

### 7.1 外部演習書の使い方

外部演習書は、

- coverage の漏れ
- 難度の幅
- 章末で複数技能をまとめる設計
- 標準的な計算対象

を確認するために使う。

問題本文や解答は DREAM THEATER 用に独立作成する。

禁止：

- 問題文の転載
- 数値・文字だけ変えた問題
- 設定を少し変えただけの近接言い換え
- 解答の論証順をそのまま移植
- 出典を隠した事実上のコピー

### 7.2 DREAM THEATER の詳細解答

各問題の詳細解答では、

1. 何から始めるか
2. どの定義・定理を使うか
3. その適用条件をどう確認するか
4. 主要な中間式
5. 結論

を追えるようにする。

「計算すると」「整理すると」「同様に」で非自明な複数段を隠さない。

### 7.3 題数の水増しをしない

同じ手順を数値だけ変えて複数題にしない。

一つの問題で十分に反復できるなら、解答中に追加確認例を置く。

## 8. 実装順

推奨順は次とする。

~~~text
Phase 1
RA1--RA8 / LA1--LA6 の exercise coverage audit
        ↓
Phase 2
learning objective 未使用箇所の局所補強
        ↓
Phase 3
RA-R1--R5 / LA-R1--R5 の累積 review set
        ↓
Phase 4
PDE / ODE / 数値解析 / 幾何 / 確率への橋問題
~~~

Phase 1 で十分な章は無理に変更しない。

## 9. 機械監査候補

将来的には、chapter.yaml の learning_objectives と problem_patterns の対応を補助監査できるようにする。

ただし自然言語の learning objective と演習内容の意味的対応は完全自動化しない。

候補出力：

- objective ごとの exercise link
- exercise が参照する canonical definitions / theorems
- Level A/B/C の偏り
- 同一 problem pattern の過剰反復
- 章をまたぐ cumulative exercise の有無

WARN は人手査読の候補抽出に使い、CI を通すためだけに形式的な problem_pattern を追加しない。

## 10. 完成条件

演習強化の完了は「問題数が増えた」ことでは判定しない。

次を満たすことを完成条件とする。

- 各主要 learning objective が演習で少なくとも1回は能動的に使われる。
- 定義検証・標準計算・仮定確認・反例・総合問題のいずれかが偏りすぎない。
- RA / LA ともに複数章横断問題がある。
- 全問題に詳細解答がある。
- prerequisite 外の概念を暗黙使用しない。
- 外部演習書への依存なしに問題と解答が自己完結している。
- 問題数増加ではなく、再現可能な数学操作の範囲が増えている。
