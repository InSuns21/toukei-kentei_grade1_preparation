## 1. winding number
$$\operatorname{Ind}(\gamma,a)=\frac1{2\pi i}\int_\gamma\frac{dz}{z-a}.$$

### 定理 CA5-THM-01：整数値性と局所定数性
index は整数で、$\mathbb C\setminus\gamma$ の各連結成分上で一定、非有界成分で0。

## 2. 偏角原理
### 定理 CA5-THM-02：偏角原理
曲線上に零点・極を持たない meromorphic 関数について
$$\frac1{2\pi i}\int_\gamma\frac{f'}f\,dz=N-P$$
（一般には index で重み付け）。

## 3. Rouché
### 定理 CA5-THM-03：Rouché の定理
単純閉曲線上で $|g|<|f|$ なら $f$ と $f+g$ は内部に同数の零点を重複度込みで持つ。
