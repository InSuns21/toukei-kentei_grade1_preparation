# DREAM THEATER オリガミクス：折り紙の幾何・作図・平坦折り・計算折り紙

- 設計・講義数確定: 2026-11-10
- 状態: in progress（ORI1 の本文・系列manifest・公開導線を実装開始。残りの講義と映像資産は未完了）
- 系列仮ID: `ORI`（`ORI1`〜`ORI30`。着手時に既存ID・pathと再照合）
- **確定講義数: 30講（5部構成、5 + 7 + 7 + 5 + 6講）**

## 1. 中心問いと授業の境界

**紙を折るという幾何操作で何を作図でき、どのような折り線図が平坦・連続的に折れ、どこまでアルゴリズムで設計できるか。**

「オリガミノミクス」との依頼は、数学・数学教育で通用する「**オリガミクス（Origamics）**」として扱う。芳賀和夫の正方形の幾何を入口に、現代の *mathematical origami / computational origami* を後半へ接続する。名称は経済学の「〜ノミクス」を意味しない。

以下の区別を通読中ずっと維持する。

1. **作図可能性**：既知の点・直線から定めた折り操作を有限回行い、新たな点・直線を得られるか。単一折りの公理、同時複数折り、曲線折りを混同しない。
2. **静的な平坦折り可能性**：指定された折り線と山谷・層順に従う自己交差のない平坦な配置が存在するか。単一頂点と多頂点を区別する。
3. **連続的な折り畳み可能性**：初期の平らな状態から面の剛性・衝突回避等を守って目標配置まで動けるか。完成形の存在だけから可動性を結論しない。
4. **数理模型と現実の紙**：厚さ0・伸長なし・理想ヒンジの模型と、紙厚・曲げ・弾性・摩擦をもつ実物を区別する。SVGの見た目は実現可能性の証明ではない。

- `NP`/計算複雑性に相当する既存の正本と形式をORI19の着手時に照合し、NP困難性とNP完全性を混同しない。NP困難性の帰着の核心を証明できない場合、結果紹介の境界を明記して講義完成を誤認しない。

## 4. 全30講シラバス（確定）

### I. 幾何折りと芳賀のオリガミクス（ORI1〜5）

1. **ORI1：折り目は何をする写像か** — 点・直線・折り線・反射、等距離性、紙面の局所等長写像。点を重ねる折りが垂直二等分線になることを座標と合同で証明。直接例：正方形の対角線と中線。
2. **ORI2：芳賀の定理と比の幾何** — 正方形の角を指定位置へ折るときの辺比・合同三角形。条件を変えた場合の比の変化を相似とPythagorasで導出。特殊配置だけを一般定理として提示しない。
3. **ORI3：折りによる等分・面積・有理比** — $1/n$等分の実構成、面積比、折り線の交点の座標検算。繰り返し操作の収束法と有限作図を区別する。
4. **ORI4：多角形・対称性・定理折り** — 正三角形・五角形等の折り線と角度の必要十分条件、芳賀の幾何図形の例を原図から独立に再構成。古典作図の一般可否はSQC/FLDへ委譲。
5. **ORI5：折りの包絡線と放物線** — 点を直線へ重ねる折りの軌跡を計算し、放物線の接線の包絡として理解する。焦点・準線の定義→反射による接線条件→具体式を導出。

### II. 折り紙作図の公理と代数（ORI6〜12）

6. **ORI6：Huzita–Justin公理O1〜O4** — 点・直線の一致条件と解の存在・一意性、二等分・垂線の構成。退化配置（同一点、平行・一致直線）の扱いを明確化。
7. **ORI7：公理O5と二次方程式** — 指定点を指定直線へ送る一折りと円・直線の交点。解が0/1/2本となる場合を式と図で判別する。
8. **ORI8：公理O6と三次方程式** — 二点を各々の直線へ同時に重ねる一折り（Beloch折り）。一般位置の連立制約から三次式を導き、実根・折り線の対応と退化例を調べる。
9. **ORI9：公理O7と単一折りの尽くし方** — 点・直線合わせの残る操作、7操作の分類と網羅性の前提。Justinの先行発表とHuzita・Hatoriの呼称を史料上区別する。
10. **ORI10：角の三等分と立方体倍積の折り紙作図** — Abeの三等分構成とBeloch型の立方根を、点の移動条件と三倍角公式から検算。**定規・コンパスでは不可能**と**折り紙では可能**を操作集合の差で説明する。
11. **ORI11：折り紙可作図数と拡大次数** — 一折りから生じる高々三次式、二次・三次拡大を使う十分性の範囲、次数が$2^a3^b$であることと作図可能性の同値を安易に主張しない。既存FLD/SQCへの使用箇所リンクを付ける。
12. **ORI12：同時複数折り・曲線折りの作図能力** — 単一折りとのモデル差、角の五等分・高次方程式の結果と制限、構成規則を明記。一般定理の研究級証明は必要なら独立した発展補講へ切り出し、本講で未証明を証明済み扱いしない。

### III. 平坦折りの局所・大域問題（ORI13〜19）

13. **ORI13：折り線図、山谷、平坦折り写像** — 平面グラフ・単頂点／多頂点・山折り谷折り・層順、面ごとの等長写像と重なりの整合条件を定義。線が描けることと折れることを区別。
14. **ORI14：Kawasaki–Justinの定理** — 単頂点・山谷未指定の場合の交互角和$180^\circ$の必要十分性。必要性と十分性を異なる手順で証明し、角順・偶数本・退化角を検査。
15. **ORI15：Maekawaの定理** — 平坦に折った内部単頂点での山谷本数差が$\pm2$となる必要条件を証明。Kawasaki条件と合わせても指定山谷の一般的十分条件にならない例を示す。
16. **ORI16：局所平坦折り可能性の判定** — 単頂点の折り線の構成・重ね順と山谷指定の可否を扱う。局所モデルでの成立範囲とアルゴリズムを、自己交差・零角の条件付きで記述。
17. **ORI17：複数頂点の大域条件・層順** — 局所条件が全体条件を保証しない反例、層の循環・衝突・非交差条件、平坦折り写像の整合性を証明付きで整理する。
18. **ORI18：地図折り・切手折りと組合せ** — 一列・格子の折り方、順列・層順・向きの制約、実例の列挙。全種類の数え上げと平坦折り判定は別問題とする。
19. **ORI19：平坦折り判定の計算困難性** — 問題の入力形式、証明書、NP困難性の定義、Bern–Hayes型の帰着の基本ガジェットと論理を詳述。一般定理の全帰着を再現できない場合は証明境界と原論文を明記し、簡単な制限クラスを独立に完全証明する。

### IV. 折り線図の計算設計（ORI20〜24）

20. **ORI20：一回の直線切断で何が切り出せるか** — fold-and-one-cutの厳密な入力、重なりと切断線、単純な多角形・文字形状の完全構成。定理の一般主張と示した特殊例を分離。
21. **ORI21：直線骨格を使うfold-and-one-cut** — 距離・角二等分線・骨格の作成、折り線図を生成する考え方。一般アルゴリズムの正当性は文献に照合し、証明上の未閉鎖点を明示する。
22. **ORI22：tree methodと円・河川パッキング** — 目標形状の木構造化、長さ制約、円配置から単軸基本形へ。単純な木の制約を手計算で検算。
23. **ORI23：box pleating・格子折りの設計** — 格子の角度条件、山谷と局所平坦性、複数配置の衝突の事前判定。最適化目的と単に一つ作れることを区別する。
24. **ORI24：Origamizerと多面体表面の実現** — 多面体・向き付き表面・被覆・追加構造の定義、構成アルゴリズムの入出力・保証・限界。Demaine–Tachiの普遍構成定理を特殊例と構成図から追い、一般証明を省略した部分を明記する。

### V. 剛体折り・曲線折り・応用（ORI25〜30）

25. **ORI25：剛体折りと4価頂点** — 面剛性、折り角、球面リンク、拘束式、単頂点4折り線の運動パラメータ。静的に平坦に折れることとの非同値性。
26. **ORI26：剛体折りの運動経路と特異点** — 配置空間・自由度・分岐・衝突・ロック、4価頂点を使った局所導出と反例。見かけの補間を実運動と呼ばない。
27. **ORI27：Miura折りと展開機構** — 平行四辺形格子、展開時の角・長さ関係、1自由度運動の成立条件、投影と幾何検算。厚さゼロの理想模型を明示する。
28. **ORI28：曲線折りと可展曲面** — 曲率・母線・局所等長条件を既習GEOに接続し、曲線の左右での接平面と展開可能性を検算。滑らかな曲面と離散パネル模型を区別する。
29. **ORI29：紙厚・自己折り・実装制約** — 厚さ・干渉・曲げのモデル化、アクチュエーションは幾何可動性とは別の条件であることを示す。理想化の反例を通じて応用境界を設定する。
30. **ORI30：総合設計・数学的検証** — 一つの折り線図について作図可能性、局所／大域平坦性、連続可動性、厚みの影響を別々に判定。数式・原図・アニメーションの一致を提出する総合演習。

**研究級の停止線**：ORI19の一般NP困難性、ORI21のfold-and-one-cut一般構成、ORI24のOrigamizer一般定理などは、特殊例だけを完全証明した場合「一般定理を完全証明済み」と記載しない。標準教科書・原論文での全証明を本講に置くか、直接必要な独立補講を設けるかを本文着手時に決定し、後続に必要な核心結果を未証明のまま通過させない。

### 5.2 形式・閲覧・アクセシビリティ

- **正本**：数理モデル（入力・単位・変数範囲・不変量）と編集可能なSVGソース、時間→幾何状態を生成する小さなJS/データ。必要なら同じ正本からMP4/WebMをオフライン書き出し。動画エンコード版のみを数学的正本にしない。
- **操作**：再生／一時停止／初めから／前後1工程／速度変更、折り工程番号、進捗と残りの操作をキーボードでも提供する。自動再生は行わず、`prefers-reduced-motion`で静止代表フレームを既定にする。ブラウザ内スクラブと戻しで状態が決定的に再現する設計。
- **表現**：山折り・谷折りは色だけで区別せず実線／破線や記号を併記する。前後関係は層番号・不透明度・遮蔽で示す。3次元の場面は**SVGへの投影図**である旨と投影法を明示し、2Dの単純な変形アニメを剛体折りの証拠にしない。
- **本文を正本に**：前に定義と仮定・式、後に結論と検算を記す。各映像へ静止ポスター、工程別の文章代替（字幕／トランスクリプト）、重要状態の静的SVG、描画不能時の表・式を用意。外部動画サイトへの依存なし。
- **配置の試案**：各章の`assets/`に映像固有のSVGと状態データ、共有の再生器は `pages/` の既存構成に合わせた1実装。直接HTML/JSをMarkdownへ無検証で埋め込まず、Docsify/Pagesのサニタイズ・CSP・Service Workerとの実機互換を先に確認する。具体パスとAPIは試作PRで確定。
- **図のlint**：静的SVG代表フレームも `DREAM_THEATER_AUTHORING_STANDARD.md` の配置／可読性／色非依存・`data-layout-lint="strict"` に従う。アニメーションの主要キーフレーム（開始・中間・終端・衝突が近い時点）を別途レンダリングして可視衝突を検査する。

### 5.3 制作順と受け入れ試験

1. **Phase A：再生器の試作** — ORI-V01（鏡映）とORI-V08（Kawasaki）を実装し、動きの不変量・停止・一工程送り・低速端末／狭い幅・スクリーンリーダーで確認。既存の数値シミュレーション共通基盤とは、数学的状態更新を含まない単純再生を無理に統合しない。
2. **Phase B：全学習パターンの制作** — V02〜V07を先に作り、O5/O6では解の0本と退化例を含める。V09〜V15は層順・剛体・曲面の別モデルの数理テストを先に整える。**最低15本は目標資産数であり、30講の不足した図の代替や映像による水増しを認めない。**
3. **Phase C：自動・実機試験** — 幾何状態の不変量をフレームごとに数値／記号で検算し、Playwright等で停止・巻戻し・速度・offline再訪、360px幅、200%拡大、静止画フォールバック、主要キーフレーム画像差分を確認する。
4. **Phase D：公開品質** — メイン本文から見られ、Pages上の動画再生と静止図・本文の式が一致する。動画がなくても講義の証明・演習が完結し、読み上げ・動き軽減が利用できることを人手で監査する。

## 6. 執筆・査読・完了判定

- 各講の `chapter.yaml` と `knowledge.yaml` は着手時に作り、直接prerequisiteを実在する章・stable anchorで固定する。前提外の用語を定義前に使わない。章間の逆依存・二重定義を避ける。
- 初出定義→条件確認つき直接例→形式的命題→核心を省略しない証明→反例・境界→演習と全詳細解答。理由付き例外がなければ各講 **Level A 4題 / B 3題 / C 1題以上**。とくに「折れそう」な図から実現可能性を結論させる誤答を検証する。
- 新規講義は変更区分Cとして全主要証明・全演習／詳細解答の再計算と別観点の再読を記録する。同一著者による再読を第三者独立査読と称しない。
- SVGを新規追加したときは `validate:svg-layout:changed` と `validate:svg-quality:changed` の適用に加え実レンダリングを検証し、動画は全主要キーフレームでの幾何的正しさも検証する。通常の本文変更はchanged-only validationを基本に、共有ランタイム／索引変更時のみfull validationへ昇格。
- 全30講、学修導線、演習・解答、図・映像（少なくとも15本とその代替）、knowledge DAG、シリーズmanifest、公開目次、実ブラウザ検証、横断監査が終わるまで `plan_done/` へ移さない。今回の**講義数確定とPLANのマージは執筆完了を意味しない**。
