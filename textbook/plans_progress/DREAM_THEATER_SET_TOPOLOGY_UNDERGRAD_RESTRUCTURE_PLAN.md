# DREAM THEATER 集合・位相空間論 学部標準再構成計画

作成日: 2026-09-29  
状態: in_progress

## 0. 目的

現在の DREAM THEATER では、集合・写像・集合族・順序・選択公理・Zorn の補題と、距離空間・位相空間・積・商・分離公理・コンパクト性などが「集合論・位相空間論」という一つの公開科目に置かれている。

既存章は後続科目の前提を埋める目的で段階的に追加されてきたため、個々の内容は有用でも、学部の「集合と位相」の講義として見ると、集合論前半の標準主題が薄く、F0-00A1D「順序・全順序・最小最大・整列」から選択公理へ急に進む構成になっている。

本計画では、既存 stable ID / URL と canonical result を尊重しつつ、**集合・写像・関係・可算性・濃度・順序を一通り学んでから位相へ進む、学部標準の「集合・位相空間論」へ再構成する**。

本計画は ZF / ZFC、順序数、超限帰納法、超限再帰などの公理的集合論を基礎科目へ持ち込む計画ではない。それらは別計画の独立科目「集合論・数学基礎論」で扱う。

## 1. 再構成の原則

1. 既存章を読まずに全面書き換えしない。
2. F0-00A / A1C / A1D / A2 / A3、F0-00B 系、TOP1--TOP7 の既存内容をまず監査する。
3. stable ID / anchor / URL は原則維持する。
4. 既存 canonical result がある主題を新章へ複製しない。
5. 学部「集合と位相」の読者が、位相の定義に入る前に必要な集合論の語彙と基本定理を自力で再構成できることを完成条件とする。
6. 順序数・超限帰納法・ZF の公理体系を prerequisite にしない。
7. 選択公理・Zorn は、学部数学で実際に使うための導入と適用をこの科目に残してよいが、基礎論的な完全同値証明は独立科目へ責務を分ける。

現在の集合・位相系列では、可算性公理は TOP4 に現れるが、その前提となる集合そのものの可算性を体系的に扱う章が薄い。

扱う候補:

- 有限集合・無限集合

- $\mathbb N\times\mathbb N$ の可算性
- 有限個・可算個の可算集合の和

- Cantor の対角線論法

候補 ID: **SET-U2「可算集合・非可算集合」**

### 3.3 濃度と集合の大きさ

学部「集合と位相」では、少なくとも次を一度は整理したい。

- 全単射による同じ濃度
- 単射による濃度比較
- Cantor--Bernstein の定理
- Cantor の定理 $X\not\cong\mathcal P(X)$
- $\mathbb R$ と $\mathcal P(\mathbb N)$ の濃度
- 可算無限と連続体の違い

候補 ID: **SET-U3「濃度・Cantor--Bernstein・Cantor の定理」**

ここでは基数を順序数として構成しない。$\aleph$ 記法や初期順序数を本格的に扱う場合は独立科目「集合論・数学基礎論」へ送る。
