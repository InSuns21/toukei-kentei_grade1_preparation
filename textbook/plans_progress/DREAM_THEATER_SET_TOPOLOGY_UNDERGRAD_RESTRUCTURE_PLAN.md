# DREAM THEATER 共通基礎再構成計画：集合論 → 線形代数 → 実解析 → 位相空間論

作成日: 2026-09-29  
状態: in_progress

## 0. 目的

現在の DREAM THEATER では、集合・写像・集合族・順序・選択公理・Zorn の補題と、距離空間・位相空間・積・商・分離公理・コンパクト性などが「集合論・位相空間論」という一つの公開科目に置かれている。

既存章は後続科目の前提を埋める目的で段階的に追加されてきたため、個々の内容は有用でも、学部の「集合と位相」の講義として見ると、集合論前半の標準主題が薄く、F0-00A1D「順序・全順序・最小最大・整列」から選択公理へ急に進む構成になっている。

本計画では、既存 stable ID / URL と canonical result を尊重しつつ、**集合・写像・関係・可算性・濃度・順序を一通り学んでから位相へ進む、学部標準の集合論・位相空間論へ再構成する**。

2026-10-02 の依存監査で、集合論と位相空間論を一つの公開科目として先に完走させる構成そのものが、線形代数・実解析との依存順を歪めていることが判明した。そこで本計画のスコープを共通基礎4科目へ拡張し、公開上・依存上の標準順を

~~~text
集合論
  ↓
線形代数
  ↓
実解析
  ↓
位相空間論
~~~

へ変更する。

ここで重要なのは目次だけを並べ替えないことである。**線形代数は位相空間論・実解析の結果を暗黙使用せず、実解析は一般距離空間・一般位相空間の結果を暗黙使用しない**ことを publication gate とする。後続の位相空間論は、実解析で具体的に学んだ収束・コンパクト性・完備性を一般の距離空間・位相空間へ抽象化する役割を担う。

本計画は ZF / ZFC、順序数、超限帰納法、超限再帰などの公理的集合論を基礎科目へ持ち込む計画ではない。それらは別計画の独立科目「集合論・数学基礎論」で扱う。

## 1. 再構成の原則

1. 既存章を読まずに全面書き換えしない。
2. F0-00A / A1C / A1D / A2 / A3、F0-00B 系、TOP1--TOP7 の既存内容をまず監査する。
3. stable ID / anchor / URL は原則維持する。
4. 既存 canonical result がある主題を新章へ複製しない。
5. 学部「集合と位相」の読者が、位相の定義に入る前に必要な集合論の語彙と基本定理を自力で再構成できることを完成条件とする。

7. 選択公理・Zorn は、学部数学で実際に使うための導入と適用をこの科目に残してよいが、基礎論的な完全同値証明は独立科目へ責務を分ける。

この順は見た目の分類ではなく、**前の科目だけを prerequisite として次へ進める**ことを意味する。


### 6.2 線形代数

線形代数は集合論だけを共通前提とし、距離空間・コンパクト性・一般位相・実解析の極値定理を prerequisite にしない。

対象は F0-00E / E1 / E2 / F / F1 / F2 と LA1--LA6・LA3A--LA3E 等の標準線形代数系列である。

特に次を publication gate とする。

- F0-00E の現行 \`F0-00B\` prerequisite は、本文・knowledge 上の実需要が確認できなければ削除する。
- F0-00F1 の実対称行列スペクトル定理は、現行の「単位球面の compactness → Rayleigh 商の最大値 → Lagrange 条件」という証明経路をそのまま使用しない。
- F0-00F1 / F0-00F2 / LA4--LA6 から後続位相・実解析へ流れる依存を全文検索・knowledge DAG の両方で監査する。

#### F0-00F1 証明経路 decision gate

現行 F0-00F1 は F0-00C2、Heine--Borel、コンパクト集合上の極値存在を実依存として持つ。これは「線形代数 → 実解析 → 位相空間論」という新順序と両立しない。

実装前に次を比較し、**後続科目を逆輸入しない経路だけを採用する**。

1. 複素化と固有値存在から自己共役作用素のスペクトル定理を導く代数的経路。
2. Schur 型三角化から normal / self-adjoint の対角化へ進む経路。
3. その他、有限次元線形代数として閉じる標準証明。
4. 上記のどの経路も、Fundamental Theorem of Algebra・実解析の極値定理・一般位相のコンパクト性などを逆輸入せず自然に閉じられない場合は、**スペクトル定理の正確な主張と使い方を F0-00F1 で先に扱い、証明だけを後段の回収章へ繰り下げる**。

ただし 1 / 2 は複素固有値の存在、すなわち多項式の根の存在をどこで保証するかを別途解決する必要がある。**Fundamental Theorem of Algebra を未定義のまま使ったり、後続の複素解析へ prerequisite を飛ばしたりしてはいけない。**

4 を採る場合も「証明済み」のように扱わない。F0-00F1 では定理の対象・仮定・結論、最小例、何が可能になるか、後続での使用法を自足的に説明し、「証明は後段で回収する」ことを学習者向けに自然に明示する。knowledge DAG では後段の証明章を F0-00F1 の prerequisite にせず、proof ownership / forward reference として追跡する。DREAM THEATER の通常の完全証明原則に対する**理由付き例外**として記録し、後段に実在する証明回収先を作ることを completion gate とする。

適切な有限次元線形代数内の証明が得られるなら 1--3 を優先し、無理に依存順を壊してまで完全証明を前倒ししない。この decision gate を通過するまで F0-00F1 の依存修正を完了扱いにしない。

#### decision gate 結論（2026-10-02）

**4 の「証明繰り下げ」を最小単位で採用する。スペクトル定理全体を黒箱にはしない。**

F0-00F1 では、次の存在補題だけを proof-deferred とする。

> 実対称行列 $A$ は少なくとも一つ実固有値と対応する単位固有ベクトルを持つ。

この補題を受け取った後は、単位固有ベクトル $v$ に対して $v^\perp$ が $A$-不変であることを
$$
\langle Ax,v\rangle
=
\langle x,Av\rangle
=
\lambda\langle x,v\rangle
=
0
$$
から示し、$A|_{v^\perp}$ が再び実対称であることを確認して次元帰納法を適用する。したがって、**直交固有基底の構成とスペクトル定理本体の帰納的論証は F0-00F1 内で完全に閉じる。**

繰り下げた存在補題の proof owner は F0-00C2 のコンパクト性応用部に置く。実解析を履修済みの段階で、単位球面のコンパクト性と Rayleigh 商の最大値存在を用いて最大化点 $v$ を取り、$v^\perp$ 方向の変分から $Av\parallel v$ を示す。現行 F0-00F1 の Lagrange 必要条件を線形代数側へ残す必要はない。

この構成では

~~~text
F0-00F1:
  固有対存在補題（結果のみ）
    ↓
  直交補空間の不変性
    ↓
  次元帰納法
    ↓
  実対称スペクトル定理

F0-00C2（後段）:
  単位球面のコンパクト性
    ↓
  Rayleigh 商の最大値存在
    ↓
  固有対存在補題の証明回収
~~~

と責務を分離する。F0-00F1 から F0-00C2 への prerequisite edge は置かず、forward proof reference として追跡する。
