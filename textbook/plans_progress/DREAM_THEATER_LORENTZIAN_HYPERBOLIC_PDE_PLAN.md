# DREAM THEATER ローレンツ多様体上の双曲型PDE I（HPDE系列・全24講）

作成・分冊: 2026-10-11  
改訂: 2026-10-18（標準講義・教科書との再照合、局所→大域の証明依存・束値分布・支持空間を精密化）  
状態: in_progress（HPDE1・HPDE2の本文・系列manifest・公開導線を実装済み。HPDE3〜HPDE24は未着手）

## 中心問いと出口

平坦な波動方程式の解法を、曲がった時空上でどのように定式化し直すか。**幾何学的な双曲性・大域双曲性・エネルギー評価から、初期値問題の存在一意性、有限伝播、遅延/先進Green作用素、因果伝播子のexact sequenceまで**を、関数空間と支持条件を含めて導く。

出口は、滑らかな大域双曲時空上のベクトル束値normally hyperbolic作用素について、Cauchy問題・Green作用素の主定理を正しく述べ、その証明の局所→大域の核を再構成でき、実スカラーKlein–Gordon場の古典的なシンプレクティック解空間を構成できること。相互作用QFTや量子真空・Hawking放射そのものは扱わない。

**共通の正確な設定**：時空 (M,g) は時間向き付き滑らかなLorentz多様体（符号 (-,+,…,+)）、標準定理では大域双曲・境界なし。E→M は有限ランク滑らかな実/複素ベクトル束とし、接続・束計量・向きを必要な命題で指定する。微分作用素の記号の規約を固定し、基本模型は P=-Box_g+m²（m²≥0、Box_g=g^{ab}∇_a∇_b）とする。一般のnormally hyperbolic Pの2次主シンボルは σ₂(P)(x,ξ)=-g_x^{-1}(ξ,ξ) id_{E_x} と定義する（フーリエの i による符号流儀と混同しない）。形式的自己随伴性は一般のPに自動では成立しない。

## 局所から大域への二つの証明経路

**経路A（初期値問題）**：HPDE1–2の手計算 → HPDE3–6の解析基盤 → HPDE7–10のエネルギー・一意性・有限伝播 → HPDE11の一次対称双曲系への還元と局所存在 → HPDE15–17の時間分割・貼り合わせによる大域Cauchy解 → HPDE18–20のGreen作用素。この経路では**後のHadamard局所基本解に局所存在の証明を依存させない**。

**経路B（局所基本解）**：HPDE3/4の束値分布・形式的双対 → HPDE12の分布核 → HPDE13のRiesz分布、測地的凸近傍、世界関数、van Vleck係数、Hadamard輸送式 → HPDE14のcutoff・平滑誤差とVolterra型補正 → HPDE15/18で経路Aの解との整合を検査。経路Bの補正を経路Aの既証局所存在で行う場合、それは**独立証明ではない**と明記する。「形式的漸近級数がそのまま真の基本解になる」という飛躍も禁止する。

**貼り合わせの注意**：局所解 `u_i` と分割関数 `χ_i` には `P(χ_i u_i)=χ_i P u_i+[P,χ_i]u_i` が生じる。したがって局所解をpartition of unityで単純に足しても大域解ではない。局所一意性、重なりの一致、有限伝播、コンパクトな因果領域、有限時間スラブでの延長を区別して証明する。

**最終的な主定理の閉包**：HPDE16の存在一意性・HPDE18–20の作用域と支持制約を前提に、HPDE21–22で `0→Γ_c(M,E) --P→ Γ_c(M,E) --E_cau→ Sol_sc(P)→0` の単射・核・全射を**別々に**示す。HPDE23は実スカラーKlein–Gordonの場合に限って自己随伴・シンプレクティック形式へ進む。非線形Einstein方程式、Hadamard二点関数、CCRの構成は下流科目と区別する。

## 支持空間・定理の精密化ゲート

- Γ_c(E) はコンパクト支持の滑らかな切断、Γ_sc(E) はあるコンパクトKについて支持が J(K)=J⁺(K)∪J⁻(K) に含まれる滑らかな切断。**解の支持は通常コンパクトではなく空間コンパクト**。過去コンパクトpc・未来コンパクトfc・時間コンパクトtcとは区別し、因果的未来/過去との交差のコンパクト性で各定義を与える。時刻方向有界とは無条件に等置しない。
- G_ret, G_advの入力はまず Γ_c(E) とし、出力は一般に Γ_c(E) でない。演算子等式は定義域を表示する。PはGreen作用素を持つという仮定だけで自己随伴とは限らない。
- exact sequenceは大域双曲時空上のnormally hyperbolic P、適切な支持と滑らかさの下で証明し、列0→Γ_c(M,E) --P→ Γ_c(M,E) --E_cau→ Sol_sc(P)→0をまず対象にし、冒頭の単射性を有限伝播とCauchy一意性から導く。長い列でΓ_sc --P→ Γ_scまで示すなら追加の作用域とexactnessを別証する。
- 波動作用素の主シンボルがLorentz計量の逆であることと、幾何の因果円錐・有限伝播の関係を主計算で示す。
- 一般の非大域双曲時空にretarded/advanced Green作用素を無条件に仮定しない。大域双曲でなくても特定の作用素・境界条件によって存在する場合は「存在しない」と断定せず、**一般定理が保証しなくなる**と表現する。
- 初期値の滑らかさとSobolev解・分布解は明示的に区別し、弱解から滑らかな解への格上げには正則性の仮定と証明を置く。

## 計算・証明・演習の必須ゲート

1. **平坦時空**：1+1 d'Alembert公式から初期値を代入して検算。3+1 massless模型でGreen核の支持を検算し、1+1・3+1のHuygens性の差を明確にする。
2. **エネルギーから一意性・有限伝播**：P u=fに乗数を掛け、発散恒等式→領域積分→境界項→Grönwallまでの中間式を省略しない。LORGの因果領域定義のどこを使うか特定する。
3. **局所→大域の存在**：局所Cauchy存在とHadamard局所基本解を別経路として、形式的→近似的→真の基本解の各ゲート、誤差補正、[P,χ]の交換子、局所解の一致、有限スラブでの大域的な延長を分解する。Bär–Ginoux–Pfäffleの一般定理を結果先行にする場合は明記し、モデル証明だけを一般証明と偽らない。
4. **Greenとexactness**：P G_± = id、G_± P = id、P E_cau=E_cau P=0を作用域付きで示し、ker E_cau =PΓ_c(E) と im E_cau={Pu=0, u∈Γ_sc(E)} を別々に証明。後者の分解にはCauchy時間関数とcutoffを具体的に使う。
5. **KG保存電流**：∇_a j^a = u Box_g v − v Box_g u を計算し、KG方程式から零、StokesによるCauchy面独立性と初期値による非退化性を証明。束値の一般化には束計量と形式的自己随伴の追加条件を要求する。
6. **反例**：除去点時空・時間的境界などで「局所双曲性はあるが大域一意性/Green存在の一般定理の仮定が欠ける」ことを因果ダイヤモンド・未指定境界条件の具体例で確認する。
