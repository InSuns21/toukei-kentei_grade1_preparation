# DREAM THEATER 主束・接続・ゲージ理論の幾何（GBG系列・全30講）

設計: 2026-10-13  
講義構成確定: 2026-11-21（標準教科書・公開講義ノートによる校正、全30講）  
状態: in_progress（GBG1〜GBG4は実装済み、GBG5〜GBG30は未着手）

## 1. 中心問いと到達点

**局所的なゲージポテンシャルをどのように大域的な幾何へ貼り合わせ、曲率・holonomy・特性類・位相的電荷を、どの仮定の下でゲージ不変量として取り出せるか。**

GEOはベクトル束・Levi–Civita接続・微分形式・de Rhamを、LIEはLie群・Maurer–Cartanを扱う。本科目はそれらを再講義せず、一般の主G束、表現から作る随伴束、一般接続、holonomy、Chern–Weil理論を一続きの証明として構成する。最後にU(1) monopoleと4次元SU(2) instantonを、局所表示から位相的不変量まで往復して計算する。

到達目標は次の5点である。

1. 遷移関数のcocycleから主束を構成し、局所section・束の同型・ゲージ変換を正確に区別する。
2. 右主作用の規約で接続1形式・水平分布・共変微分・曲率を構成し、局所ゲージ変換則・Bianchi恒等式を自力で導く。
3. 平行移動・holonomy・Wilson loopにおける基点、閉曲線、表現、共役作用を明示してゲージ不変性を検算する。
4. Chern–Weil形式の閉性・接続非依存性、U(1)の第一Chern数、SU(2)の第二Chern数・4次元の自己双対性を正規化込みで説明する。
5. Spin構造の存在障害とゲージ結合Dirac作用素を幾何学的に位置付け、一般指数定理・量子異常の未証明部分を切り分ける。

## 2. 前提・担当境界・数式規約

### 既習事項と段階的な追加前提

- 基本入口：既存GEO2／7〜9／13のうち必要な束・微分形式・de Rham・ベクトル束接続、LIE1〜4のLie群・Lie環・随伴作用・Maurer–Cartan、GRP／LA／位相。具体的な既習定義と結果のstable anchorは各章の執筆時に照合する。GEOのLevi–Civita接続を一般主束接続の定義そのものと混同しない。
- GBG15〜17：閉曲線のホモトピー・基本群を利用する際は必要な既習TOP章を指定し、経路の固定端点ホモトピーと自由ホモトピーを区別する。
- GBG18〜24：de Rham類に加え、Chern数の**整数性**を論じるときは整数係数コホモロジー、長完全系列または遷移関数の巻き数という必要部分を、その講の前段で導入する。de Rham閉形式だけから整数性は導けない。
- GBG25〜28：球面・clutching・次数／π3(SU(2))、向き付け、Hodge星、4次元積分のうち未習の道具を該当講に導入する。一般のホモトピー群分類や全Yang–Mills方程式の解空間分類を暗黙前提にしない。
- GBG29〜30：Spin(n)被覆・Clifford表現は[Lie群の表現・スピノル](../plans/DREAM_THEATER_LIE_REPRESENTATIONS_SPINORS_PLAN.md)の関連成果に接続する。ただし未完成のLREPを既存完成章の必修前提へ遡及追加しない。Z/2係数Čech cohomologyと第二Stiefel–Whitney類はGBG29の必要最小限を先に導入する。

### canonical ownership と停止線

- **GBGが所有**：主束・局所自明化とcocycle、主束接続、水平移動・holonomy、随伴束と共変微分、Chern–Weil、monopoleの大域幾何、SU(2) instantonの幾何、spin構造の大域的存在障害。
- **GEOが所有**：一般の微分形式・de Rham、ベクトル束の入口、Riemann／Levi–Civita幾何の基礎。曲がった時空の大域Lorentz因果構造は[LORG](../plan_done/DREAM_THEATER_LORENTZIAN_GEOMETRY_CAUSALITY_PLAN.md)の担当とする。
- **LREPが所有**：SU(2)・Spin群・Clifford代数・平坦時空のspinor表現の一般構成。本科目はその表現に主束接続を作用させたときの大域的幾何を扱う。
- **QFT II／IIIが所有**：Yang–Mills量子化、ゲージ固定・ghost／BRSTの詳細、Faddeev–Popov、ループ異常の具体的計算と標準模型の相殺。GBG13のゲージ軌道は幾何だけ、GBG30の異常・指数は証明責務を区別する橋に限る。一般Atiyah–Singer指数定理、4次元Yang–Mills理論の非摂動構成、全instantonsの分類、一般的なUhlenbeckコンパクト性定理を証明済みと扱わない。
- 平坦Minkowski上で局所計算を行うQFT IIにGBG全30講を一律必修とせず、必要な完成済みGBG章だけを後続の章単位で参照する。

### 固定する規約

- 滑らかな有限次元多様体M、有限次元Lie群G、右主作用R_g(p)=pgとLie環𝔤を基本設定にする。標準的な主束π:P→Mの局所sectionをs_i、重なりでs_j=s_i g_ijと置き、g_ij g_jk=g_ikとする。合成の左右・行列積順を章間で統一する。
- 接続1形式ωはω(ξ_P)=ξ、R_g^*ω=Ad(g^{-1})ω、局所ポテンシャルA_i=s_i^*ωとする。このときA_j=Ad(g_ij^{-1})A_i+g_ij^{-1}dg_ij。表現ρ:G→GL(V)から作る結合は(P×V)/((pg,v)∼(p,ρ(g)v))を用い、局所成分はv_j=ρ(g_ij^{-1})v_iとする。
- 曲率Ω=dω+(1/2)[ω∧ω]、局所曲率F_i=dA_i+(1/2)[A_i∧A_i]（行列表現ではdA_i+A_i∧A_i）とし、F_j=Ad(g_ij^{-1})F_i。Lie環値形式の角括弧・符号・次数を省略しない。
- 複素線束のU(1)接続を反Hermite行列値で書くとき、第一Chern形式は(i/2π)F（通常の行列表示）。第二Chern形式はc2=(1/8π²)tr(F∧F)（tr F=0のSU(2)接続・複素基本表現）を採り、向き・規約を切り替えたtopological chargeの符号は都度定義する。一般不変多項式の実数de Rham類、整数Chern類、特性数の整数性を別々に論証する。
- Hodge星やYang–Millsノルムは基底多様体の**指定した向きとRiemann計量**を使う。Lorentz符号の場合と4次元Euclid自己双対の場合を混ぜない。

### 講数の根拠と履修の分岐

**5 + 8 + 4 + 7 + 4 + 2 = 30講。**

- 元の13候補テーマを一講一項目にはしない。主束の貼り合わせと束自己同型、水平分布と接続形式、局所式と曲率、holonomyとWilson loop、Chern–Weilの閉性と接続非依存性、第一／第二Chern数、4次元自己双対性は別々の証明責務を持つため分けた。
- GBG1〜17は主束・接続・輸送の中核。GBG18〜24が局所曲率から大域的特性類への橋、GBG25〜28が4次元非可換例、GBG29〜30がSpin・指数との接続である。
- 大域的ゲージ理論に必要なルート：GBG1〜24を主軸に、4次元トポロジーを扱うときGBG25〜28へ。Spin/fermionへ進む場合GBG29〜30とLREPの必要部分を接続する。GBG27〜28が必要とするHodge星などの道具は各講で前提確認する。
- **講義数確定は学修内容の設計確定**であり、章の実装・検証が済んだという意味ではない。分割統合の必要が実際に判明した場合は理由を記録し、PLAN・manifest・直接参照を同時に更新する。

## 4. 必須の証明・検算・演習ゲート

1. **貼り合わせと右作用**：三重重なりでg_ij g_jk=g_ik、section変更でg'_ij=h_i^{-1}g_ij h_j、結合束の局所成分がρ(g^{-1})で変わることを、作用の向きからすべて再導出する。
2. **接続と曲率**：水平分布と接続形式の同値、局所Aの非斉次変換、Fの共変変換、d_A F=0の次数と符号を再計算する。単一の大域Lie環値1形式Aを任意の非自明主束に仮定しない。大域なのはP上のωである。
3. **輸送とWilson loop**：水平リフトの存在一意性をODEの仮定と結び、路の連結・向き・holonomyの共役変換からWilson loopのtrace不変性を導く。開いたWilson線の両端での変換を閉路と同一視しない。
4. **二つの非自明束を必須例にする**：S²上のU(1) Hopf／monopole束とS⁴上のSU(2) clutching／instanton束で、遷移関数→局所A→F→大域不変量の全工程を個別に検算する。S¹の平坦U(1) holonomyも補助的な反例に使う。
5. **Chern–Weilの三層を区別**：Ad不変多項式による閉形式、接続変更時の完全形式、整数係数特性類・整数特性数は論証の階層が異なる。特にde Rham類から整数性を飛躍して主張しない。traceの選択、2π、i、向き、実／複素、境界項を明示する。
6. **4次元とSpin**：SU(2)第二Chern数・積分・自己双対分解の符号、BPST模型の曲率と有限作用を再計算する。Spin障害のw₂に必要なZ/2係数コホモロジーを先に置く。Lorentz群とSpin(n)の使い分け、Dirac作用素の定義域・楕円性・境界条件を適用箇所で明記する。
7. **索引と異常**：index=zero modesの差は適切な楕円Fredholm作用素の下で語る。局所異常・大域異常・トポロジカル不変量を同一視しない。一般指数定理・量子異常の完全証明を持たない箇所は「導出済み」と書かない。
8. **各講の演習**：最低Level A 4題／B 3題／C 1題と全詳細解答を置く。最低数は上限ではない。単なる公式代入ではなく、直接例の束条件、変換、非自明な中間計算、仮定を落とした反例、分野間の往復を必要分だけ追加する。
