# DREAM THEATER：院試・編入演習系列 強化計画

作成日: 2026-09-23

## 0. 位置付け

この文書は、DREAM THEATER の理論系列とは別に置く **院試・編入向け演習系列** の設計台帳である。

現行リポジトリにはすでに次の独立演習章がある。

- `LAX1`「線形代数・院試／編入 計算演習」
- `CAX1`「複素解析・院試／編入 計算演習」

どちらも、理論章へ演習を無制限に足すのではなく、理論系列を prerequisite として **手計算・定理選択・場合分け・総合処理を反復する独立ページ**として実装されている。

今回の実解析演習強化も、この既存構造と整合させる。ただし、既存の `LAX1` / `CAX1` の題数・章構成・計算偏重を固定テンプレートとはしない。分野ごとの学習目標に合わせて構成を決める。

参照する外部演習書は次とする。

- 杉浦光夫・清水英男・金子晃・岡本和夫『解析演習』東京大学出版会
  - https://www.utp.or.jp/book/b302122.html
- 齋藤正彦『線型代数演習』東京大学出版会
  - https://www.utp.or.jp/book/b302056.html

外部演習書は coverage、難度、問題配置、典型技能の benchmark として使う。問題文・解答・論証順を転載または近接改変しない。

## 1. 既存演習章との整合

### 1.1 LAX1

現行 `LAX1` は `LA6` を prerequisite とし、理論の再講義ではなく、

- 行基本変形
- 階数・核・像
- パラメータ付き連立一次方程式
- 基底変換
- 行列式
- 固有値・対角化・行列の冪
- Gram--Schmidt / QR / 最小二乗
- 射影
- Householder 変換
- SVD
- 二次形式
- 双対基底・annihilator
- Hermitian / Schur / polar decomposition
- Jordan 鎖

を紙上で処理する独立演習章である。

現在は Level A 8題 / Level B 10題 / Level C 4題の計22題を持つ。

### 1.2 CAX1

現行 `CAX1` は `CA4` を prerequisite とし、

- Cauchy--Riemann
- 調和共役
- 複素指数方程式
- 複素線積分
- Cauchy 積分公式
- Taylor / Laurent 展開
- 留数
- 実積分
- Rouché の定理
- 偏角原理

を手計算と定理選択へ落とした独立演習章である。

こちらも Level A 8題 / Level B 10題 / Level C 4題の計22題を持つ。

### 1.3 今回の基本原則

したがって、新しい実解析演習を

- RA1--RA8 の各章へ大量に追記する
- RA-R1, RA-R2, ... のような小 review set を多数増殖させる

方式にはしない。

**理論章は理論章、集中的な演習は独立演習章**という現行設計を基本とする。

ただし `LAX1` / `CAX1` の「A8/B10/C4」は歴史的な実装値であり、今後の演習章すべてに強制しない。

## 2. 新設候補：RAX1 実解析・院試／編入 演習

仮 ID：`RAX1`

仮題：

> 実解析・院試／編入 演習

「計算演習」とするか単に「演習」とするかは実装時に確定する。

実解析では計算だけでなく、

- 定義からの判定
- epsilon--delta / epsilon--N 論法
- 仮定確認
- 反例構成
- 短い証明
- 収束概念の比較

が中核技能になるため、線形代数・複素解析よりも証明問題の比率を高くしてよい。

### prerequisite 候補

実装時に direct prerequisite を確定するが、少なくとも次を候補とする。

- RA4A
- RA6A
- RA7
- RA8

RA8 だけでは RA4A・RA6A・RA7 の全内容を経由しないため、単に「最後の章だけ」を prerequisite にして未修内容を暗黙使用しない。

## 3. RAX1 の範囲

### 3.1 数列・級数・関数極限

候補技能：

- epsilon--N による収束証明
- 単調性・有界性からの収束
- limsup / liminf
- 比較判定・比判定・根判定・凝縮判定の使い分け
- 条件収束と絶対収束
- 再配列
- 冪級数の収束半径と端点判定

単に「判定法の名前を答える」問題にはしない。

### 3.2 連続・一様連続

候補技能：

- epsilon--delta の直接証明
- 点列判定
- 一様連続性の判定
- Lipschitz 評価
- コンパクト性を使う Heine--Cantor
- 連続だが一様連続でない反例

量化記号の順序を実際に扱わせる。

### 3.3 微分・Taylor・極値

候補技能：

- 平均値定理の適用条件確認
- Taylor 剰余項による誤差評価
- 多変数微分・Jacobian
- Hessian と極値
- 逆関数定理の局所適用
- 陰関数の微分
- Lagrange 未定乗数法

単なる微分計算は既存の「計算基礎体力」と重複させず、定理適用・局所構造・誤差評価へ比重を置く。

### 3.4 Riemann 積分・広義積分

候補技能：

- Darboux 上下和からの可積分性
- 可積分 / 非可積分の判定
- 広義積分の片側極限
- 比較判定・Dirichlet / Abel 型判定
- 絶対収束・条件収束
- Cauchy 主値との区別
- Gamma / Beta 型積分

### 3.5 関数列・関数級数

候補技能：

- 各点収束と一様収束
- 一様 Cauchy 条件
- Weierstrass M-test
- 積分と極限の交換
- 微分と極限の交換
- 仮定を外した反例
- パラメータ積分

この部分は `DREAM_THEATER_REAL_ANALYSIS_STRENGTHENING_PLAN.md` で予定する RA5 補強と同期する。

### 3.6 多変数積分・変数変換

候補技能：

- 重積分の領域設定
- 反復積分
- Jacobian
- 極座標・球座標
- 変数変換公式の適用条件
- 多変数広義積分
- Gaussian 積分
- 原点・無限遠での可積分性

この部分は RA7 補強と同期する。

### 3.7 関数族のコンパクト性・近似

候補技能：

- 同程度連続性
- 各点有界性
- Arzelà--Ascoli の適用
- compactness が壊れる例
- Bernstein 多項式
- Stone--Weierstrass の適用条件

ここは「計算」より、仮定確認と短い証明を中心にする。

## 4. RAX1 に入れないもの

『解析演習』には広い意味での解析学として多様体、Fourier 級数、線積分・面積分、積分定理、微分形式なども含まれるが、DREAM THEATER では既存正本を優先する。

| 論点 | 正本 |
|---|---|
| 多様体 | GEO 系列 |
| Fourier 級数・Fourier 変換 | FOU 系列 |
| 線積分・面積分 | VC 系列 |
| Green / Gauss--Ostrogradsky / Stokes | VC 系列 |
| 微分形式 | GEO / VC の既存正本 |
| 複素解析 | CA 系列、演習は CAX1 |
| Lebesgue 積分・BV・絶対連続 | MT 系列 |

RAX1 は「解析学一般の巨大演習書」にはしない。

## 5. RAX1 の問題構成

既存 `LAX1` / `CAX1` と同じく Level A/B/C を使うが、題数は固定しない。

### Level A

目的：

- 定義を直接使う
- 標準的な判定・計算を最後まで通す
- 1つの定理を適用条件込みで使う

候補：8--10題。

### Level B

目的：

- 複数の収束概念を比較する
- 反例を構成する
- 条件分岐を行う
- 証明の核心1--2段を自力で再構成する
- 複数の定理をつなぐ

候補：10--12題。

### Level C

目的：

- 数列・関数列・積分・多変数解析を横断する
- 仮定を自分で整理する
- 院試・編入の大問として20--40分程度の論証を組み立てる

候補：4--6題。

**A8/B10/C4 に合わせること自体を目的にしない。** coverage と問題の独立性を優先する。

## 6. 『解析演習』から採るもの

東京大学出版会の『解析演習』は、各章冒頭で重要事項を整理し、基本例題から発展問題まで置き、章末問題を設ける構成である。

DREAM THEATER へは次を設計思想として取り込む。

- 基本技能から総合問題への段階化
- 一変数と多変数を分断しすぎない
- 極限・微分・積分を別々に覚えるだけでなく横断問題で再利用させる
- パラメータ積分・広義積分・一様収束など「極限交換」を重点的に練習する
- 定理の仮定を使う問題を置く
- 詳細解答で途中の判断を説明する

一方、同書の目次に含まれる多様体・Fourier・ベクトル解析は、RAX1 へ取り込まず既存系列へ送る。

## 7. LAX1 の再監査

『線型代数演習』は、

- 行列・一次方程式系
- 行列式・特性多項式
- 線形空間・線形写像
- Jordan 標準形・最小多項式
- 対称変換・二次形式
- 複素計量線形空間
- 線形微分方程式・漸化式への応用
- 多項式

まで含む。

現行 `LAX1` はすでにかなり広く、単純な問題追加は不要である。

### 7.1 監査する観点

- LA1--LA6 の主要 learning objective が LAX1 で実際に使われているか。
- 抽象概念が「名前だけ」で終わらず具体行列へ落ちているか。
- 逆に、計算だけで canonical theorem との関係が見えなくなっていないか。
- パラメータ付き問題・場合分け・検算が十分か。
- Jordan / SVD / polar decomposition が単発計算で終わらず、後続用途へつながるか。

### 7.2 追加候補

次は「『線型代数演習』に載っているから」ではなく、後続系列への橋として価値がある場合だけ追加する。

- Jordan 標準形と線形 ODE
- 固有値分解と漸化式
- 行列指数
- 多項式を用いた作用素計算
- パラメータ行列の rank / eigenstructure 分類

ただし、

- 数値線形代数は NA 系列
- 抽象代数としての多項式環は ALG 系列
- ODE 理論そのものは ODE 系列

を canonical とし、LAX1 を万能演習章へ膨張させない。

## 8. CAX1 の扱い

CAX1 は今回の外部参考書追加対象ではないが、演習系列の既存実装として参照する。

ただし CAX1 の現行 A8/B10/C4 や「計算演習」という名前を、そのまま RAX1 へコピーする必要はない。

複素解析では留数・Laurent 展開・輪郭積分など手計算の比率が高い一方、実解析では定義・反例・証明の比率が高い。この分野差を残す。

## 9. 演習系列全体の共通設計

今後の院試・編入演習章は、原則として次の構造を持つ。

1. **対象となる理論系列を prerequisite にする。**
2. 新しい大定理を演習章で初出させない。
3. 冒頭に「問題を見たときの最初の一手」を必要に応じて整理する。
4. Level A/B/C で技能を段階化する。
5. 全問に詳細解答を付ける。
6. 理論章の stable anchor へ戻れるようにする。
7. 同じ型を数値だけ変えて水増ししない。
8. 分野に応じて計算・証明・反例の比率を変える。

理論章の標準 A4/B3/C1 と、演習専用章の多題構成は別制度として扱う。

## 10. 外部演習書の利用規則

外部演習書は、

- coverage の漏れ
- 難度の幅
- 問題配置
- 標準技能
- 総合問題の粒度

を確認するために使う。

禁止：

- 問題文の転載
- 数値や文字だけを変更した問題
- 設定だけを変えた近接問題
- 解答の論証順の実質的コピー
- 書籍の問題を機械的に全項目対応させること

DREAM THEATER の問題は、canonical definitions / theorems / learning objectives から独立に設計する。

## 11. 実装順

推奨順：

~~~text
1. RAX1 の scope / prerequisite / learning objectives を確定
2. 『解析演習』を coverage benchmark として RAX1 問題設計
3. RAX1 を独立演習章として実装
4. LAX1 を『線型代数演習』と LA1--LA6 の learning objectives から再監査
5. 必要な不足だけ LAX1 へ追加または再編
6. CAX1 を含む演習系列全体の導線を dream-theater.md で統一
~~~

LAX1 / CAX1 の既存構成を守ること自体は目的にしない。より良い問題配置・分割が明確なら、既存演習章も再編してよい。

## 12. 完成条件

RAX1 または LAX1 改稿を完了扱いするには、

- 理論系列の主要技能が実際の問題で使われる。
- 計算だけでなく、必要な分野では仮定確認・反例・証明も含む。
- Level A/B/C の役割が明確である。
- 全問に詳細解答がある。
- prerequisite 外の概念を暗黙使用しない。
- 外部演習書なしで問題・解答が自己完結している。
- 題数ではなく、学習者が再現できる数学操作の範囲が増えている。

ことを確認する。
