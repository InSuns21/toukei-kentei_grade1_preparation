## 80題共通フォーマット

各実装問題は原則として次を含む。

- 問題: 4〜6小問、20〜30分級
- 詳細解答: 非自明な代数・行列計算を行間に隠さない
- 本番答案: 90分で3題を解く前提の圧縮答案
- 採点基準: 20点配点
- 打ち切り判断: 20〜25分時点で確保すべき式・論点

### 詳細解答の完全性ルール

「非自明な計算を隠さない」を次のように具体化する。

- 設問が「求めよ・導け・示せ」と要求した式を、詳細解答で既知公式として置かない。
- たとえば固有値なら特性方程式、差分方程式なら特性根または逐次導出、正規方程式なら消去過程、MGFなら定義の和・積分を残す。
- 「一般解は」「公式より」「定理より」の直後に答えが出る場合、その公式自体が当該小問の論点でないかを必ず確認する。
- 問題文が明示的に使用を許可した定理・分位点・公式は証明不要。ただし、そこから本問の答えへ至る代数は省略しない。
- 本番答案は短くしてよいが、採点基準で独立に配点された導出の核は残す。詳細解答だけでなく本番答案も「答えだけ」にはしない。

### 定理を適用するときの必須4点

定理・補題・漸近結果を使う箇所では、原則として

1. **定理名**
2. **必要条件**
3. **本問での条件確認**
4. **適用して得る結論**

を順に書く。

理工学では特に次を落とさない。

- Cochran / t / F: 正規誤差、直交射影、ランク、独立性。
- Gauss–Markov: 線形性、不偏性、$Var(\varepsilon)=\sigma^2I$、$X$ の列フルランク。正規性は不要。
- Wald / LR / Score / Wilks: 内部点、正則性、識別可能性、有限正情報量。
- Markov連鎖の収束・エルゴード定理・Kac公式: 既約性、非周期性、正再帰性など必要な条件。
- Poisson過程の条件付き順序統計量: **一様化は homogeneous Poisson process に対する条件付き結果**であり、非一様Poisson過程へ無条件に流用しない。
- Brown運動の反射原理: 標準Brown運動、$a>0$、$T>0$ など適用設定を確認する。

問題文が定理の使用を許していても、**その定理がこの設定で使えることの確認までは省略しない**。

Core / Standard / Advanced の全階層にこのルールを適用する。

## 電卓と数表

2026年度の試験条件を前提に、80題すべてを一般電卓（四則演算・％・平方根）と問題冊子の統計数値表で完答できるよう設計する。

$\log$, $e^x$, $\Phi$, $\Gamma$、非心分布などの数値評価は要求しない。必要なら記号式までで完答とするか、分位点・定数を問題文で与える。

## KaTeX検証

```bash
npm ci
npm run validate:rikou80
```

リポジトリ全体は

```bash
npm run validate:math
```

で検証する。`validate:rikou80` は `katex.renderToString` を `throwOnError: true`, `strict: "error"` で実行する。

## 数式記法

- インライン: `$...$`
- 別行: `$$...$$`
- 複数行: `$$\begin{aligned}...\end{aligned}$$`
- 禁止: `\(...\)`, `\[...\]`, `align`, `equation`, 独自マクロ
