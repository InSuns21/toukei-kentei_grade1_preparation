## 「統計応用」らしい大問にする

理工学午後問題は、数学的導出を含んでも **具体的な研究・工程・装置・観測・調査の文脈から始まり、結果を解釈して意思決定へ戻す** ことを原則とします。

```text
具体的文脈
→ 何を確率変数・応答・状態とするか
→ モデル化
→ 計算・導出
→ 解釈・設計判断
```

次の構成は避けます。

- 抽象的な $y=X\beta+\varepsilon$ だけを与え、射影行列の性質を証明して終わる。
- 「Markov連鎖」「ポアソン過程」「AR特性多項式」などを未定義のまま問題文へ置く。
- 詳細解答で初めて後退作用素 $B$ や弱定常性の意味を説明する。
- 本番で問われやすい解釈・モデル選択・設計判断を削り、純粋な定理証明だけを主目的にする。

数学は削らず、工学的問いを解くための道具として配置します。

## 確率過程・時系列の前提

確率過程・時系列は、最初の大問で最低限の定義を与えます。

- 確率過程: 時刻 $t$ ごとに確率変数 $X_t$ がある確率変数族。
- Markov性: 現在を条件とすると、次状態の条件付き分布がそれ以前の履歴に依存しない性質。
- ポアソン過程: $N(0)=0$、独立増分、区間長だけで決まるポアソン増分。
- Brown運動: $B(0)=0$、独立な正規増分、連続経路を持つ確率過程。
- 時系列: 白色雑音、弱定常性、自己共分散、自己相関をAR・MAより先に確認する。
- 後退作用素 $B$: $BX_t=X_{t-1}$ を短く書く記法にすぎない。初出では通常の添字表示を先に示す。

## 問題中の図

図は、式だけでは区別しにくい概念を短時間で認識させる場合に使用します。装飾目的では増やしません。

- 原則としてリポジトリ内の **SVG** を正本とし、拡大しても崩れず、差分レビューできる形にする。
- 図が読み込めなくても問題が解けるよう、必要な座標・定義・数値は本文にも残す。
- 図中に答えを直接書かない。問題では観察・分類・式との対応を受験者に求める。
- 代表例:
  - [Standard 38](standard/38_multicollinearity_diagnostics.md): 大残差、高レバレッジ、影響点候補を1枚の散布図で区別。
  - [Advanced 55](advanced/55_svm_margin.md): 2次元データ、決定境界、マージン境界を対応させる。

図は `assets/` に置き、問題ファイルから相対リンクします。
