## 「統計応用」らしい大問にする

理工学午後問題は、数学的導出を含んでも **具体的な研究・工程・装置・観測・調査の文脈から始まり、結果を解釈して意思決定へ戻す** ことを原則とします。

次の構成は避けます。

- 抽象的な $y=X\beta+\varepsilon$ だけを与え、射影行列の性質を証明して終わる。
- 「Markov連鎖」「Poisson過程」「AR特性多項式」などを未定義のまま問題文へ置く。
- 詳細解答で初めて後退作用素 $B$ や定常性の意味を説明する。
- 本番で問われやすい解釈・モデル選択・設計判断を削り、純粋な定理証明だけを主目的にする。

数学は削らず、**文脈 → モデル化 → 計算・導出 → 解釈** の順に置きます。純粋な行列証明や一般定理の完全証明は、午後問題で直接使う部分だけ Core に残し、残りは Standard / Advanced または統計数理側へのリンクに寄せます。

## 確率過程・時系列の前提

確率過程・時系列は、用語を既知扱いせず、最初の大問で最低限の定義を与えます。

- 確率過程: 時刻 $t$ ごとに確率変数 $X_t$ がある確率変数族。
- Markov性: 現在を条件とすると、次の状態の条件付き分布がそれ以前の履歴に依存しない性質。
- homogeneous Poisson過程: $N(0)=0$、独立増分、区間長だけで決まる Poisson 増分。
- Brown運動: $B(0)=0$、独立な正規増分、連続経路を持つ確率過程。
- 時系列: 時刻順に観測された確率変数列。白色雑音、弱定常性、自己共分散、自己相関を AR/MA より先に確認する。
- 後退作用素 $B$: あくまで $BX_t=X_{t-1}$ を短く書く記法。AR/MA の概念そのものではない。初出では必ず通常の添字表示を先に示す。

## 推奨学習順

ファイル番号は安定IDとして維持しますが、**初回学習で Core 01 から機械的に進む必要はありません**。

初回は午後問題の文脈を掴みやすい順として、次を推奨します。

1. 品質管理・工程能力（Core 21, 22, 36, 37, 39）。
2. 信頼性・寿命（Core 24〜27, 40）。
3. 実験計画（Core 14〜20, 38）。
4. 確率過程（Core 09, 10, 32, 33）と Brown運動の基礎。
5. 時系列（Core 11〜13, 34, 35）。
6. 回帰・線形モデル（Core 01〜06, 30, 31）。
7. 多変量・漸近・その他の横断論点。

回帰から始める場合でも、Core 01〜03の抽象行列論を「午後試験の代表形」と誤解しないでください。これらは道具の補強問題であり、適用・解釈を伴う問題を主軸に改稿します。

## 80題共通フォーマット

各実装問題は原則として次を含みます。

- 問題: 4〜6小問、20〜30分級
- 詳細解答
- 本番答案: 90分で3題を解く前提の圧縮答案
- 採点基準: 20点配点
- 打ち切り判断: 20〜25分時点で確保すべき式・論点

詳細解答の粒度、定理の適用条件確認、電卓・数表の制約、略語を使わない表記はすべて共通規約に従います。

詳細解答の代表的な粒度は `statistical-mathematics/core/40_fisher_information_delta_mle_efficiency.md` を参照します。ただし文字数を揃えるのではなく、各小問で「出発式 → 適用条件 → 採点対象の途中計算 → 結論」が追えることを基準にします。
