# Core 38 Fisherの3原則・実験単位

- 安定ID: `RIKOU-CORE-38`
- 80大問 No.: 43
- 演習価値: A
- 難度: C
- 目安時間: 20分

## 問題

傾斜による肥沃度勾配がある圃場で、3種類の肥料 $A,B,C$ を比較したい。

1. Fisherの3原則を挙げ、それぞれの目的を説明せよ。
2. 圃場を傾斜方向に応じて同質なブロックへ分けることは3原則のどれに対応するか。
3. 各肥料を1区画にだけ施し、その区画から植物を20本測定して「各群20標本」として通常の一元配置ANOVAを行うことの問題点を説明せよ。
4. この実験を妥当に設計し直す案を述べよ。

## 詳細解答

### 1. 3原則

- 反復: 同一処理を複数の独立実験単位に適用し、実験誤差を推定して精度を上げる。
- 無作為化: 処理割付をランダムにし、未知の交絡を平均化し確率的推論の根拠を作る。
- 局所管理: 既知の大きなばらつき要因で実験単位をブロック化し、誤差から系統変動を除く。

### 2. ブロック化

肥沃度勾配に沿って同質ブロックを作るのは局所管理に対応する。

### 3. 擬似反復

肥料の割付単位は区画である。1区画内の20植物は同じ処理割付を共有し、肥料処理に対する独立な実験単位20個ではない。植物を独立反復として扱うと誤差自由度を過大評価し、標準誤差を過小評価する擬似反復になる。

### 4. 再設計

複数ブロックを設け、各ブロック内に3区画を用意し、A,B,Cを無作為に割り付ける乱塊法が自然。各区画内で複数植物を測る場合は区画平均を解析単位とするか、階層モデルで区画内相関を扱う。

## 本番答案

Fisherの3原則は反復・無作為化・局所管理。反復は誤差推定、無作為化は交絡抑制と確率推論、局所管理は既知変動のブロック化を目的とする。圃場勾配でのブロック化は局所管理。

1肥料1区画で区画内20本を独立反復とするのは擬似反復で、処理の実験単位は区画である。複数ブロック内で各肥料を区画へ無作為割付する乱塊法へ改める。
