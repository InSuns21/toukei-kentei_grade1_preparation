# Core 40 横断監査 2026-08-25

対象: `applied-rikou-80/core/` の Core 01〜40。

監査観点は次の5点。

1. 問題の重複
2. 難度校正
3. 数値・数式の誤り
4. 本番30分以内に収まるか
5. 詳細解答が「計算すると」「整理すると」などで非自明な手計算を読者に押し付けていないか

## 総括

- **30分を明確に超える問題は0題**。
- **25〜30分を十分使う本番型**は約8題。
- **18〜25分程度**は約14題。
- **10〜18分程度の短め問題**は約18題。30分超過の心配はない一方、単独で「本番30分大問」と呼ぶには軽いものがある。
- 数値計算は再計算し、明確な数値ミスは確認されなかった。
- 数学・論理上の要修正を2件検出し修正した。
  - Core 20: D最適 exact design で、奇数 $n$ にも最大値 $n^2$ を達成すると読める記述を修正。奇数では最大値は $n^2-1$。
  - Core 32: 固定時刻での独立性だけから2つの計数**過程**の独立性を結論していた点を修正。独立増分と独立マーキングまで明示した。
- 行間で非自明な手計算を要求していた箇所を修正した。
  - Core 02: 追加平方和の「平方完成すると」を展開。
  - Core 06: 制約推定量の分散の「整理すると」を行列積まで展開。
  - Core 07: 3検定の漸近同値を Taylor 展開で1段深く説明し、対数の小数化を不要化。
  - Core 15: $2^3$ 効果の対比を一覧表で明示。
  - Core 33: $NR$ の行列積を明示。
  - Core 22, 36, 37: 正規尾確率や平方根の小数化を採点対象から外した。
  - Core 26: Gaussian積分を問題の主眼にせず、標準結果として使用可と明示。

## 重複監査

### 強い重複

**Core 27 と Core 39**。

- Core 27: ワイブルの密度・生存・ハザード・中央値・最頻値・平均・形状母数解釈
- Core 39: ワイブルの形状母数とハザード、初期故障・偶発故障・摩耗故障、bathtub

Core 39 の1〜4は Core 27 の1・5とかなり重なる。Core 39 固有の価値は「bathtub hazard を単一ワイブルでは表現できない」という部分が中心であり、Core 40 の1枠としては重複が大きい。

**推奨**: Core 39 は Standard 側へ戻し、代わりに親目次 No.61「$C_p$ の点推定とカイ二乗分布による信頼区間」を Core に昇格する案を第一候補とする。第二候補は No.37「Frisch–Waugh–Lovell」。

### 意図的に残せる中程度の重複

- Core 10 と Core 32: Poisson 過程の基本 vs 重ね合わせ・間引き。役割は異なる。
- Core 11, 12 と Core 34: AR構造 vs 多期予測。Core 34 は予測専用ドリルとして残せる。
- Core 14〜17: $2^k$、一部実施、直交表で公式が重なるが、設計思想が異なるため残す価値がある。
- Core 24〜27: 寿命・打ち切り・ワイブルで接続が強いが、尤度・ハザード・分布特性という別技能を担当している。
- Core 04 と Core 31: 回帰分散分析 vs 一元配置分散分析。一般線形モデルの同一骨格を別文脈で確認する意図的重複。
- Core 07 と Core 28: Score/フィッシャー情報量が重なるが、検定と指数型分布族で役割が異なる。

## 手計算ポリシー

この Core 40 では次を原則とする。

- 統計的立式が本質で、対数・正規尾確率・平方根の小数値が本質でない場合、**厳密式までで満点**とする。
- 詳細解答では、非自明な行列積・平方完成・符号対比を「計算すると」「整理すると」だけで飛ばさない。
- 本番答案では詳細計算を圧縮してよいが、詳細解答側には圧縮前の1段を必ず残す。
- 正規分布表、カイ二乗表、F表など外部数表が必要な数値は、数表が与えられない限り確率記号・分位点記号までを主解答とする。
- 問題の主題と無関係な Gaussian 積分などを突然証明させない。必要なら既知結果として問題文に与える。
