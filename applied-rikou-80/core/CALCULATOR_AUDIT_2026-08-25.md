# 2026年度一般電卓制約チェック

Core 40 を 2026年度統計検定1級の電卓条件で再確認した。

## 判定

- 関数電卓がなければ最終答案を作れない問題: **0題**
- CAS / R / Python がなければ最終答案を作れない問題: **0題**
- 数値積分が必要な問題: **0題**
- $\log$, $\exp$, $\Phi$, $\Gamma$ 等が登場するが記号式までで完答の問題: あり
- $t,\chi^2,F$ の分位点が必要な場合: 問題文で値を与える、または問題冊子の統計数値表を使う方針

## 個別注意

- Core 07: LRは $100\log(25/24)$ までで完答。
- Core 08: Markov LRT の対数和は厳密式までで完答。
- Core 10, 40: $e^{-c}$ は数値化しない。
- Core 22, 36: 正規確率は $\Phi$ 表現までで完答。数表があれば数値化可。
- Core 26: Gaussian積分値を問題文に与える。
- Core 27: $\log,\Gamma$ は記号のままでよい。
- Core 39: 必要なカイ二乗分位点を問題文に与える。残る計算は四則演算・平方根のみ。
