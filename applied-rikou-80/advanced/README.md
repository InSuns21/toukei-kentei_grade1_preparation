# Advanced 20 実装順

公式範囲の穴・低頻度難論点・横断問題を扱う20大問。各題20〜30分、問題・詳細解答・本番答案・20点採点基準を含む。難しさは手計算量ではなくモデル化・導出・解釈に置く。電卓・数表は `../core/CALCULATOR_POLICY.md` に従う。

## Advanced層の前提知識ルール

Advanced は「説明を省略してよい層」ではない。**Core を修了した受験者が、その問題文と同じページの説明だけで本流解答を追えること**を標準とする。

暗黙に既知としてよいのは、原則として次だけである。

1. `../core/` で既に導入・導出した事項。
2. 問題冒頭で「既知としてよい」と明示した事項。
3. 問題文で使用してよい公式・定理として与えた事項。

Advanced 固有の概念・名前・公式を初めて使う場合は、次の順序を優先する。

- まず定義・モデル・計算から性質を出す。
- その後で「これを○○と呼ぶ」と名前を付ける。
- 一般定理を使う場合は、少なくとも必要条件と本問で条件が満たされる理由を書く。
- 1級対策として証明全体を要求しない定理は、問題文で「使用してよい定理」として明示し、解答では適用条件を確認する。

特に次はブラックボックス化しない。

- 固有値・固有ベクトルを使う多変量解析: **なぜその固有値問題を解くのか**を目的関数から示す。
- 状態空間・判別分析: 完成した更新式・判別式を暗記公式として置かず、条件付き正規分布やBayes則から接続する。
- 乱数生成・Monte Carlo: アルゴリズムだけでなく、**なぜ目的分布になるか**を確率分布から確認する。
- 実験計画・標本設計: 最適化基準の名前だけでなく、何の分散・情報を最適化しているかを式で示す。

各題で前提の飛躍が大きい場合は、冒頭に次を短く置く。

- **既知としてよい**: Core で扱った事項。
- **この問題で導入**: Advanced 固有概念。
- **1級での扱い**: 導出対象か、使用してよい定理か、補足事項か。
- **関連Core**: 必要なら参照先。

同じ理論を複数題で長く重複させる場合は、共通解説または先行問題を正本としてリンクし、各問題では本問に必要な橋渡しだけを再掲する。
