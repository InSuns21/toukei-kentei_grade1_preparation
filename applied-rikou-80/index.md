# 統計検定1級 統計応用（理工学）80大問 — 正式演習目次

最終更新: 2026-08-25

## 設計方針

この80題は、統計検定1級「統計応用（理工学）」の公式出題範囲を骨格にし、公開過去問・過去問解説索引・理工学対策講座で確認できる頻出テーマを重ねて構成したオリジナル演習用の目次である。実過去問の問題文を転載するものではない。

本試験は5問から3問を選択する90分の論述式であるため、各大問は最終的に20〜30分、4〜6小問程度へ展開できる粒度を基本とする。

### 学習層

- **Core 40**: 先に2周する。理工学で3問を選ぶための主戦力。
- **Standard 20**: 頻出論点の変形耐性と横断力を作る。
- **Advanced 20**: 低頻度・高難度・未出寄りの論点まで穴を塞ぐ。

### 評価軸

**演習価値**は出題頻度だけでなく、他論点への転用性、本番で選択候補になりやすいか、近年の出題との接続を含めて評価する。

- **S**: 最優先。複数論点へ波及し、本番選択戦略上も強い。
- **A**: 高優先。頻出または重要な変形パターン。
- **B**: 網羅性・変形耐性を上げる補強問題。
- **C**: 低頻度だが公式範囲の穴を作らないための補完。

**難度**はこの問題を4〜6小問の大問へ展開した場合の想定難度で、`C < B < A < S` の順に難しい。

### 「過去問対応年度」の読み方

年度は「同一問題が出た年」ではなく、**同テーマまたは近接構造を確認した代表年度**を示す。`関連` は部分論点・近接構造、`シラバス補完` は公式範囲にはあるが今回確認した過去問索引から明確な対応年度を固定しなかったものを表す。実問題を正式に教材化するときは、リポジトリのスタイルガイドに従い `official_problem` と `third_party_topic_index` を区別する。

理工学固有の6項目をすべて明示的に含める。

- 多変量解析法: 多変量正規分布、平均ベクトル、分散共分散行列、相関行列、固有値・固有ベクトル
- 確率過程: ランダムウォーク、マルコフ過程、ポアソン過程、マルコフ連鎖、時系列解析、自己回帰過程、移動平均過程、ARIMA過程
- 線形推測: 線形モデル、一般化線形モデル、線形結合の分布、線形対比、線形制約
- 漸近理論: 大数の法則、中心極限定理、最尤推定量の漸近正規性、漸近分散、一致性、デルタ法
- 品質管理: 管理図、信頼性、保全性、プロセス管理、工程能力指数
- 実験計画: 実験の計画と実施、固定効果、変量効果、交絡因子、ブロック化、直交表、交絡法

さらに統計応用の共通事項から、標本調査法、実験計画法、重回帰分析、各種多変量解析法、確率過程、時系列解析を補う。共通基礎の「不完全データ」「シミュレーション」も、理工学の過去問・対策上の重要性から採用する。
