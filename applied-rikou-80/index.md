# 統計検定1級 統計応用（理工学）80大問 — 正式演習目次

最終更新: 2026-09-01

## 設計方針

この80題は、統計検定1級「統計応用（理工学）」の公式出題範囲を骨格にし、公開過去問・過去問解説索引で確認できるテーマを重ねたオリジナル演習である。実過去問の問題文を転載するものではない。

本試験は5問から3問を選択する90分の論述式であるため、各大問は原則20〜30分、4〜6小問程度で

```text
具体的な工程・装置・観測・調査の文脈
→ モデル化
→ 計算・導出
→ 結果の解釈・判断
```

まで進む構成とする。

## 出題範囲は三層で監査する

2015年の1級出題範囲表は、統計応用について **各分野に共通した事項** と **理工学固有事項** を別々に定めている。さらに現行の1級公式ページは「統計検定準1級の内容をすべて含む」としている。

したがって本教材では次の三層を別々に監査する。

1. **1級統計応用・共通事項層**
2. **1級理工学固有層**
3. **受験時点の準1級包含層**

Brown運動、$L_1$正則化、主成分分析、因子分析、判別分析、クラスター分析、ロジスティック回帰、プロビット分析、非線形回帰、サポートベクターマシン、状態空間モデルなどは、準1級だけでなく **2015年の1級統計応用・共通事項にも明記されている**。理工学固有欄だけを見て「範囲外」「発展」と判断しない。

2026年11月試験では2026年12月31日まで有効な準1級範囲を包含層として用いる。2027年1月1日以降の改定範囲は将来差分として別管理する。

詳細は [公式出題範囲との対応](../references/official-scope.md)、[範囲・午後問題適合性監査](SCOPE_APPLIEDNESS_AUDIT_2026-08-31.md)、[準1級包含の残論点監査](PRE1_INCLUSION_AUDIT_2026-09-01.md) を参照する。

## 学習層

- **Core 40**: 理工学で3問を選ぶための主戦力。
- **Standard 20**: 頻出論点の変形耐性と横断力を作る。
- **Advanced 20**: 低頻度・高難度・共通範囲の補強を担う。

番号は安定IDであり、初回学習順ではない。初回は品質管理・信頼性・実験計画など具体文脈の強い領域から入り、確率過程・時系列・回帰へ進むことを推奨する。

### 評価軸

- **S**: 最優先。複数論点へ波及し、本番の選択戦略上も強い。
- **A**: 高優先。頻出または公式明示範囲の重要な変形パターン。
- **B**: 網羅性・変形耐性を上げる補強。
- **C**: 低頻度・特殊。

難度は `C < B < A < S` の順に高い。

## 残存カバレッジ監査

今回までの統合・置換で、Brown運動、$L_1$正則化、非線形回帰、サポートベクターマシン、比例ハザード、因子分析、クラスター分析、プロビット、分類評価、情報量規準AIC、時系列クロスバリデーション、ブートストラップ、jackknife は80題内で実質演習できるようになった。

一方、80題を「準1級細目まで1項目1大問」にすることは目的ではない。[準1級包含の残論点監査](PRE1_INCLUSION_AUDIT_2026-09-01.md) の結論に従い、次の2群は現時点で理工80の独立枠を使わず、通常教材・統計数理側に正本を置く。

- 欠測メカニズム・期待値最大化法。
- 分割表・対数線形モデル。

期待値最大化法は完全データ対数尤度、E-step、M-step を独立して導入しないと概念が飛ぶ。対数線形モデルもカテゴリカルデータの独立性・オッズ比との接続を含めて通常教材側で扱う方が自然である。

理工80へ将来置換導入するのは、理工学午後問題として既存 Advanced より高い選択価値を示す過去問・出題証拠が得られた場合とする。
