# 統計検定1級 統計応用（理工学）80大問

統計検定1級「統計応用（理工学）」向けのオリジナル演習集です。公式出題範囲と公開過去問で確認できる主題をもとに、実際の工程・装置・観測・調査を題材として、モデル化から計算・導出、結果の解釈までを一つの大問で練習します。

本試験は90分で5問から3問を選ぶ論述式です。この問題集でも、1題をおおむね20〜30分で解くことを想定しています。

## この問題集について

各大問は、理工学の文脈から統計モデルを立て、必要な計算を行い、最後に結果を現実の判断へ戻す流れを重視しています。

```text
具体的な工程・装置・観測・調査
→ モデル化
→ 計算・導出
→ 結果の解釈・判断
```

実際の過去問題の問題文を転載するものではありません。

## 学習層

- **Core 40**：理工学で3問を選ぶための主力となる40題です。
- **Standard 20**：頻出論点の変形に対応する力と、複数分野をつなぐ力を鍛える20題です。
- **Advanced 20**：低頻度の論点、高難度の設定、共通範囲の補強を扱う20題です。

各問題には演習価値と難度を付けています。演習価値は **S → A → B → C** の順に優先度が高く、難度は **C → B → A → S** の順に高くなります。

## 学習の進め方

まず Core を中心に進めます。理工学らしい具体的な文脈から入りたい場合は、**品質管理 → 信頼性・寿命 → 実験計画 → 確率過程 → 時系列 → 回帰・線形モデル → 多変量解析・一般化線形モデル・分類・漸近・計算統計**の順が読みやすい構成です。

Core で主要な解法を固めたら Standard で変形に慣れ、必要に応じて Advanced へ進んでください。問題番号は学習順そのものではありません。

## 1問の構成

各大問は原則として、**問題 → 詳細解答 → 本番答案 → 20点の採点基準**で構成しています。問題によっては、時間内にどこまで確保するかを考えるための打ち切り判断や補足も付けています。
