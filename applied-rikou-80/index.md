# 統計検定1級 統計応用（理工学）80大問 — 正式演習目次

最終更新: 2026-08-31

## 設計方針

この80題は、統計検定1級「統計応用（理工学）」の公式出題範囲を骨格にし、公開過去問・過去問解説索引・理工学対策講座で確認できる頻出テーマを重ねたオリジナル演習である。実過去問の問題文を転載するものではない。

本試験は5問から3問を選択する90分の論述式であるため、各大問は原則20〜30分、4〜6小問程度で「具体的文脈 → モデル化 → 計算・導出 → 解釈」まで進む構成とする。

## 出題範囲は三層で監査する

2015年の1級出題範囲表は、統計応用について **各分野に共通した事項** と **理工学固有事項** を別々に定めている。さらに現行の1級公式ページは「統計検定準1級の内容をすべて含む」としている。

したがって本教材では次の三層を別々に監査する。

1. **1級統計応用・共通事項層**
2. **1級理工学固有層**
3. **受験時点の準1級包含層**

Brown運動、$L_1$正則化、主成分分析、因子分析、判別分析、クラスター分析、ロジスティック回帰、プロビット分析、非線形回帰、サポートベクターマシン、状態空間モデルなどは、準1級だけでなく **2015年の1級統計応用・共通事項にも明記されている**。理工学固有欄だけを見て「範囲外」「発展」と判断しない。

2026年11月試験では2026年12月31日まで有効な準1級範囲を包含層として用いる。2027年1月1日以降の改定範囲は将来差分として別管理する。

詳細は [公式出題範囲との対応](../references/official-scope.md) と [範囲・午後問題適合性監査](SCOPE_APPLIEDNESS_AUDIT_2026-08-31.md) を参照する。

## 80枠の運用

公式用語を1語ずつ独立大問にして80題を膨張させない。同じ答案技術へつながる論点は横断大問へ統合する。

2026-08-31の再監査で、明示範囲なのに薄かった項目を次のように補強した。

- No.21: Brown運動の基本定義・平均分散・共分散を反射原理より前に配置。
- No.25: 自己相関・偏自己相関によるモデル同定へペリオドグラムを統合。
- No.30: 状態空間モデルを「シラバス補完の難問」から1級共通事項の基礎へ再評価。
- No.38: 多重共線性・回帰診断へ $L_1$ 正則化とソフトしきい値を統合。
- No.69: 線形判別分析へ混同行列・ROC曲線・曲線下面積を統合。
- No.73: ロジスティック回帰へプロビットの潜在変数表現・限界効果を統合。

因子分析・クラスター分析など通常教材に独立章があるものは、理工学午後問題として独立大問化する根拠が弱い段階では、既存多変量大問への統合または通常教材へのリンクで担保する。

## 学習層

- **Core 40**: 理工学で3問を選ぶための主戦力。
- **Standard 20**: 頻出論点の変形耐性と横断力を作る。
- **Advanced 20**: 低頻度・高難度・未出寄りを補う。

Core No. は安定IDであり、初回学習順ではない。初回は品質管理・信頼性・実験計画など具体文脈の強い領域から入り、確率過程・時系列・回帰へ進むことを推奨する。

### 評価軸

- **S**: 最優先。複数論点へ波及し、本番の選択戦略上も強い。
- **A**: 高優先。頻出または公式明示範囲の重要な変形パターン。
- **B**: 網羅性・変形耐性を上げる補強。
- **C**: 低頻度・特殊。置換候補を含む。

難度は `C < B < A < S` の順に高い。
