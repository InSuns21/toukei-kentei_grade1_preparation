# P2-01 確率変数・確率関数・密度・累積分布関数

確率質量関数・確率密度関数・累積分布関数の日本語名、英語名、略語、式は`01_motivation.md`と`02_definitions.md`で初めて導入します。主要分布の式は`references/distribution-notation-guide.md`からも引けます。

## この章で解けるようになる問題

与えられた関数が分布を定めるかを非負性・正規化・累積分布関数の性質から判定し、離散・連続・混合分布の確率を計算します。二変量では同時分布から周辺分布を導き、独立性を因数分解で判定します。

## 公式出題範囲との対応

| 公式範囲 | 本章の内容 |
|---|---|
| 確率関数 | 離散型の確率質量関数、台、正規化 |
| 確率密度関数 | 連続型の確率密度関数、領域積分 |
| 累積分布関数 | 右連続性、跳躍、区間確率 |
| 同時分布 | 同時確率質量関数・同時確率密度関数、支持領域 |
| 周辺分布 | 和・積分による周辺化 |

期待値・分散・母関数は次章 P2-02 で扱います。

## 前提知識チェック

1. P1-01: 事象 $\{X\leq x\}$ の補事象を書く。
2. P1-02: 独立な二事象の積公式を述べる。
3. F0-01: 一変数・二変数積分を計算する。
4. F0-01: 区分関数の端点と左右極限を確認する。

## 学習目標

- 台を先に書き、確率質量関数または確率密度関数を正規化する。
- $F_X(x)=P(X\leq x)$ の不等号を保って端点を処理する。
- 累積分布関数の跳躍幅から点確率を読む。
- 同時分布の支持領域を図示または不等式で固定して周辺化する。
- Level Cを25分時点で提出可能な答案へ閉じる。

合格基準は Level B 85%以上、Level C 70%以上、30分ドリル70点以上です。
