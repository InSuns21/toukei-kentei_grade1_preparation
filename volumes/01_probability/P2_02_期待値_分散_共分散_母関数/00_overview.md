# P2-02 期待値・分散・共分散・母関数

## この章で解けるようになる問題

分布から平均・分散・共分散を導き、混合分布では群内変動と群間変動へ分解します。PGF・MGFは定義域と微分可能性を確認してから使い、独立和のモーメントを短く計算します。

## 公式範囲との対応

| 公式範囲 | 本章の内容 |
|---|---|
| 期待値 | 存在条件、LOTUS、線形性、全期待値 |
| 分散 | 二乗公式、線形変換、全分散 |
| 共分散 | 双線形性、独立との関係、相関係数 |
| 確率母関数 | 非負整数値、係数、階乗モーメント |
| モーメント母関数 | 存在範囲、微分、独立和 |

## 前提知識チェック

1. P2-01: PMF・PDFの台と正規化を確認する。
2. P2-01: 同時分布から周辺分布を求める。
3. P1-02: 有限分割に全確率公式を使う。
4. F0-01: 級数・積分・微分の収束条件を意識する。

## 学習目標

- $E[|X|]<\infty$ を期待値の前に確認する。
- $E[X^2]-(E[X])^2$ を使って分散を検算する。
- 共分散0と独立を混同しない。
- 全分散を群内分散と群平均の分散に分ける。
- 母関数の存在区間と微分点を明記する。
