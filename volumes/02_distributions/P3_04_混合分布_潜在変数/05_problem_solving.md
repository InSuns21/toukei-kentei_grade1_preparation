# 問題解決の型

混合問題では、最初に「成分指標を条件にした式」を書く。

1. $Z$ の値、$P(Z=j)=\pi_j$、条件付き分布を表にする。
2. 求める周辺質量関数・密度を $\sum_j\pi_jg_j$ または $\int g(x\mid\lambda)f(\lambda)d\lambda$ と書く。
3. 平均・分散は全期待値・全分散で計算し、群内項と群間項を分ける。
4. 観測 $x$ 後の成分確率は、各成分の尤度に事前重みを掛けて正規化する。
5. 推定では、観測データ尤度の積の中に和があることを確認する。成分が観測されていれば各成分の標本として解けるが、見えなければ責務を使う。

25分時点で積分が終わらない場合も、周辺化の式、全分散の二項、責務の分数のいずれかを完成させれば部分点を確保できる。混合比の和が1、責務の和が1、分散が非負であることを最後に検算する。
