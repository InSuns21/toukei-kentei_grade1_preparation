# P3-01 主要な離散分布

## この章で解けるようになる問題

「何を固定し、何を数えるか」から分布を選びます。固定回数の成功数、非復元標本の成功数、成功までの待ち時間、一定区間の発生件数、多カテゴリ度数を、台とPMFから論述します。

## 公式範囲との対応

| 試行構造 | 分布 |
|---|---|
| 1回の成否 | Bernoulli |
| 独立な$n$回の成功数 | 二項 |
| 有限母集団から非復元抽出 | 超幾何 |
| 初成功までの試行回数 | 幾何 |
| $r$回目の成功までの試行回数 | 負の二項 |
| 一定区間の発生件数 | Poisson |
| $m$カテゴリの度数 | 多項 |

## 前提知識チェック

1. P1-02: 独立試行の確率を積で表す。
2. P2-01: PMFの台と正規化を確認する。
3. P2-02: PGFの微分と独立和を使う。
4. F0-01: 二項定理・多項定理を使う。

## 学習目標

- パラメータ範囲と台を答案の最初に書く。
- 二項と超幾何、幾何と負の二項を区別する。
- 平均分散を暗記だけでなく指示変数・PGFから再現する。
- Level Cを25分で提出答案へ閉じる。
