# P4-01 変数変換・順序統計量

## この章で解けるようになる問題

変換後の台を先に描き、逆像を全て数え、絶対Jacobianを掛けます。和・差・積・比、極座標変換、最大・最小・第$k$順序統計量を、正規化検算まで含む25分答案にします。

## 公式出題範囲との対応

| 範囲 | 主な問題 |
|---|---|
| 一変数変換 | P4-A01, A02, C01 |
| 多変数・Jacobian | P4-B03, C02 |
| 和・差・積・比 | P4-B01, B02, C02, C05 |
| 最大・最小 | P4-A03, B04, C04, drill |
| 一般順序統計量 | P4-A04, C03, D01 |

## 前提知識チェック

1. F0-01: 逆関数、置換積分、Jacobianを計算する。
2. P2-01: CDFを微分して密度を得る。
3. P1-02: 独立標本の同時確率を積で表す。
4. P3-01: Gamma・Beta・二項係数を使う。
5. P3-02: 一様・指数・正規分布の密度と台を書く。

## 学習目標

- 非単調変換で逆像の寄与を足す。
- 変換前後の領域を不等式で対応させる。
- Jacobianの絶対値と積分変数を落とさない。
- 順序統計量の係数を「左・点・右」の配置数から導く。
- 最大・最小・範囲をCDF法と同時密度法で処理する。

合格基準はLevel B 85%以上、Level C 70%以上、30分ドリル70点以上です。
